# 라이더 시뮬레이터 (백엔드 쪽 문서)

- 시뮬레이터 저장소: `../pmart-rider-simulation`(백엔드 작업에서는 읽기만). 라스트마일(MFC → 고객)을 카카오 지도 위에서 돌리고, 가상 라이더가 라이더 앱처럼 배차 제안 수락 → MFC 인계 → 전달 완료를 한다(2026-11-16 시작).
- 회신·공지: `docs/handoff/simulator/rider/`. MFC 시뮬레이터 쪽은 `../mfc/`.
