## 1. 배치 규칙 (모든 계산 공통)

| 항목 | 값 | 출처 |
|---|---|---|
| 랙 바닥 | 1.25 × 0.45 m = 0.5625 ㎡, 높이 2.1 m | 문서 117행 표·263행·695행 |
| 랙 사이 통로 | 0.70 m | 문서 158행(1-2), 3-1 표 "70cm (확장하지 않음)" |
| 줄 형태 | 벽 홑줄 0.45 m + (통로 0.7 + 겹줄 0.9 m) 반복, 끝은 통로 0.7 또는 통로 + 홑줄 | 부산 평면과 같음 — 겹줄 1조 = 1.6 m 에 2줄 |
| 줄 끝 여유 | 안쪽 끝 0.8~1.0 m, 문 쪽 1.2~1.3 m | **[가정]** 부산 평면 값(북쪽 0.8~1.0 m) |
| 횡단 통로 | 줄이 12랙(15 m)을 넘으면 1.2 m 하나 | **[가정]** 부산 평면 냉동·냉장 18랙 줄의 가운데 통로 1.45 m |
| 칸(슬롯) | 냉동 5단×6, 냉장 5단×7, 상온 C·G 6×9, D·F 6×10, E 6×8, H 5×5 | 문서 282~296행(3-3), 338~350행(4-2) |
| 운영 상한 | 이론 칸의 85 % | 문서 3-3·4-2 |

**식**: 폭 W 에 놓을 수 있는 줄 수 = `max{1 + 2d (+1)}` s.t. `0.45 + 1.6·d + 0.7 (+0.45) ≤ W`. 줄 길이 Lr 에 놓을 수 있는 랙 = `max k` s.t. `1.25·k + 1.2·(토막 수 − 1) ≤ Lr`. 최대 랙 = 줄 수 × k.

## 6. 사용자에게 확인할 가정

1. 줄 끝 여유(0.8~1.3 m)·횡단 통로 1.2 m·12랙 규칙 — 문서에 없는 값이라 부산 평면에서 가져왔다.
2. 세종·창원 건물 = 직사각형, 승강기·경사로·출입 위치(각 README "열린 가정").
3. 새 센터의 **줄 번호 = 통로 번호** 규칙(부산은 물리 줄 번호) — Q-03 의 줄 1자리 제한 때문.
4. 세종·창원 수량은 부산 × 면적 비(사용자 2026-11-21) — 처리량·보충 빈도는 따로 계산하지 않았다.
