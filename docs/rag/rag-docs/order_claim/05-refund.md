# PMart 환불 업무 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 주문 취소, 결품, 반품, 오배송 등으로 생기는 환불의 금액 기준, 진행 단계, 완료 기준과 직원의 안내 기준을 정합니다.

## 제2조 (환불 방법)
1. 환불은 고객이 결제한 원래 결제를 결제사(토스페이먼츠)에서 취소하는 방법으로 합니다.
2. 결품과 반품은 원래 결제에서 해당 상품·수량의 금액만 취소하는 부분 결제 취소로 환불하며, 나머지 주문은 그대로 유지합니다.
3. 주문 전체를 취소한 뒤 남은 상품을 다시 결제하게 하는 방법은 쓰지 않습니다.
4. 반품 회수비나 오배송 다시 배송비처럼 따로 결제한 금액은 그 결제를 취소해 돌려줍니다. 상품 환불과 서로 상계하지 않습니다.

## 제3조 (환불 금액 기준)
1. 환불 금액은 주문 당시의 상품 단가와 금액으로 계산합니다. 지금 가격으로 다시 계산하지 않습니다.
2. 경우별 환불 금액은 다음과 같습니다.

| 경우 | 환불 금액 |
|---|---|
| 주문 전체 취소(고객 취소, 회사 사유 취소, 전체 결품) | 결제 금액 전액(상품액, 배달팁, 봉투값). 앞서 일부 환불한 금액은 뺌 |
| 결품 부분 취소 | 주문 당시 단가 × 결품 수량. 배달팁·봉투값 없음 |
| 반품 | 주문 당시 단가 × 검수한 수량. 배달팁·봉투값 없음 |
| 고객 잘못 오배송을 회수 후 환불 | 상품값 − 9,000원(0원 아래로 내려가지 않음). 배달팁·봉투값 없음 |
| 라이더·시스템 잘못 오배송을 환불로 선택 | 전 품목 상품값 |

3. 일부 상품을 환불해 상품액이 30,000원 아래로 내려가거나 최소 주문금액보다 적어져도 배달팁을 새로 받거나 다시 결제하게 하지 않습니다.
4. 회사는 현재 쿠폰·할인을 제공하지 않으므로 쿠폰 복원이나 할인 금액 차감은 없습니다.

## 제4조 (환불 한도와 중복 금지)
1. 추가로 환불할 수 있는 금액은 "최초 결제 금액 − 이미 환불된 금액 − 처리 중이거나 결과를 모르는 환불 금액"까지입니다. 이 한도를 넘는 환불은 실행되지 않습니다.
2. 같은 상품·수량에 취소, 결품, 반품, 미배송, 오배송 환불을 겹쳐 주지 않습니다. 다른 사유로 다시 신고해도 같은 피해 수량은 한 번만 환불합니다.
3. 같은 수량을 새 상품 발송(재발송·다시 배송)과 환불로 겹쳐 처리하지 않습니다.

## 제5조 (환불 진행 단계)
1. 환불은 다음 단계로 진행됩니다.
   - 접수
   - 심사·승인
   - 실행 대기
   - 결제사 결과 확인
   - 완료, 실패 또는 확인 중
2. 승인만으로 완료라고 안내하지 않습니다. 결제사의 결제 취소 성공이 확인되어야 "환불 완료"입니다.
3. 결제사 응답이 늦거나 결과를 모르면 "확인 중"으로 안내합니다. 같은 환불을 새로 다시 요청하지 않으며, 처음 요청한 건의 결과를 조회합니다.
4. 결제 취소가 실패하면 환불은 실패로 남고 운영 관리자가 확인합니다.
5. 반품 환불은 회수한 상품을 센터가 검수한 뒤에 시작합니다(PMart 반품·교환 업무 정책).

## 제6조 (취소 완료·재고 복귀와 환불의 구분)
1. 주문 취소 완료, 재고 복귀, 환불 완료는 각각 다른 사실입니다.
2. 센터의 출고 중지와 재고 복귀가 끝났더라도 결제 취소 성공 전에는 환불 완료로 안내하지 않습니다.
3. 상담이 끝났거나 고객이 만족도를 남겼다고 환불이 끝난 것은 아닙니다.

## 제7조 (직원의 환불 권한)
1. 백오피스에서 주문 상태를 "환불 완료"로 직접 바꾸거나 결제 취소를 따로 실행하는 기능은 두지 않습니다. 환불은 취소·결품·반품·오배송 처리 절차를 통해서만 실행됩니다.
2. 승인 없이 임의의 보상금을 지급하지 않습니다.
3. 운영 관리자는 기간별 환불 완료 금액을 취소·결품·반품·반품 회수비·기타로 나누어 조회할 수 있습니다. 날짜는 환불이 완료된 한국 날짜 기준이며 한 번에 93일까지 조회할 수 있습니다.
