# PMart 오배송 처리 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 상품이 주문 주소가 아닌 곳에 전달된 오배송을 확인하고, 귀책에 따라 고객에게 다시 배송·새 상품 발송·환불을 처리하는 기준을 정합니다. 회수 배송의 운영과 라이더 수행료는 PMart 배송 사고·도움요청·회수 운영 정책과 PMart 라이더 수행료 운영 정책을 따릅니다.

## 제2조 (오배송 확인)
1. 오배송은 다음 중 하나가 있을 때 확인된 것으로 봅니다.
   - 라이더가 다른 곳에 전달했다고 확인함
   - 배송 완료 사진의 위치가 주문 주소와 다름
   - 잘못 받은 사람이 연락함
2. 고객의 말만 있는 경우에는 오배송으로 바로 확정하지 않고, 문의로 접수해 담당 직원이 원래 주소, 전달 사진, 고객 진술을 확인해 판단합니다.
3. 라이더의 연락만으로 환불을 승인하지 않습니다.
4. 오배송 확인은 고객센터 상담원 또는 지원센터(라이더 운영)가 백오피스에 오배송 건으로 기록합니다. 오배송 건의 처리 기한은 고객센터·접수 건 처리 정책을 따릅니다.
5. "배송 완료인데 받지 못함"은 받은 상품의 반품으로 분류하지 않습니다.

## 제3조 (귀책 기록)
오배송을 기록할 때 귀책을 다음 중 하나로 정합니다.

| 귀책 | 예 |
|---|---|
| 고객 잘못 | 고객이 주소를 잘못 입력함 |
| 라이더 잘못 | 라이더가 다른 곳에 전달함 |
| 시스템 오류 | 지도·시스템 오류 |

## 제4조 (귀책별 처리)

| 귀책 | 조건·고객 선택 | 잘못 간 상품 | 고객 |
|---|---|---|---|
| 고객 잘못 | 실제 집이 전달 위치에서 200m 안 | 원래 라이더(어려우면 근처 다른 라이더)가 가져가 실제 집으로 다시 배송 | 추가 비용 없음 |
| 고객 잘못 | 200m 이상, 다시 배송 선택 | 고객이 앱에서 9,000원을 결제하면 근처 라이더가 실제 집으로 바로 배송 | 9,000원 |
| 고객 잘못 | 200m 이상, 회수 후 환불 선택 또는 30분 안에 결제하지 않음 | 회수해 센터로 반납 | 상품값 − 9,000원 환불 |
| 라이더 잘못 | 새 상품 발송 선택 | 회수해 센터로 반납 | 센터가 같은 상품을 새로 피킹·포장해 원래 주소로 보냄(비용 없음) |
| 라이더 잘못 | 환불 선택 | 회수해 센터로 반납 | 전 품목 환불 |
| 시스템 오류 | 라이더 잘못과 같음 | 라이더 잘못과 같음 | 라이더 잘못과 같음 |

1. 고객 잘못일 때 200m 이상 떨어진 경우의 다시 배송은 잘못 간 그 상품을 실제 집으로 옮기는 것이며, 센터에서 새로 피킹하지 않습니다.
2. 9,000원 결제 기한은 30분입니다. 기한 안에 결제하지 않거나 고객이 결제 대신 회수 후 환불을 고르면 회수 후 환불로 바뀝니다. 환불액은 상품값에서 9,000원을 뺀 금액이며 0원 아래로 내려가지 않고, 배달팁과 봉투값은 환불하지 않습니다.
3. 회수 후 환불로 바뀐 뒤 늦게 9,000원 결제가 승인되면 그 결제는 취소해 돌려줍니다.
4. 라이더 잘못과 시스템 오류는 고객이 새 상품 발송과 환불 중에서 고르고, 상담원이 고객의 선택을 기록합니다.
5. 새 상품을 보낼 때 센터에 재고가 모자란 품목은 그 품목만 부분 환불하며, 다른 상품으로 바꿔 보내지 않습니다.
6. 회수한 상품은 원래 고객에게 다시 보내지 않습니다. 신선·냉장·냉동 회수품은 폐기하고, 상온 미개봉품만 검수 뒤 재고로 되돌립니다.

## 제5조 (실제 집 주소의 기록)
1. 고객 잘못인 경우에만 상담원이 고객에게 받은 실제 집 주소를 기록합니다. 기록할 때 사유를 적으며, 누가 언제 입력했는지 남습니다.
2. 실제 집 주소를 기록해도 주문의 배송지는 바뀌지 않습니다. 결제 후 주소 변경 금지를 우회하는 새 주소 입력으로 쓰지 않습니다.
3. 실제 집과 전달 위치의 거리(200m 안·밖)는 시스템이 원래 라이더가 전달 완료를 누른 위치를 기준으로 계산합니다.

## 제6조 (중복 처리 금지)
같은 피해 수량을 다시 배송·새 상품 발송과 환불로 겹쳐 처리하지 않습니다. 이미 다른 사유로 환불된 수량은 다시 환불하지 않습니다.

## 제7조 (라이더 수행료와의 구분)
1. 오배송에 따른 원래 라이더의 수행료 처리는 PMart 라이더 수행료 운영 정책을 따릅니다. 고객센터 상담원은 라이더 수행료를 정하지 않고 확인한 사실만 기록합니다.
2. 고객 환불과 라이더 수행료 조정은 따로 처리합니다.
