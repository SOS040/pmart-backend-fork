# PMart 주문·클레임 상담 기록·안내 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 고객센터 상담원이 주문 취소·환불·반품·배송 문제를 상담할 때 무엇을 기록하고 고객에게 어떻게 결과를 안내하는지 정합니다. 상담 접수의 본인 확인 방법과 접수 건 처리는 PMart 고객센터·접수 건 처리 정책을 따릅니다.

## 제2조 (접수와 실행의 구분)
1. 상담 접수는 처리 명령이 아닙니다. 상담을 접수한 것만으로 취소·환불·회수가 실행되지 않으며, 실제 처리는 주문·배송·결제 처리 절차가 결과를 냅니다.
2. 상담원의 답변, 고객의 만족도 응답, 상담 종료는 취소·반품·환불 처리의 완료를 뜻하지 않습니다. 상담이 끝나도 진행 중인 처리는 계속 조회할 수 있습니다.
3. 같은 대상에 진행 중인 접수가 있으면 새로 만들지 않고 기존 접수에 이어서 기록합니다.
4. 한 상담에서 여러 주문을 다루면 주문마다 따로 연결하며, 한 주문의 증빙이나 환불을 다른 주문에 적용하지 않습니다.

## 제3조 ("완료" 안내 기준)
1. "완료"는 결과가 확정된 뒤에만 안내합니다.
   - 주문 취소: 출고 중지 확인과 결제 취소 성공이 모두 확인된 뒤
   - 환불: 결제사의 결제 취소 성공이 확인된 뒤
2. 취소·환불을 접수했을 때는 "요청이 접수되었고 결과는 앱 알림으로 안내된다"고 안내합니다.
3. 결과를 아직 모르면 "확인 중"으로 안내하며, 성공이나 실패를 미리 말하지 않습니다.

## 제4조 (반드시 기록할 것)

| 상황 | 기록할 내용 |
|---|---|
| 모든 취소 요청 | 취소 사유, 요청 시각, 주문 단계 |
| 주문자 본인이 아닌 사람과의 상담 | 주문자와의 관계 |
| 배송 완료 미수령·오배송 | 원래 주소 확인 결과, 전달 사진 확인, 라이더 확인 결과(귀책 인정 여부, 다시 전달할 수 있는지), 잘못 간 주소 |
| 개인정보를 다른 사람에게 전달 | 누구에게 무엇을 전달하는지, 동의 여부 |
| 누락·다른 상품·파손 | 상품과 수량, 사진 여부, 고객 선택(교환/환불), 회수 필요 여부 |
| 반품·교환 | 사유, 받은 시각, 비용 안내 여부 |

고객 동의는 따로 기록합니다. 예를 들어 주소를 라이더에게 알리는 데 대한 동의, 교환·환불 선택이 이에 해당합니다.

## 제5조 (상담 분류)
고객 문의는 다음과 같이 나눕니다.

| 분류 | 예 | 관련 정책 |
|---|---|---|
| 지연 | 라이더 배정 지연, 배송 중 지연 | PMart 배송 문제 상담 정책 |
| 오배송 | 다른 주문 포장을 받음, 주문하지 않은 사람이 받음 | PMart 오배송 처리 정책 |
| 미수령 | 배송 완료인데 받지 못함 | PMart 배송 문제 상담 정책 |
| 누락 | 포장에 상품이 빠짐 | PMart 배송 문제 상담 정책 |
| 파손 | 깨짐, 샘, 포장 불량 | PMart 배송 문제 상담 정책 |
| 품질 | 신선도, 이물 등 | PMart 배송 문제 상담 정책 |
| 기타 | 취소, 반품, 계정 등 | PMart 주문 취소 정책, PMart 반품·교환 업무 정책 |

## 제6조 (고객 알림)
1. 주문 취소, 결품 부분 취소, 환불, 반품 진행 결과는 고객에게 앱 알림으로 자동 안내됩니다.
2. 취소·환불 결과 같은 거래 알림은 고객이 끌 수 없습니다.
3. 휴대폰 알림 전송에 실패해도 다시 보내지 않으며, 같은 알림은 앱 알림함에 남습니다. 알림이 실패했다고 주문·결제·취소 처리를 되돌리거나 다시 하지 않습니다.
