# PMart 결제·주문 확정·주문 변경 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 직원이 고객의 결제 결과, 주문 확정, 주문 진행 상태와 결제 후 주문 변경 문의에 답할 때 따르는 기준을 정합니다.

## 제2조 (결제 수단)
1. 결제는 토스페이먼츠 주문서형 결제만 씁니다.
2. 결제 화면을 닫거나 앱으로 돌아온 것, 고객 앱에 성공 화면이 보인 것만으로는 결제가 승인되었다고 보지 않습니다.

## 제3조 (결제 전 재고 확보)
1. 결제를 시작하기 전에 주문의 모든 상품 재고와 필요한 배송 시간대를 먼저 확보합니다. 하나라도 확보하지 못하면 결제로 넘어가지 않고, 이미 확보한 것은 풀어 줍니다.
2. 마지막 남은 재고 하나를 두 주문이 함께 고르면 재고를 먼저 확보한 주문만 결제로 넘어갑니다. 결제를 먼저 끝낸 순서로 바꾸지 않습니다.
3. 장바구니에 담는 것만으로는 재고를 확보하지 않습니다.

## 제4조 (주문 확정)
1. 결제사의 승인이 확인되고 승인 금액이 주문 결제 금액과 같아야 주문이 확정됩니다.
2. 승인 금액과 주문 금액이 다르면 주문을 확정하지 않고 출고하지 않으며, 대사(맞춰 보기) 대상으로 남깁니다.
3. 승인은 되었지만 주문 확정에 실패하면 새 주문이나 새 결제를 만들지 않고, 같은 결제로 주문을 되살리거나 그 결제를 승인 취소합니다.
4. 주문 확정은 상품 준비나 라이더 인계가 끝났다는 뜻이 아닙니다.

## 제5조 (결제 결과를 아직 모를 때)
1. 결제사 응답이 늦거나 끊겨 결과를 모르면 결제 실패로 보지 않고 "결제 확인 중"으로 둡니다. 이때 새 결제를 만들지 않고 처음 결제 건을 다시 조회합니다.
2. 재고 확보 10분이 지나도 결제 결과를 모르면 확보한 재고와 시간대를 풀지 않고 결제 확인을 기다리는 상태로 붙잡아 둡니다.
3. 그 뒤 1분 간격으로 최대 5번 다시 조회하고, 그래도 모르면 담당자에게 넘긴 뒤 15분 간격으로 계속 조회합니다.
4. 시간이 지났다는 이유만으로 확보를 풀거나 주문을 끝내지 않습니다. 사람이 끝낼 때도 결제사 원거래의 미승인·실패·취소 또는 주문을 되살릴 수 있다는 근거를 확인해야 합니다.
5. 재고 확보가 끝난 뒤 늦게 승인이 확인되면 주문을 되살릴 수 있는지 다시 확인하고, 되살릴 수 없으면 그 결제를 승인 취소합니다. 승인 취소가 확인되기 전에는 그 재고를 다시 팔지 않습니다.
6. 결제 확인 중인 고객에게는 다시 결제하라고 안내하지 않습니다.

## 제6조 (주문 진행 상태)
고객 화면의 주문 상태는 다음 뜻으로 안내합니다.

| 고객 화면 | 뜻 | 뜻하지 않는 것 |
|---|---|---|
| 주문 확인 | 결제가 확인되어 주문이 확정됨 | 상품 준비 시작, 라이더 배정 |
| 상품 준비 중 | 센터가 실제로 피킹을 시작함 | 포장 완료, 라이더 인계 |
| 배송 중 | 포장이 라이더에게 인계되어 출발함 | 고객 수령 |
| 일부 전달 | 나눠 배송한 것 중 일부가 전달됨 | 나머지 배송의 취소 |
| 배송 완료 | 모든 배송이 실제로 전달됨 | 반품·환불 처리의 종료 |

1. 시간이 지났거나 라이더가 도착 지점에 왔다는 것만으로 배송 완료로 바꾸지 않습니다. 고객 전달이 확인되어야 완료입니다.
2. 남은 상품을 취소·환불로 끝낸 주문은 실제 전달분과 취소분을 나눠 안내하며, "모두 받음"으로 안내하지 않습니다.
3. 주문 상세의 상품명·가격·배송지는 주문 당시 값입니다. 상품 정보나 고객 기본 배송지가 나중에 바뀌어도 주문 내용은 바뀌지 않습니다.

## 제7조 (결제 후 주소·연락처·요청 사항)
1. 결제한 뒤에는 배송지 주소, 연락처, 요청 사항을 바꿀 수 없습니다. 고객센터도 바꿔 주지 않습니다.
2. 다른 주소로 받아야 하는 고객에게는 취소할 수 있는 단계인지 확인한 뒤(PMart 주문 취소 정책) 취소하고 새 주소로 다시 주문하도록 안내합니다.
3. 배송 문제를 확인할 때는 주문 당시 주소를 기준으로 봅니다.

## 제8조 (예약배달 시간 변경)
1. 예약배달 주문은 상품 준비가 시작되기 전까지 고객이 앱에서 예약 시간만 바꿀 수 있습니다. 배송 방식, 주소, 연락처, 요청 사항은 바꿀 수 없습니다.
2. 지금과 같은 시간대로는 바꿀 수 없고, 한 주문에 진행 중인 시간 변경은 하나뿐입니다.
3. 새 시간대의 정원, 센터 작업 여력, 재고와 소비기한을 다시 확인해 모두 맞아야 바뀝니다.
4. 상품 준비 시작과 시간 변경이 겹치면 먼저 확정된 쪽만 유효합니다. 준비가 먼저 시작되었으면 시간 변경은 거절됩니다.
5. 변경에 실패하면 기존 시간·재고·금액이 그대로 유지됩니다. 시간 변경으로 새 결제를 하지 않습니다.
6. 결과를 아직 모르면 "예약 시간 변경 확인 중"으로 안내하고, 새 시간과 이전 시간을 둘 다 확정으로 안내하지 않습니다.

## 제9조 (센터가 주문 작업을 받지 못할 때)
1. 결제 뒤 센터가 재고 불일치나 운영 중단으로 주문 작업을 받지 못하면, 같은 센터에서 재고를 되찾을 수 있는지 처음 거절부터 10분 동안 1분마다 확인하고 되찾으면 작업을 다시 보냅니다. 다시 보내는 것은 한 주문에 최대 2번입니다.
2. 그 밖의 사유로 거절되거나, 되찾지 못하거나, 횟수를 넘기거나, 배송 시간대가 시작되면 주문 전체를 자동으로 취소하고 결제 금액 전액을 환불합니다.
3. 다른 센터로 옮겨 보내지 않습니다.
