# PMart 주문 취소 업무 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 고객 요청에 따른 주문 취소와 회사 사유에 따른 주문 취소의 가능 시점, 접수 방법, 처리 단계와 완료 기준을 정합니다.

## 제2조 (취소 가능 시점)
주문 취소는 주문 단계에 따라 다음과 같이 처리합니다.

| 주문 단계 | 고객 요청 취소 | 처리 |
|---|---|---|
| 결제 완료 ~ 상품 준비 전 | 가능 | 고객이 앱 주문 내역에서 직접 취소하거나, 고객센터가 대신 접수 |
| 상품 준비 시작 뒤 ~ 라이더 인계 전 | 불가 | 고객 앱·고객센터 모두 받지 않음. 받은 뒤 반품으로 안내 |
| 라이더 인계 뒤(픽업·배달 시작 뒤) | 불가 | 취소가 아니라 고객센터 경유 회수·반품(PMart 반품·교환 업무 정책) |

1. "상품 준비 시작"은 센터가 그 주문의 첫 피킹을 시작한 때입니다. 작업자가 배정만 된 주문은 아직 상품 준비 전입니다.
2. 예약배달 시간 변경이 가능한 시점을 일반 취소 마감으로 바꿔 쓰지 않습니다. 둘 다 상품 준비 시작 전까지이지만 별개의 규칙입니다.

## 제3조 (고객센터 대리 취소)
1. 고객센터 상담원과 운영 관리자는 고객 요청에 따라 상품 준비 전인 주문의 취소를 대신 접수할 수 있습니다.
2. 대리 취소도 고객 앱 취소와 범위가 같으며, 주문 전체만 취소할 수 있습니다.
3. 접수할 때는 고객 본인 확인 방법과 취소 사유를 반드시 남겨야 합니다. 접수한 직원, 본인 확인 방법, 연결된 상담 건이 취소 기록에 함께 남고, 고객은 이 취소를 앱에서 볼 수 있습니다.
4. 상품 준비가 시작된 주문은 대리 취소가 거절됩니다. 상담원은 "받으신 뒤 반품"으로 안내합니다.
5. 같은 주문에 진행 중인 취소가 있으면 새로 접수하지 않고 기존 취소의 진행 상황을 안내합니다.

## 제4조 (부분 취소)
1. 고객이 결제한 뒤 일부 상품만 골라 취소하는 것은 지원하지 않습니다. 고객 앱과 고객센터 모두 주문 전체 취소만 받습니다.
2. 일부 상품만 결제가 취소되는 경우는 결품(PMart 결품·부분 취소 정책)과 반품(PMart 반품·교환 업무 정책)뿐입니다.
3. 일부만 필요 없는 고객에게는 받은 뒤 반품 기준에 맞으면 반품으로 안내합니다.

## 제5조 (회사 사유 취소)
고객 요청이 아닌 주문 취소는 다음과 같습니다. 모두 주문 전체 취소이며, 결제 금액 전액(봉투값·배달팁 포함)을 환불합니다.

| 사유 | 누가 | 가능 시점 |
|---|---|---|
| 결품으로 남은 상품이 하나도 없음 | 시스템 자동 | 라이더 인계 전 |
| 센터가 주문 작업을 받지 못함 | 시스템 자동(PMart 결제·주문 확정·주문 변경 정책 제9조) | 상품 준비 전 |
| 배차 불가(라이더를 끝내 찾지 못함) | 그 센터의 센터 관리자, 고객센터 상담원, 운영 관리자. 또는 시스템 자동 | 상품 준비 뒤라도 라이더 인계 전 |
| 관리자 판단(설비 고장, 주문 오류 등 회사 사정) | 그 센터의 센터 관리자, 운영 관리자(고객센터 상담원은 불가) | 상품 준비 뒤라도 라이더 인계 전 |

1. 배차 불가 취소와 관리자 판단 취소는 회사 사유이므로 고객 본인 확인을 하지 않습니다. 관리자 판단 취소는 사유 메모를 반드시 남깁니다(MFC 센터 관리자 작업 조작·운영 제한 정책).
2. 시스템이 배차 불가로 자동 취소하는 조건은 PMart 배차 운영 정책을 따릅니다. 자동 취소가 거절되면(이미 인계되었거나 취소된 경우 등) 다시 시도하지 않으며, 직원이 확인해 처리합니다.
3. 회사 사유 취소는 고객 요청 취소로 쓸 수 없습니다. 고객이 원해서 취소하는 경우에는 관리자 판단이나 배차 불가 사유를 쓰지 않습니다.
4. 라이더에게 인계된 뒤에는 회사 사유로도 취소하지 않으며 반품으로 처리합니다.

## 제6조 (취소 처리 단계)
1. 취소 버튼을 누르거나 상담원이 접수한 것은 "접수"이며 취소 완료가 아닙니다.
2. 취소 요청은 다음 단계로 진행되며, 주문의 상품 준비·배송 상태와 따로 표시됩니다.
   - 접수
   - 출고 중지 확인 중 또는 인계 확인 중
   - 취소 처리 중(재고 해제, 결제 취소)
   - 취소 완료 또는 취소 불가
3. 취소 접수와 함께 센터에 작업 중지가 자동으로 요청됩니다.
4. 피킹을 시작한 뒤 회사 사유로 취소된 주문은 센터가 이미 집거나 포장한 상품을 선반으로 되돌린 뒤에 다시 팔 수 있게 됩니다.

## 제7조 (취소와 라이더 인계가 겹칠 때)
1. 취소 접수 시각만으로 라이더 인계보다 먼저라고 보지 않습니다. 같은 포장에 대해 센터가 먼저 확정한 결과(출고 중지 또는 인계)가 유효합니다.
2. 라이더 인계가 진행 중이면 취소는 "인계 확인 중"으로 두고 결과를 기다립니다. 이때 취소를 다시 접수하지 않습니다.
3. 출고 중지가 먼저 확정된 포장은 그 뒤 라이더가 스캔해도 인계되지 않습니다.
4. 이미 인계된 포장이 하나라도 있으면 주문 전체 취소는 거절되고, 인계된 상품은 회수·반품으로 처리합니다.
5. 현장 응답을 아직 모르면 "확인 중"으로 두고 고객에게 완료로 안내하지 않습니다.

## 제8조 (취소 완료와 환불)
1. 취소 완료는 출고 중지 확인과 결제 취소 성공이 모두 확인된 뒤입니다. 재고 복귀가 끝나도 결제 취소 성공 전에는 환불 완료로 안내하지 않습니다.
2. 주문 전체 취소의 환불액은 결제 금액 전액(상품액, 봉투값, 배달팁)입니다. 앞서 결품으로 일부 환불된 금액이 있으면 그만큼 뺍니다.
3. 결제 뒤 출고 전에 주문 전체가 취소되면 그 주문은 첫 구매 자격을 쓰지 않은 것으로 되돌립니다.
4. 환불의 진행 단계와 완료 기준은 PMart 환불 정책을 따릅니다.
