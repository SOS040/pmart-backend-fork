# PMart 배송 문제 상담 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 고객센터 상담원이 배송 지연, 미수령, 받은 상품의 누락·다른 상품, 파손·품질 문제 상담을 처리하는 기준을 정합니다. 오배송은 PMart 오배송 처리 정책, 반품·교환 기한과 비용은 PMart 반품·교환 업무 정책을 따릅니다.

## 제2조 (공통 원칙)
1. 배송 지연이나 전달 실패만으로 자동 환불하지 않습니다. 고객 연락, 보관 가능 여부, 후속 조치·회수 여부를 확인해 판단합니다.
2. 고객이 받았다는 사실 없이 시간이 지났다는 이유로 배송 완료로 처리하지 않습니다.
3. 배송 문제는 주문 당시 주소를 기준으로 확인합니다.
4. 같은 피해 수량은 사유를 바꿔 다시 신고해도 한 번만 환불합니다. 같은 대상의 접수가 이미 있으면 새로 만들지 않고 기존 접수와 처리 내역을 먼저 안내합니다.
5. 고객 환불과 라이더 수행료 조정은 같은 일이 아니며 따로 처리합니다.
6. 귀책 조사가 끝나지 않았더라도 고객 대응은 따로 진행합니다. 귀책이 정해지지 않은 상태를 환불 완료로 안내하지 않습니다.

## 제3조 (배송 지연)
1. 고객은 주문이 확정된 뒤부터 배송 완료 전까지 고객 앱에서 배송 지연을 신고할 수 있습니다. 지연 신고는 배송 문의로 접수되어 고객센터 상담원이 답합니다.
2. 배송 완료 뒤에 받지 못했다는 신고는 지연이 아니라 미수령으로 받습니다.
3. 라이더 배정이 늦어지는 배송은 배차 지연 접수 건으로 모이며, 처리는 PMart 고객센터·접수 건 처리 정책과 PMart 도착 시간대·배송 약속 정책을 따릅니다.
4. 라이더가 끝내 배정되지 않은 주문의 취소는 PMart 주문 취소 정책의 배차 불가 취소를 따릅니다.
5. 지연에 대한 쿠폰·적립금 보상은 없으며, 보상금은 PMart 환불 정책 제7조를 따릅니다.

## 제4조 (배송 완료인데 받지 못함)
1. 고객은 고객 앱에서 배송 완료된 주문을 받지 못했다고 신고할 수 있으며, 배송 문의로 접수됩니다.
2. 상담원은 원래 주소, 배송 완료 사진, 고객 진술을 확인합니다. 오배송 확인 조건에 해당하면 PMart 오배송 처리 정책에 따라 처리합니다.
3. 미수령은 받은 상품의 반품으로 분류하지 않습니다.
4. 사진 등 증빙을 낼 수 없는 고객에게는 다른 방법으로 확인할 수 있게 하며, 증빙이 없다는 이유만으로 바로 거절하지 않습니다.

## 제5조 (받은 상품의 누락·다른 상품)
1. 결품으로 이미 부분 취소된 상품인지 먼저 주문 상세에서 확인합니다. 결품이면 PMart 결품·부분 취소 정책을 따릅니다.
2. 포장 라벨이 다른 주문이면 포장 자체가 잘못 간 것이므로 PMart 오배송 처리 정책을 따릅니다.
3. 포장 안의 상품이 빠졌거나 다른 상품·규격이 들어 있으면 고객 신고·사진과 피킹·포장·인계·배송 이력을 확인해 센터(포장) 쪽 문제인지 배송 쪽 문제인지 판단합니다.
4. 고객에게 교환(같은 상품으로 다시 받기)과 환불 중 원하는 방법을 반드시 확인하고, 재고와 고객 동의를 확인한 뒤 처리합니다. 필요하면 회수를 요청합니다.
5. 환불은 해당 상품·수량만 부분 결제 취소로 합니다.
6. 오배송·하자로 인한 교환은 받은 뒤 3개월 이내 또는 안 날부터 30일 이내면 받으며, 고객의 교환 배달비는 0원입니다.

## 제6조 (파손·포장 불량·품질 문제)
문제를 발견한 때에 따라 다음과 같이 처리합니다.

| 발견한 때 | 처리 |
|---|---|
| 라이더가 가져가기 전 | 센터 직원에게 알려 인계를 멈추고, 다시 포장할지 환불할지 정함 |
| 라이더가 가져간 뒤(배송 중) | 라이더 도움요청으로 사진·시각·상품 위치를 남기고, 회수·폐기·재발송을 정함(PMart 배송 사고·도움요청·회수 운영 정책) |
| 고객이 받은 뒤 | 고객 신고·사진과 피킹·포장·인계·배송 이력을 확인해 포장 쪽과 배송 쪽 귀책을 판단하고, 환불·교환·재발송과 필요하면 회수를 정함 |

1. 일부 상품만 문제이면 그 상품·수량만 고객과 협의합니다.
2. 신선식품(냉장·냉동)은 받은 뒤 24시간 이내, 그 밖의 상품은 7일 이내에 접수합니다. 상품 하자의 교환은 3개월 또는 안 날부터 30일 특례를 적용합니다.
3. 상품 문제로 인한 교환·반품은 고객의 배달비·회수비가 없습니다.
4. 신선·냉장·냉동 회수품은 다시 팔지 않습니다.
5. 추가 보상은 따로 승인을 받아야 합니다.

## 제7조 (회수 없이 처리)
1. 받은 상품 문제의 처리는 회수가 기본입니다.
2. 회수 없이 환불·교환하려면 승인 사유와 증빙을 남겨야 하며, 승인 없이 회수 단계를 생략하지 않습니다.
