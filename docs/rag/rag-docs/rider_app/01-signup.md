# PMart 라이더 가입 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 PMart(이하 "회사")의 라이더 앱(이하 "서비스")에 라이더로 가입하고 로그인하는 기준과 절차를 정합니다.

## 제2조 (정의)
1. "라이더"란 이 정책에 따라 가입해 회사가 제안하는 배송을 수행하는 사람을 말합니다.
2. "배달 수단"이란 라이더가 배송에 쓰는 도보, 자전거, 전기자전거, 전동킥보드, 오토바이, 자동차를 말합니다.
3. "정산 계좌"란 회사가 수행료를 지급하는 라이더 명의의 계좌를 말합니다.

## 제3조 (로그인)
1. 라이더는 Google·카카오·네이버 계정으로 로그인합니다.
2. 처음 로그인하면 가입 절차가 시작되며, 제4조의 정보를 모두 등록해야 가입이 완료됩니다.

## 제4조 (가입 때 등록하는 정보)
1. 라이더는 가입할 때 다음 정보를 등록합니다.
   - 이름, 휴대폰 번호(제5조의 번호 확인)
   - 거주지 주소
   - 정산 계좌(은행과 계좌번호)
   - 배달 수단과 배달할 지역
   - 운전면허 번호(오토바이·자동차·전동킥보드로 가입하는 경우)
2. 거주지 주소는 회사가 실제 주소인지 확인하며, 확인되지 않는 주소로는 가입할 수 없습니다.
3. 정산 계좌는 은행을 목록에서 고르며, 다른 라이더가 이미 등록한 계좌로는 가입할 수 없습니다.

## 제5조 (휴대폰 번호 확인)
1. 라이더가 휴대폰 번호를 입력하면 회사는 확인 숫자와 문자를 보낼 번호를 앱에 표시합니다.
2. 라이더는 표시된 번호로 확인 숫자를 직접 문자로 보낸 뒤 앱에서 확인을 요청합니다. 회사는 라이더에게 확인 문자를 보내지 않습니다.
3. 휴대폰 번호 하나로는 라이더 한 명만 가입할 수 있습니다. 이미 가입한 번호면 그 계정의 로그인 방법을 안내합니다.
4. 탈퇴한 라이더의 휴대폰 번호로는 탈퇴 후 30일 동안 다시 가입할 수 없습니다.

## 제6조 (배달 수단과 운전면허)
1. 오토바이·자동차·전동킥보드로 배송하려면 운전면허 번호를 등록해야 합니다.
2. 다른 라이더가 이미 등록한 운전면허 번호로는 가입하거나 수단을 바꿀 수 없습니다.
3. 회사는 운전면허 번호를 원래 값 그대로 저장하지 않으며, 앱에는 일부를 가려 표시합니다.
4. 가입한 뒤 배달 수단을 오토바이·자동차·전동킥보드로 바꿀 때 등록된 면허가 없으면 면허 번호를 함께 등록해야 합니다.

## 제7조 (가입 정보의 변경)
1. 라이더는 앱에서 휴대폰 번호, 거주지, 정산 계좌, 배달 수단과 지역을 바꿀 수 있습니다.
2. 바꾸는 정보에도 제4조부터 제6조까지의 기준이 같게 적용됩니다.
