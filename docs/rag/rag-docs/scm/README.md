# SCM(센터 간 상품 공급) 사내 정책 문서 — RAG 원고 (초안)

본사 공급 담당·MFC 센터 관리자·운영자가 센터 간 상품 공급(중앙 물류센터 → MFC 센터)에 대해 물을 때 AI 가 근거로 쓸 **직원용 사내 정책 문서** 초안입니다. 고객·라이더에게 공개하는 문서가 아닙니다. MFC 센터 관리자의 공급 요청 방법은 `mfc/03-inbound-putaway-move.md` 제11조, 센터 초기 재고 반입 승인은 `backoffice/03-approval.md`, 이관 출발·미출발 잔량 정리는 `cdc_wms/03-replenishment-transfer-departure.md` 에 이미 있어 다시 적지 않고 참조만 합니다.

## 넣지 않은 것
- `docs/business/SCM-business-logic.md` 전체: 문서 상태가 승인 전(운영 정책·연계 계약 승인 대기)이고, 공급 흐름(보충 계산·배분·공급 승인·실행 추적)은 구현되지 않았다. 예: 보충 필요량 계산식·안전량·운송 배수, 센터별 배분 우선순위, 공급 승인선·부분 승인·추가 승인(공급가능량 50% 초과 조건), 일반 6시간·긴급 2시간 기한, 미출발 잔량 정리, 부분 수령·운송 손실 승인, 운영 화면·지표, 수용 검증 시나리오.
- `docs/business/flows/replenishment-transfer.md`(v0.1): 구현 기록이 없어 단계별 처리·변경 가능 시점 표를 넣지 않음.
- `contracts/states/scm-states.md`: 상태 이름이 명칭 제안이고 구현 전.
- 개발·연계 내용: 멱등·응답 불명 복구, 데이터 계보, 전달 상태.
