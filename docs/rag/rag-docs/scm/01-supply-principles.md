# PMart 센터 간 상품 공급 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 중앙 물류센터(CDC)에서 각 MFC 센터로 상품을 공급할 때 지켜야 할 기본 원칙과 단계별 책임을 정합니다.

## 제2조 (공급 경로와 단계)
1. 센터 간 공급은 중앙 물류센터에서 MFC 센터로만 합니다. 중앙 물류센터는 칠곡 1곳입니다.
2. 센터 간 공급은 다음 순서로 진행합니다.
   - MFC 센터의 공급 요청
   - 본사 공급 담당의 공급 승인(이관)
   - 중앙 물류센터의 재고 확보·피킹·검품·상차
   - 간선 운송(차량 편성과 실제 출발)
   - MFC 센터의 실제 수령·검수·적치
   - 중앙 물류센터의 운송 중 수량 대사
3. 각 단계의 결과는 그 단계를 맡은 곳이 확정합니다. 본사 공급 담당은 재고 수량, 운송 편성, 센터 현장 수령을 직접 바꾸지 않습니다.

## 제3조 (한 요청, 한 이관, 한 출발)
1. 공급 요청 1건은 승인된 이관 1건으로, 이관 1건은 실제 출발 1회로 보냅니다.
2. 같은 이관을 나누어 나중에 다시 출발시키지 않습니다. 출발하지 않은 수량의 처리는 CDC 선반 보충·MFC 이관 출발 정책을 따릅니다.

## 제4조 (단계별 수량은 서로 다릅니다)
1. 승인한 수량, 중앙 물류센터가 실제로 확보한 수량, 실제로 출발한 수량, MFC 센터가 수령한 수량은 서로 다른 결과입니다.
2. 승인되었다고 재고가 확보된 것으로, 확보되었다고 출발한 것으로, 출발했다고 수령된 것으로 보지 않습니다.

## 제5조 (출발 뒤 변경 금지)
1. 차량이 실제로 출발한 뒤에는 목적지 센터를 바꾸지 않습니다.
2. 출발한 상품은 원래 목적지 센터에 인계합니다. 출발 뒤 이관 취소 요청, 다른 센터의 박스가 섞여 실린 경우, 빈 롤테이너 회수는 PMart 간선 운송 도착·인계·예외 처리 정책 제5조·제8조를 따릅니다.

## 제6조 (고객 판매와의 관계)
1. 고객 주문은 배송지를 담당하는 MFC 센터에 지금 있는 상품으로만 받습니다.
2. 공급이 예정되어 있다는 이유로 아직 들어오지 않은 상품을 미리 판매하지 않습니다.

## 제7조 (다루지 않는 업무)
다음 업무는 이 정책의 대상이 아니며 지금은 운영하지 않습니다.
1. 공급업체 구매·발주와 중앙 물류센터 외부 입고
2. MFC 센터 사이의 재고 이관

## 제8조 (관련 정책)
1. MFC 센터 관리자의 공급 요청 방법(중복 요청 금지, 접수 전까지만 수정·철회)은 MFC 입고·품질검사·적치·재고 이동 정책 제11조를 따릅니다.
2. 센터 초기 재고 반입 승인은 변경 요청·승인 정책을 따릅니다.
3. 중앙 물류센터의 이관 출발과 출발하지 않은 잔량 정리는 CDC 선반 보충·MFC 이관 출발 정책을 따릅니다.
4. 중앙 물류센터에서 MFC 센터까지의 간선 운송은 간선 운송 관련 정책(이관요청서 접수·배차·상차·출차·인계·마감)을 따릅니다.
