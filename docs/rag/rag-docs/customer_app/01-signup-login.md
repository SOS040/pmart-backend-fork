# PMart 회원 가입·로그인 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 PMart(이하 "회사")가 제공하는 PMart 앱(이하 "서비스")의 회원 가입, 로그인, 휴대폰 번호 확인에 관한 기준과 절차를 정합니다.

## 제2조 (정의)
1. "회원"이란 이 정책에 따라 가입을 마치고 서비스를 이용하는 사람을 말합니다.
2. "비회원"이란 로그인하지 않고 상품을 둘러보거나 장바구니를 쓰는 사람을 말합니다.
3. "소셜 계정"이란 회원이 로그인에 쓰는 Google·카카오·네이버 계정을 말합니다.
4. "휴대폰 번호 확인"이란 회원이 회사가 알려 준 번호로 확인 숫자를 직접 문자로 보내 번호의 주인임을 확인하는 절차를 말합니다.

## 제3조 (로그인 방법)
1. 회원은 Google·카카오·네이버 소셜 계정으로 로그인합니다.
2. 처음 로그인하면 가입 절차가 시작되며, 제4조의 절차를 모두 마쳐야 가입이 완료됩니다.
3. 로그인 상태는 서비스를 이용하는 동안 유지되며, 30일 동안 이용하지 않으면 다시 로그인해야 합니다.
4. 로그인에 여러 번 실패하면 그 기기에서 일정 시간 로그인이 제한될 수 있습니다.

## 제4조 (가입 절차)
1. 가입은 다음 순서로 이루어집니다.
   - 약관 동의: 필수 항목(이용약관, 개인정보 수집·이용, 만 14세 이상)과 선택 항목(마케팅 정보 수신)
   - 휴대폰 번호 확인
2. 선택 항목에 동의하지 않아도 가입과 주문에 제한이 없습니다.
3. 위치기반서비스 이용약관은 현재 위치로 주소를 찾는 기능을 이용할 때에만 따로 동의를 받습니다.
4. 만 14세 미만은 가입할 수 없습니다.

## 제5조 (가입을 마치지 않은 경우)
1. 가입 절차를 마치지 않고 서비스를 나간 경우, 다음에 같은 소셜 계정으로 로그인하면 약관 동의부터 다시 진행합니다.
2. 이때 이전에 고른 선택 항목도 다시 선택해야 하며, 새로 고른 내용이 적용됩니다.

## 제6조 (휴대폰 번호 확인)
1. 회원이 휴대폰 번호를 입력하면 회사는 확인 숫자 6자리와 문자를 보낼 번호를 앱에 표시합니다.
2. 회원은 표시된 번호로 확인 숫자를 직접 문자로 보낸 뒤 앱에서 확인을 요청합니다. 회사는 회원에게 확인 문자를 보내지 않습니다.
3. 확인 숫자는 표시된 때부터 10분 동안 유효하며, 시간이 지나면 새로 받아야 합니다.
4. 확인 요청 횟수와 하루에 새로 받을 수 있는 횟수에는 제한이 있습니다.
5. 문자 발송 요금은 회원이 이용하는 통신사 요금제에 따릅니다.
6. 휴대폰 번호 확인은 번호의 주인인지를 확인하는 절차이며, 이름이나 나이를 확인하는 본인인증이 아닙니다.

## 제7조 (한 번호 한 계정)
1. 휴대폰 번호 하나로는 한 계정만 가입할 수 있습니다.
2. 확인한 번호로 이미 가입한 계정이 있으면, 회사는 그 계정의 로그인 방법(Google·카카오·네이버), 가입일, 일부를 가린 이메일을 안내하며 새 가입은 진행하지 않습니다.
3. 탈퇴한 회원의 휴대폰 번호로는 탈퇴 후 30일 동안 다시 가입할 수 없습니다.

## 제8조 (비회원 이용)
1. 비회원은 상품을 둘러보고 장바구니에 담을 수 있습니다.
2. 주문·결제·찜은 회원만 이용할 수 있습니다.
3. 비회원이 로그인하면 비회원 때 담은 장바구니가 회원 장바구니와 합쳐지며, 가격과 재고는 다시 확인합니다.

## 제9조 (문의)
로그인이나 가입이 되지 않는 경우 잠시 뒤 다시 시도하고, 계속되면 앱의 고객센터로 문의합니다.
