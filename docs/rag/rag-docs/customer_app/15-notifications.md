# PMart 앱 알림 안내

시행일: 2026년 11월 20일

## 제1조 (목적)
이 안내는 PMart(이하 "회사")가 회원에게 보내는 주문·배송·취소·환불·고객센터 답변 알림의 종류와 받는 방법을 정합니다.

## 제2조 (앱 알림함)
1. 회사는 다음 일이 생기면 앱 알림함에 알림을 남깁니다.
   - 주문 확정
   - 상품 준비 시작
   - 배송 출발
   - 배송 완료
   - 주문 취소(품절로 주문 전체가 취소된 경우 포함)
   - 품절로 일부 상품이 취소된 경우
   - 환불 결과
   - 고객센터 문의 답변
   - 배차·배송이 늦어지는 경우
   - 배송 완료 뒤 리뷰 작성 요청
   - 쿠폰이 쿠폰함에 들어온 경우(배달할 라이더를 구하지 못해 취소된 주문의 보상 쿠폰 포함)
2. 주문을 나눠 보내는 경우 배송마다 출발·완료 알림을 보냅니다.
3. 이 알림은 거래에 필요한 안내이므로 회원이 끌 수 없습니다. 마케팅 정보 수신 동의와의 관계는 「PMart 약관 동의·개인정보 이용 안내」 제3조를 따릅니다.

## 제3조 (취소·환불 알림)
1. 주문 취소나 품절 취소 알림을 보낼 때 환불이 아직 끝나지 않았으면, 환불 결과가 나오면 다시 알려 드린다고 안내합니다.
2. 환불 완료 알림은 결제사에서 환불 결과를 확인한 뒤에만 보냅니다.

## 제4조 (휴대폰 알림)
1. 회사는 다음 알림을 앱 알림함과 함께 휴대폰 알림으로도 보냅니다.
   - 상품 준비 시작
   - 배송 출발
   - 주문하신 곳으로 가는 중·곧 도착
   - 배송 완료
   - 배송 완료 뒤 리뷰 작성 요청
   - 품절로 일부 상품이 취소된 경우
   - 주문 취소
   - 환불 완료·환불이 늦어지는 경우
   - 배차가 늦어지는 경우
   - 배송 중 사고·파손으로 새 상품을 다시 보내는 경우
   - 오배송 상품을 다시 배송하기 위한 추가 결제가 필요한 경우(「PMart 미수령·오배송 처리 안내」 제5조)
2. 그 밖의 알림은 앱 알림함에서만 확인할 수 있습니다.
3. 휴대폰 알림은 회원이 로그인한 기기로 보내며, 로그아웃한 기기로는 보내지 않습니다.
4. 휴대폰 알림의 제목과 내용은 앱 알림함과 같으며, 개인정보를 담지 않습니다.
