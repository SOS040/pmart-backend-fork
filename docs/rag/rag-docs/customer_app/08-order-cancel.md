# PMart 주문 취소 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 PMart(이하 "회사") 회원의 주문 취소 가능 시점, 취소 절차, 회사 사정에 따른 취소에 관한 기준을 정합니다.

## 제2조 (취소할 수 있는 시점)
1. 회원은 주문의 상품 준비가 시작되기 전까지 앱의 주문 내역에서 직접 주문을 취소할 수 있습니다.
2. 상품 준비가 시작된 뒤에는 앱과 고객센터 모두에서 주문을 취소할 수 없습니다. 상품을 받은 뒤 반품으로 도와드립니다.
3. 이미 라이더에게 전달되어 출발한 상품도 주문 취소 대신 상품을 받은 뒤 반품으로 도와드립니다.
4. 반품 기준은 「PMart 반품·교환 정책」을 따릅니다.

## 제3조 (취소 절차)
1. 취소 버튼을 누르면 "취소 요청"이 접수됩니다. 센터에서 상품 준비를 멈추고 결제 취소가 끝나야 "취소 완료"가 됩니다.
2. 진행 단계는 주문 상세에서 확인할 수 있습니다: 취소 요청 → 확인 중 → 취소 처리 중 → 취소 완료(또는 취소 불가).
3. 결과는 앱 알림으로 알려 드립니다. 확인 중일 때 다시 누르지 않아도 되며, 다시 눌러도 같은 요청으로 이어집니다.

## 제4조 (회사 사정에 따른 취소)
1. 센터에 상품이 없어 일부 상품을 보낼 수 없는 경우 그 상품만 자동으로 취소·환불되며 앱 알림으로 알려 드립니다. 자세한 내용은 「PMart 결품 처리 정책」을 따릅니다.
2. 회사 사정으로 주문 전체를 취소하는 경우 결제 금액 전액을 환불하고 앱 알림으로 알려 드립니다.

## 제5조 (취소 뒤 다시 주문)
1. 취소 뒤 다시 주문하면 새 주문으로 진행됩니다. 이전 주문의 요청 사항은 넘어가지 않으므로 새로 적어야 합니다.
2. 이전 주문의 취소·환불은 새 주문과 따로 진행됩니다.

## 제6조 (취소 환불)
취소에 따른 환불 금액과 시기는 「PMart 환불 정책」을 따릅니다.
