# PMart 고객 알림 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 회사가 고객에게 보내는 앱 알림의 종류, 알림함과 휴대폰 푸시, 수신 설정, 리뷰 작성 안내 알림, 고객 문의 응대 때 확인할 기준을 정합니다. 라이더에게 보내는 알림은 이 정책에서 다루지 않습니다.

## 제2조 (알림 채널)
1. 고객 알림은 앱 알림함에 저장되며, 알림함이 알림의 기준입니다.
2. 제4조에서 정한 종류는 알림함에 저장된 뒤 고객의 휴대폰에도 푸시로 보냅니다. 푸시의 제목과 본문은 알림함과 같습니다.
3. 휴대폰 푸시는 Android 앱에서만 받을 수 있습니다.
4. 문자, 알림톡 등 다른 채널로는 보내지 않습니다.
5. 직원 계정에는 고객 알림함이 없습니다.

## 제3조 (알림 내용의 원칙)
1. 알림 문구에는 고객의 개인정보를 넣지 않습니다.
2. 결과가 확인되지 않은 일을 끝난 것처럼 알리지 않습니다. 예를 들어 취소·품절 알림에서는 환불 결과가 나오면 다시 알려 드린다고 안내하고, 환불 완료는 실제로 환불이 처리된 뒤에만 알립니다. 결과를 아직 모르는 환불은 알리지 않습니다.
3. 알림은 보낸 때의 사실을 담습니다. 알림을 열 때는 주문의 최신 상태를 다시 보여 주므로, 지난 "배송 중" 알림을 눌러도 이미 배송이 끝났으면 주문 상세로 이동합니다.
4. 같은 일로는 알림을 한 번만 보냅니다. 한 주문을 여러 번에 나누어 배송하면 배송마다 출발·완료 알림이 갑니다.
5. 알림을 보내지 못해도 주문·배송·환불은 그대로 진행되며, 알림 실패 때문에 업무를 다시 하거나 되돌리지 않습니다.
6. 알림을 읽었다는 사실은 상품을 받았다는 증거가 아닙니다.

## 제4조 (알림 종류)
고객에게 보내는 알림은 다음과 같습니다. "푸시"가 "예"인 종류는 휴대폰 푸시로도 보냅니다.

| 분류 | 알림 | 보내는 때 | 푸시 |
|---|---|---|---|
| 주문 | 주문이 확정되었어요 | 주문이 확정되었을 때 | 아니요 |
| 주문 | 상품을 준비하고 있어요 | 센터가 상품 준비를 시작했을 때(예약 주문은 도착 시간대 포함) | 예 |
| 주문 | 예약 시간이 바뀌었어요 | 예약 배송의 도착 시간대가 바뀌었을 때 | 아니요 |
| 주문 | 주문 취소 | 주문이 취소되었을 때(배달 기사를 찾지 못한 경우, 품절인 경우 등 사유별 문구) | 예 |
| 주문 | 결품 부분 취소 | 일부 상품이 품절되어 그 수량만 취소되었을 때 | 예 |
| 배송 | 배송 출발 | 라이더가 상품을 받아 출발했을 때 | 예 |
| 배송 | 주문하신 곳으로 가고 있어요 | 라이더가 고객에게 향하기 시작했을 때 | 예 |
| 배송 | 곧 도착 | 라이더가 고객 주소 가까이(약 300m) 왔을 때 | 예 |
| 배송 | 배송 완료 | 배송이 끝났을 때(리뷰 작성 기한 안내 포함) | 예 |
| 배송 | 배송이 늦어지고 있어요 | 배달 기사 배정이 늦어질 때(예상 지연 시간을 5분 단위로 안내) | 예 |
| 배송 | 배송이 늦어질 수 있어요 | 센터의 배송 가능 수량이 줄어 도착이 늦어질 수 있을 때 | 아니요 |
| 배송 | 새 상품으로 다시 보내 드려요 | 배송 중 사고나 파손으로 상품을 다시 보낼 때 | 예 |
| 배송 | 배송을 이어서 진행해요 | 배송 실패로 처리했던 건을 되돌려 배송을 이어갈 때 | 아니요 |
| 배송 | 상품을 받으셨나요? | 고객이 상품을 받았는지 확인이 필요할 때 | 아니요 |
| 배송 | 다시 배송비 결제 필요 | 오배송 건을 다시 배송하려면 배송비 결제가 필요할 때 | 예 |
| 반품 | 반품 회수 안내 | 회수 기사를 배정하는 중일 때, 회수했을 때, 고객 사정으로 회수하지 못했을 때 | 아니요 |
| 환불 | 환불이 완료되었어요 | 환불이 결제 수단으로 처리되었을 때 | 예 |
| 환불 | 환불 처리가 늦어지고 있어요 | 환불 처리에 실패해 다시 처리해야 할 때 | 예 |
| 문의 | 고객센터 답변 | 고객 문의에 답변이 달렸을 때 | 아니요 |
| 리뷰 | 리뷰 작성 안내 | 제6조의 기준을 충족할 때 | 예 |

## 제5조 (수신 설정)
1. 제4조의 알림은 모두 거래에 필요한 안내이므로 고객이 끌 수 없습니다.
2. 마케팅 수신 동의를 철회해도 거래 알림과 주문 조회에는 영향이 없습니다.
3. 회사는 현재 할인·행사 등 마케팅 알림을 보내지 않습니다.

## 제6조 (리뷰 작성 안내 알림)
1. 배송이 끝나고 10분이 지난 뒤, 그 주문에 아직 리뷰를 쓰지 않았고 쓸 수 있는 상품이 남아 있으면 리뷰 작성 안내 알림을 보냅니다.
2. 이미 리뷰를 쓴 주문(쓴 뒤 지운 경우 포함)이나 쓸 수 있는 상품이 없는 주문에는 보내지 않습니다.
3. 리뷰 작성 안내는 주문마다 한 번만 보냅니다. 나누어 배송하거나 다시 배송해도 다시 보내지 않습니다.
4. 취소된 주문과 반품 회수 배송에는 보내지 않습니다.
5. 오배송이 확인된 주문은 다시 배송이 끝날 때까지 보내지 않으며, 다시 배송이 끝난 때부터 다시 10분을 기다립니다. 다시 배송 없이 환불로 끝나면 보내지 않습니다.
6. 리뷰 작성 여부를 확인하지 못한 채 배송 완료 뒤 3일이 지나면 보내지 않습니다.

## 제7조 (휴대폰 등록과 해제)
1. 고객이 앱에 로그인하면 그 휴대폰이 푸시를 받을 단말로 등록되고, 로그아웃하면 해제됩니다.
2. 한 고객은 단말을 5대까지 등록할 수 있습니다. 더 등록하면 가장 오랫동안 쓰지 않은 단말이 해제됩니다.
3. 회원 탈퇴가 완료되면 등록된 단말이 모두 해제되어 더는 푸시를 받지 않습니다. 알림함 기록은 남습니다.

## 제8조 (고객 문의 응대)
1. 고객이 푸시를 받지 못했다고 하면 앱 알림함에서 같은 알림을 확인하도록 안내합니다. 휴대폰 푸시는 보내지 못해도 다시 보내지 않으며, 알림함에는 남아 있습니다.
2. 알림이 없더라도 고객은 주문 상세에서 주문과 배송의 최신 상태를 확인할 수 있습니다.
