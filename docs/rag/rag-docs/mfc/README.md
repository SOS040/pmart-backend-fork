## 색인에 넣으려면 (아직 안 함)
- MFC 사내용 RAG 는 아직 없다(지금은 운영자용·고객용). 운영자용 색인에 넣을지, 센터 관리자·작업자용을 따로 둘지는 사용자 결정 — 승인 뒤.

## 넣지 않은 것
- **LAN·시험 값이거나 결정 전인 값**: 예약 배송 피킹 준비 시각(LAN 90분), 센터 시간당 수용 주문 수(LAN 30), 센터 직원 근무 시간표(LAN 07~24시 임시), 장바구니 수(LAN 4대 — 늘릴지 결정 필요), 보관 온도대별 최소 잔여 소비기한 값(설정값 — 사용자 결정 기록 못 찾음), 배정 추천 작업 시간·작업자 속도 배율(시뮬레이터 임시 값), 이동 예상 5분.
- **결정 대기·미결**: 실사를 계획한 센터 관리자의 승인 금지 여부(미결), 일일크루를 "미배정 작업만" 받게 하는 정규직 우선 규칙(2026-11-08 결정은 있으나 구현 확인 못 함), 일일크루 그날 업무를 수요로 나누기(사용자 "일단 유지"), 새 작업 유형(실사·회수품 반입·검수)을 기존 작업자에게 자동으로 넣을지, 품질 사고 MB-2 남은 질문(DECIDED·CLOSED 기준 등), 피킹 뒤 부분 중지(미구현), PACK·RETURN 부분 종료.
- **업무 원문에 없거나 정하지 않은 것**: 주류(성인 확인) 취급·인계 규칙, 피킹 장소 방문 순서의 구역 이름(평면도 의존 — "시스템이 정한 순서"로도 쓰지 않음), 진열 카테고리 칸 배치(LAN 은 전부 기타 칸).
- **고객·라이더 쪽 규칙**: 결제 전 예약 10분, 고객 자율 취소 마감, 회수비 등은 고객·라이더 문서 몫.
- **LAN 시험 전용 기능**: 시험 입고 예정 등록.
