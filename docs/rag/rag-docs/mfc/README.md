## 넣지 않은 것
- **LAN·시험 값이거나 결정 전인 값**: 예약 배송 피킹 준비 시각(LAN 90분), 센터 직원 근무 시간표(LAN 07~24시 임시), 장바구니 수(LAN 4대 — 늘릴지 결정 필요), 배정 추천 작업 시간·작업자 속도 배율·가중치(시뮬레이터·임시 값), 이동 예상 5분, 복귀 예상 5분, 계획 기준 하루 154박스(실측으로 바꿀 값), 입고 검수 인원(산출 값).
- **업무 원문 1장의 산출·모형 값**: 구역별 평수·랙 수·슬롯·SKU 수·인원·박스 환산, 오전 입고 작업 순서(운영 설계 단계), 패킹 13단계 작업 흐름(적용 검토 단계), 포장재 규격(원본 기록), PDA 화면 예시·로케이션 코드 해석(미확인), 냉장·냉동 상품의 출하대기 시간 한계(정하지 않음), 발주 주기·재고 산식. 센터 총면적 463평 같은 확정 입력도 현장 직원 규칙이 아니라서 넣지 않음.
- **승인되지 않은 ADR**: ADR-0002(재고 단일 쓰기 — 상태 제안. 재고 수량 개념 H/Q/E/R 은 직원 규칙이 아니라 넣지 않음).
- **결정 대기·미결**: 실사를 계획한 센터 관리자의 승인 금지 여부(미결), 일일크루를 "미배정 작업만" 받게 하는 정규직 우선 규칙(2026-11-08 결정은 있으나 구현 확인 못 함), 일일크루 그날 업무를 수요로 나누기(사용자 "일단 유지"), 새 작업 유형(실사·회수품 반입·검수)을 기존 작업자에게 자동으로 넣을지, 품질 사고 MB-2 남은 질문(DECIDED·CLOSED 기준 등), 피킹 뒤 부분 중지(미구현), PACK·RETURN 부분 종료.
- **업무 원문에 없거나 정하지 않은 것**: 주류(성인 확인) 취급·인계 규칙, 진열 카테고리 칸 배치(LAN 은 전부 기타 칸), 입고 예정(도착 전) 작업을 줄지·도착한 차 먼저 줄지(다음 작업 받기 입고 순위 세부 — 사용자 결정 남음).
- **고객·라이더 쪽 규칙**: 결제 전 예약 10분, 고객 자율 취소 마감, 회수비 등은 고객·라이더 문서 몫.
- **LAN 시험 전용 기능**: 시험 입고 예정 등록.
