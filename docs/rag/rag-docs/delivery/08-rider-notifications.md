# PMart 라이더 알림 운영 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 회사가 라이더에게 보내는 처리 결과 알림의 종류와 내용, 전달 방식을 정해, 직원이 라이더 문의에 답할 때 기준으로 삼게 합니다.

## 제2조 (알림 방식)
1. 라이더 알림은 라이더 앱의 알림함에 쌓이며, 알림함이 알림의 원본입니다.
2. 라이더가 앱에서 휴대폰 알림을 받도록 등록했으면 같은 알림을 휴대폰 푸시로도 보냅니다. 라이더 알림은 모두 처리할 일이므로 종류를 골라 끌 수 없습니다.
3. 휴대폰 푸시 발송에 실패해도 다시 보내지 않으며, 알림함의 알림은 그대로 남습니다. 알림 발송 실패로 업무 처리를 되돌리지 않습니다.

## 제3조 (라이더에게 알리는 일)
회사는 다음 일이 생기면 라이더에게 알립니다.
1. 지원센터 답장: 도움요청 대화에 지원센터가 메시지를 보낼 때마다
2. 도움요청 처리 끝: 라이더 도움요청 접수 건이 완료되었을 때
3. 라이더 문의 답변: 라이더 문의에 답변이 등록되었을 때
4. 계정 제한·해제: 신규 배차 제한, 일시 중지, 이용 종료가 걸리거나 정상으로 풀렸을 때
5. 수행료 조정: 산정 불가 수행료의 조정 결과가 나왔을 때

## 제4조 (알림 내용)
1. 알림 문구에는 메시지·답변 내용이나 개인정보를 넣지 않습니다. 라이더는 알림을 눌러 원래 화면에서 내용을 확인합니다.
2. 계정 제한 알림에는 제한 사유와 근거를 넣지 않고 지원센터에 문의하라고 안내합니다. 제한에 기한이 있으면 기한을 함께 알립니다.
3. 도움요청 처리 끝 알림에는 처리 결과나 메모를 넣지 않습니다.
4. 같은 일은 한 번만 알립니다.
