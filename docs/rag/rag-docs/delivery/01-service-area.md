# PMart 배송 권역·배송 가능 지역 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 PMart(이하 "회사")가 고객 주소로 배송할 수 있는지 판단하는 배송 권역과 담당 센터, 배송 조건, 배달 서비스 시간에 관한 직원 업무 기준을 정합니다.

## 제2조 (정의)
1. "배송 권역"이란 한 센터가 고객 배송을 맡는 지도 위의 구역을 말합니다.
2. "권역 매핑"이란 배송 권역과 그 권역을 맡는 센터를 묶은 한 벌의 설정을 말하며, 바뀔 때마다 새 버전으로 관리합니다.
3. "배송 가능 판정"이란 고객 주소가 어느 배송 권역에 들어가 어느 센터가 배송할 수 있는지 판단하는 일을 말합니다.

## 제3조 (권역 매핑의 변경과 발효)
1. 권역 매핑을 바꾸려면 운영 직원이 새 버전의 초안을 만들어 승인을 요청합니다.
2. 승인은 배송 권역 승인자가 합니다. 승인 절차는 승인 정책을 따릅니다.
3. 승인된 버전은 미리 정한 시험 주소로 판정 결과를 확인한 뒤에 발효됩니다.
4. 승인 뒤 내용이 바뀌었거나 시험 주소의 판정 결과가 맞지 않으면 그 버전은 발효되지 않고 반려됩니다.
5. 발효된 버전만 고객 주소 판정에 쓰입니다.

## 제4조 (배송 가능 판정의 기준)
1. 배송 가능 판정은 고객이 입력한 도로명 주소를 좌표로 바꾼 위치로 합니다. 고객이 지도에서 찍은 위치는 판정에 쓰지 않습니다.
2. 도로명 주소로 위치를 하나로 정할 수 없으면(찾을 수 없음, 여러 곳) 고객에게 도로명 주소를 다시 입력하도록 안내합니다.
3. 주소 검색 장애로 판정할 수 없으면 판정 결과는 "알 수 없음"이 되며, 배송 가능으로 처리하지 않습니다.
4. 한 주소가 여러 권역에 겹치면 우선순위가 가장 높은 권역이 하나일 때만 그 권역으로 판정합니다. 우선순위가 같은 권역이 여럿이면 임의로 고르지 않고 겹침으로 판정합니다.
5. 회사는 판정에 쓴 주소 원문을 저장하지 않습니다.
6. 비회원도 둘러보기와 배송지 확인을 위해 배송 가능 여부를 조회할 수 있습니다.

## 제5조 (배송 조건)
1. 배송 방식은 한집배달, 알뜰배달, 예약배달 세 가지입니다.
2. 배송 한 건의 무게는 10,000g까지입니다.
3. 00시부터 08시까지는 실제 배송을 하지 않습니다.
4. 배송 조건은 발효된 권역에 속한 센터에 대해서만 조회됩니다.

## 제6조 (배달 서비스 시간)
1. 회사의 배달 서비스 시간은 매일 08시부터 24시까지입니다.
2. 배차는 배달 서비스 시간 안에서만 진행합니다. 시간 밖에 들어온 배차 요청은 다음 서비스 시작 시각에 진행합니다.
3. 라이더가 이미 맡은 배송은 서비스 시간이 지나도 전달 완료나 예외 처리까지 진행합니다.
