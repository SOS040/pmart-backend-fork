# PMart 업무 개요 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 직원이 PMart의 전체 업무 흐름과 업무마다 정해진 기본 규칙을 한눈에 이해하도록 정합니다. 업무별 자세한 기준은 각 업무 정책(백오피스, MFC, 배송, 주문·클레임, 고객 안내 문서 등)을 따릅니다.

## 제2조 (서비스 개요)
1. PMart는 본사가 승인한 상품을 중앙 물류센터(CDC)에서 도심 소형 물류센터(MFC)로 보충하고, 고객이 주문하면 고객 배송지를 담당하는 MFC에서 상품을 준비해 라이더가 배달하는 서비스입니다.
2. 고객은 배송지의 지정 MFC에 실제로 있는 상품으로만 주문하고 결제합니다.
3. 배달은 오전 8시부터 밤 12시까지 합니다. 0시부터 8시 전까지는 실제 배송을 하지 않고 7시 도착 시간대도 없으며, 이 시간에도 8시 이후 도착 시간대를 골라 예약배달로 주문할 수는 있습니다.

## 제3조 (두 가지 물류 흐름)
1. 공급 흐름: MFC에 필요한 상품을 본사가 계산·배분·승인하면, CDC가 상품을 꺼내 검품하고 상차한 뒤 간선 차량이 MFC로 운송합니다. MFC가 실제로 받아 검수하고 적치하면 MFC 재고가 늘어납니다.
2. 판매 흐름: 고객이 상품을 고르고 주문서를 만들면 재고와 도착 시간대를 잡은 뒤 결제합니다. 결제가 승인되면 주문이 확정되고, MFC가 집품·포장한 상품을 라이더에게 인계하며, 라이더가 고객에게 전달하고 사진을 남깁니다.
3. 두 흐름은 MFC 재고에서 만납니다. 공급은 MFC 현물을 늘리고, 판매는 결제 전에 재고를 예약했다가 라이더에게 인계할 때 현물을 줄입니다. 집품이나 포장만으로는 재고가 줄지 않습니다.

## 제4조 (업무별 책임)
1. 각 정보는 그 정보를 맡은 업무 시스템 한 곳에서만 확정합니다.

| 업무 | 확정하는 것 |
|---|---|
| 상품·고객(커머스) | 고객 계정·동의·주소록, 장바구니, 상품·전시·검색, 리뷰, 상품 기준정보와 가격 |
| 주문·결제 | 주문과 금액, 고객과의 약속, 취소·반품·환불 요청, 결제 거래 기록 |
| 공급(SCM) | 수요 예측, 보충 필요량, 센터별 배분, 공급 승인 |
| CDC | CDC 재고, 출고 작업, 실제 출발과 이동 중 재고 확인, 품질 격리 |
| MFC | MFC 재고, 집품·포장·인계, 입고·적치, 작업 여력, 반품 검수 |
| 간선 운송(TMS) | 간선 운행, 차량·기사, 실제 출발과 인계 증빙 |
| 배송 | 배송 권역과 담당 MFC, 배송 시간대 여력, 라이더, 배차, 픽업·전달·회수, 위치와 도착 예정 시각 |
| 본사(백오피스) | 직원 권한, 승인 절차, 접수 건과 후속 처리, 센터 기준정보, 개인정보 열람 기록 |

2. 백오피스는 각 업무 시스템의 결과를 연결해 보여 주고, 승인하고, 접수 건을 관리할 뿐 주문·재고·결제·배차의 결과를 직접 정하지 않습니다.

## 제5조 (상품)
1. 상품 번호(SKU)는 회사 전체에서 쓰는 8자리 번호이며 본사 승인 뒤 발급합니다.
2. 낱개 상품과 묶음 상품은 서로 다른 재고이며 합치거나 바꾸지 않습니다. 박스와 팔레트는 상품이 아닙니다.
3. 같은 기초상품은 구성 낱개를 합쳐 한 주문에 10개까지 살 수 있습니다.

## 제6조 (주문 금액)
1. 최소 주문 금액은 상품 금액 기준 15,000원입니다.
2. 배달팁은 한집배달 4,000원, 알뜰배달·예약배달 3,000원입니다. 상품 금액이 30,000원 이상이거나 첫 구매이면 배달팁은 0원입니다.
3. 봉투값은 주문당 한 번 100원입니다.
4. 상품 총무게가 10,000g을 넘으면 배송을 나누어 보내며, 나누어 보내도 배달팁을 더 받지 않습니다. 정확히 10,000g이면 나누지 않습니다.
5. 할인 행사는 기간 할인과 장바구니 쿠폰 두 가지만 운영하며, 최소 주문 금액과 배달팁 무료 기준은 기간 할인 뒤·쿠폰 전 상품 금액으로 판단합니다. 상품 쿠폰, 배송비 쿠폰, 1+1 같은 수량 행사는 운영하지 않습니다. 자세한 기준은 「PMart 가격·행사 정책」을 따릅니다.

## 제7조 (시간 기준)
1. 주문서의 가격은 최대 10분 동안 유지됩니다.
2. 결제 직전에 잡은 재고 예약은 10분 동안 유효합니다.

## 제8조 (결제)
1. 결제는 토스페이먼츠로만 받습니다.
2. 고객이 결제창에서 돌아온 것만으로는 결제 승인을 확정하지 않습니다.
3. 결제 결과를 모르면 실패로 보지 않고 1분 간격으로 5번 확인한 뒤 담당자에게 넘기며, 그 뒤에는 15분 간격으로 확인합니다.
4. 결품이나 반품이 생기면 그 상품 금액만 결제에서 부분 취소합니다.
5. 주류는 현재 판매하지 않습니다. 판매를 시작하면 결제 단계의 인증으로 성인 여부를 확인하며, 현장에서 신분증이나 서명을 따로 받지 않습니다(「PMart 주문 조건·결제 금액 정책」 제12조).

## 제9조 (주문 변경과 취소)
1. 결제한 뒤에는 배송지 주소와 연락처를 바꿀 수 없습니다.
2. 예약배달의 도착 시간은 상품준비 전까지만 바꿀 수 있습니다.
3. 고객은 상품준비 전까지 앱 주문 내역에서 스스로 주문을 취소할 수 있습니다. 상품준비 뒤부터 인계 전까지는 고객센터를 통해서도 취소하지 않습니다.
4. 라이더에게 인계된 상품은 취소하지 않고 회수·반품으로 처리합니다.
5. 결품된 상품은 고객이 미리 고른 선택과 상관없이 그 상품만 부분 취소하고 환불합니다.
6. 지정 MFC에 없는 상품을 다른 MFC에서 가져오거나 합쳐서 보내지 않습니다.

## 제10조 (반품·교환)
1. 반품은 일반 상품은 받은 뒤 7일 안에, 신선 상품은 24시간 안에 신청할 수 있습니다.
2. 상품 하자, 오배송, 광고와 다른 상품의 교환은 받은 뒤 3개월 안에, 또는 그 사실을 안 날부터 30일 안에 신청할 수 있습니다.
3. 단순 변심 교환은 왕복 배송비 9,000원을 받습니다.
4. 회수하거나 다시 배달하는 주소는 원래 주문의 주소입니다.

## 제11조 (공급)
1. 공급 이관은 한 번 요청에 한 번 이관, 한 번 출발입니다.
2. 출발한 뒤에는 목적지를 바꾸지 않습니다. 다른 센터 상품이 섞여 실린 경우와 빈 롤테이너 회수는 간선 운송 정책을 따릅니다.
3. 공급 승인, 상품 확보, 출발, MFC 수령은 서로 다른 단계이며, 앞 단계가 끝났다고 다음 단계가 끝난 것으로 보지 않습니다.
4. 공급업체 발주, CDC 외부 입고, MFC 사이 재고 이동은 지금 운영하지 않습니다.

## 제12조 (리뷰)
1. 리뷰는 상품마다 배송 완료 뒤 14일 안에 한 번 쓸 수 있습니다.
2. 처음 등록한 뒤 3일이 지나면 고칠 수 없고, 지운 리뷰는 다시 쓸 수 없습니다.

## 제13조 (업무 처리의 기본 원칙)
직원은 업무를 처리하거나 고객·라이더에게 안내할 때 다음 원칙을 지킵니다.
1. 수량, 금액, 처리 결과는 그 정보를 맡은 업무 시스템의 기록만 기준으로 삼습니다. 화면에 보이는 사본이나 표시만으로 처리가 끝났다고 보지 않습니다.
2. 요청을 보낸 것, 받아들여진 것, 실제로 처리된 것, 기록에 반영된 것, 고객에게 안내된 것은 서로 다른 단계입니다.
3. 응답이 늦거나 없다고 실패로 보지 않습니다. 원래 요청이나 거래를 다시 확인하기 전에는 새 주문, 새 결제, 새 예약을 만들지 않습니다.
4. 같은 요청을 다시 보내도 한 번만 처리됩니다. 지난 기록으로 지금 상태를 되돌리지 않습니다.
5. 정책 값이나 승인 기준이 정해지지 않은 일은 0, 무제한, 정상으로 보고 처리하지 않습니다. 그 일만 멈추고 원인과 담당, 필요한 입력을 남깁니다.
6. 일부만 성공한 처리를 되돌릴 때는 이번에 새로 잡은 것만 풀고, 이미 움직인 상품이나 이미 출발한 운송은 되돌리지 않습니다.
