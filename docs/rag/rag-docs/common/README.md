# 공통 사내 참고 문서 — RAG 원고 (초안)

## 목적
운영자용 RAG(업무 도우미)가 어느 업무 영역의 질문에든 함께 근거로 쓸 **직원용 공통 참고 문서** 초안입니다. 업무 용어와 PMart 전체 업무 흐름·기본 규칙을 담습니다. 영역별 자세한 규정은 `backoffice/`, `mfc/`, `delivery/`, `order_claim/`, `cdc_wms/`, `scm/`, `tms/`, `rider_app/`, `customer_app/` 문서를 따르며, 여기서는 되풀이하지 않습니다. 고객·라이더에게 공개하는 문서가 아닙니다.

- 문서 버전: 0.1 (**초안 — 사용자 승인 전**)
- 작성: Claude, 2026-11-20 (사용자 요청 "운영자용 RAG 문서 정비")
- 근거:
  - 용어(01): `docs/business/glossary.md`(1~5장 — 6장 상태 태그와 멱등 키·이벤트 키 같은 개발 용어는 뺌), `docs/business/domain-map.md` §2(문서 표기 ↔ 표준 표기 중 직원에게 쓸모 있는 것 — PPC·점포·DC·관제·ICS·점원앱/PDA), `docs/backoffice/HANDOVER.md` §3(화면 용어 "접수 건"·"후속 처리"·맡기·완료 처리·다시 처리하기·넘기기)·§5(지원센터 = 라이더 운영), ADR-0049(결품은 부분 취소·환불), ADR-0052·0060(상품준비 뒤 고객 취소 없음)
  - 업무 개요(02): `docs/business/overview.md` §1~§5(4장 핵심 규칙·5장 공통 원칙), `docs/business/domain-map.md` §3(배달 서비스 시간 08:00~24:00 — 사용자 2026-11-13, 분할 기준 10,000g 초과, 주류 PG 인증 통합), ADR-0049, ADR-0052 결정 1, ADR-0060, ADR-0063(리뷰 기한 — 원문 그대로)
- 작성 규칙(`backoffice/`·`mfc/`·`rider_app/` 문서와 같음): 앱 약관 문서 형식 — 제목·시행일·제N조(제목)·번호 항목, ~합니다 체. 내부 코드·API·클래스·서비스·사건 이름과 역할 코드는 넣지 않고 역할은 표시 이름으로 쓴다. 결정·구현된 규칙만 넣고, 업무 원문의 제안·설명용 수치·결정 전 항목은 넣지 않는다.
