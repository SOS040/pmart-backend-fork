# PMart CDC 선반 보충·MFC 이관 출발 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 중앙 물류센터(이하 "CDC") 안의 피킹 위치 자동 보충과, CDC 에서 MFC 로 보내는 이관 물량의 출발·미출발 잔량 처리 기준을 정합니다.

## 제2조 (피킹 위치 자동 보충)
1. 피킹 위치의 현재 출고 가능한 수량이 등록된 최소량 **이하**가 되면 시스템이 보충 작업을 자동으로 계산합니다.
2. 직원이 선반 보충을 직접 요청하거나 보충 작업을 새로 만드는 기능은 제공하지 않습니다.
3. 운영자는 이미 만들어진 보충 작업에 대해서만 오류 수정, 중지, 재검증·재시도를 합니다.
4. 일반 재배치의 승인 여부와 기존 보충 작업의 재처리는 서로 별개로 판단합니다.

## 제3조 (한 요청은 한 번만 출발)
1. MFC 공급 요청 하나는 하나의 이관으로 처리하며, 그 이관은 한 번만 출발합니다.
2. 실제로 출발한 수량만 이동 중 물량이 됩니다. 예를 들어 60개를 승인했으나 실제로 48개만 출발했다면 이동 중 물량은 48개이고, 출발하지 않은 12개는 CDC 에 남아 정리 대상이 됩니다.
3. 출발하지 않은 수량을 같은 요청으로 나중에 다시 출발시키지 않습니다.

## 제4조 (출발하지 않은 잔량)
1. 출발하지 않은 잔량은 자동으로 없어지거나 자동으로 종료되지 않습니다.
2. CDC 에 남은 실물·작업·할당을 정리하고 처음 승인한 수량을 확인한 뒤, 공급 관리 업무에서 사유를 남기고 직접 종료합니다.
3. 추가 공급이 필요하면 남은 수량·수령 수량·미충족 수량을 다시 계산하여 MFC 가 별도로 새 요청을 합니다.

## 제5조 (출발 통보 실패)
1. 출발 통보가 전달되지 않더라도 이미 반영된 출발과 CDC 재고 차감은 그대로 유지합니다.
2. 이때는 통보만 다시 보내 복구합니다.
