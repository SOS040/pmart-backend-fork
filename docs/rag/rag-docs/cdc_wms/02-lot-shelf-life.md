# PMart CDC LOT·소비기한 관리 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 중앙 물류센터(이하 "CDC")에서 상품의 제조 LOT 을 추적하는 대상과, 소비기한에 따른 최소 잔여일수 판정 기준을 정합니다.

## 제2조 (LOT 추적 대상)
1. 식품 단품 상품은 반드시 제조 LOT 으로 추적합니다. 제조 LOT 과 재고를 연결하고, 이동·출고 이력을 남깁니다.
2. 식품 묶음 상품도 반드시 제조 LOT 으로 추적합니다. 완제품 묶음의 제조 LOT 을 기준으로 하며, 묶음 상품은 구성 단품과 별도의 상품 재고로 추적합니다.
3. 비식품 상품(단품·묶음)은 LOT 추적 대상으로 설정한 경우에만 추적하며, 이때에는 식품과 같은 이력 규칙을 적용합니다.

## 제3조 (총 소비기간과 잔여일수)
1. 총 소비기간은 확인된 제조일과 표시된 소비기한 날짜 사이의 달력 일수 차이입니다.
2. 잔여일수는 표시된 소비기한 날짜에서 판정일을 뺀 일수입니다.
3. 날짜는 한국 시간(Asia/Seoul) 기준으로 계산하며, 단위는 일입니다. 계산한 일수에 1일을 더하지 않습니다.
4. 제조사가 확인한 총기간 일수도 근거로 쓸 수 있습니다. 다만 날짜로 계산한 값과 다르면 조사합니다.
5. 제조일이나 총기간 근거가 없거나, 총 소비기간이 0일 이하이거나, 표시 내용이 서로 맞지 않으면 추정해서 계산하지 않고 보류합니다.

## 제4조 (최소 잔여일수)
1. 상품군별 최소 잔여일수는 다음과 같습니다. 아래에서 "총기간"은 총 소비기간입니다.

| 상품군 | 최소 잔여일수 |
|---|---|
| 신선 | 총기간의 30% (소수는 올림) |
| 가공식품·음료·기한 관리 생활용품 | 총기간의 20%(소수는 올림)와 30일 중 작은 값 |
| 총기간 7일 이하 신선의 출고 | 총기간의 30%(소수는 올림)와 2일 중 큰 값 |

2. 총기간 7일 이하 신선 상품을 출고할 때의 2일은 30% 기준을 낮추는 값이 아니라, 그 위에 더하는 최소 하한입니다.
