# CDC WMS 사내 정책 문서 — RAG 원고 (초안)

중앙 물류센터(CDC) 운영 화면이나 사내 상담에서 AI 가 답할 때 근거로 쓸 **CDC 사내(직원용) 정책 문서** 초안입니다. 고객·라이더에게 공개하는 문서가 아닙니다. MFC 쪽 재고·품질·현장 작업 규정은 `mfc/` 문서에 있으며 여기에 다시 적지 않았습니다.

- 문서 버전: 0.1 (**초안 — 사용자 승인 전**)
- 작성: Claude, 2026-11-20 (사용자 요청 "운영자용 RAG 문서 정비")
- 근거:
  - `docs/business/WMS-business-logic.md`(v8.1) — 문서 전체 상태가 승인 전이므로 사용자 확정·채택 운영안으로 표기된 단락만 옮김: L426(운영 개시 재고 승인), L485(위치 7구간), L734 와 바로 아래 표·해설(총 소비기간·잔여일수·최소 잔여일수), L1054(자동 보충), L1398·L1400(1요청 1이관 1출발·미출발 잔량), L1720(운영 제한 권한), L2980~2982(LOT 추적 대상)
  - `services/cdc-inventory-service/CLAUDE.md`(구현 — 센터 상품 취급 기본 꺼짐·자기 센터 운영자가 켬, 규칙·이력은 MFC 와 같음) 와 계약 `contracts/openapi/cdc-inventory-service.yaml`(켜기는 활성 상품만·일괄 500행 전부 반영 또는 전부 거절·같은 값은 이력 없음)
  - `contracts/states/cdc-states.md`·ADR-0002(상태: 제안) — 상태 이름과 수량 개념이 승인 전 원문에서 나온 것이라 본문에 옮기지 않음(대조용으로만 읽음)
- 작성 규칙(MFC·백오피스 문서와 같음): 앱 약관 문서 형식 — 제목·시행일·제N조(제목)·번호 항목, ~합니다 체. 내부 코드·API·클래스·이벤트·서비스 이름은 넣지 않고 역할은 원문의 표시 이름(본사 재고 책임자·CDC 관리자·현장 책임자·운영자 등)으로 쓴다. 결정·구현된 규칙만 넣는다.

## 색인에 넣으려면 (아직 안 함)
- 운영자용 RAG 색인에 넣을지는 사용자 결정 — 승인 뒤.

## 넣지 않은 것
- **승인 전 표기 단락 전체**: WMS 원문에서 승인 전 표기 27곳, 승인 대기 3곳, 팀 확인 필요 4곳, 권장안·제안 약 20곳과 표기 없는 단계 설명. 예: 박스·팔레트(LPN) 구성과 수명, LOT 내부 코드와 정정, Wave·작업 편성, 입고 검수·적치·재배치 절차, 피킹·검품·상차, 실사·재고 조정 승인 기준, 리콜·온도 이상 처리, 운영 값이 없을 때의 보류 원칙, 겹친 제한의 적용과 자동 재개 금지, 식품 LOT 불명 시 출고 차단(표기 없음), 소비기한 날짜형·시각형 차단 시각.
- **구현 전**: CDC 가용·할당·출발 반영·대사 기능(501 — 화면과 절차가 아직 없음).
- **개발·데이터 구조**: 재고 원장 주인, 수량 등식, 이동 중 대사, 상태 전이표.

## 확인 필요
1. **CDC 직원 역할 이름**: WMS 원문은 "CDC 관리자"·"현장 책임자"·"본사 재고 책임자"·"본사 품질 책임자"를 쓰지만 `docs/architecture/auth/staff-roles.md` 에는 CDC 역할이 없고, 상품 취급 계약은 "운영자(자기 센터)"만 적음. 본문은 원문 이름을 그대로 썼고 상품 취급은 "그 센터 권한을 가진 운영자"로 적음 — 실제 역할과 맞출지.
