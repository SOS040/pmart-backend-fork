# PMart CDC 운영 제한 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 중앙 물류센터(이하 "CDC")의 업무를 제한하거나 중지하고, 이를 해제하는 권한과 승인 기준을 정합니다.

## 제2조 (제한 범위)
1. 운영 제한은 센터, 온도대, 상품, 업무 단위로 겁니다.
2. 제한의 종류는 정상 운영, 출고 제한, 출고 중지, 안전을 위한 작업 중지입니다.

## 제3조 (제한과 해제 권한)
1. CDC 관리자는 혼잡에 따른 제한을 걸고, 회복되면 해제합니다.
2. 현장 책임자는 안전상 긴급한 경우 제한을 겁니다.
3. 본사가 건 제한이나 안전 사고로 걸린 제한을 풀고 업무를 다시 시작하려면 본사 운영 승인과 현장 확인이 모두 필요합니다.
4. 품질과 관련된 제한은 제3항에 더해 본사 품질 담당의 해제가 있어야 풀립니다.
