# PMart 간선 운송 상차·출차·운송 관제 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 간선 차량의 상차, 출차, 운송 중 관제와 지연 판정 기준을 정합니다.

## 제2조 (상차)
1. 기사가 입차를 기록합니다.
2. 상차 작업자는 박스를 스캔하며 롤테이너에 싣고, 롤테이너를 방문 순서의 반대로 상차합니다.
3. 실제 상차 수량을 온도대·이관요청서별로 계획 수량과 대조합니다. 모두 맞으면 "상차완료"가 되고, 차이가 있으면 미상차·부분출고 예외로 넘깁니다.
4. 다른 센터 박스나 다른 온도대 박스는 바로 막습니다. 이전 버전 운송지시서로 상차하려 하면 막습니다.
5. 기사는 적재함 온도를 기록합니다.
6. 상차완료는 출차나 출고 확정이 아닙니다.

## 제3조 (출차)
1. 상차완료, 차량·기사 확정, 계획 출차 시각 도달을 모두 갖추어야 출차할 수 있습니다. 계획 시각 전 출차는 배차 담당의 조기 출차 승인이 있어야 합니다.
2. 기사가 출차를 기록하면 "출차완료"가 되고 출차 시각과 위치, 적재함 온도가 남습니다.
3. 출차 사실은 중앙 물류센터에 알리고, 도착할 MFC 센터에는 차량·예상 도착 시각·이관요청서와 박스 목록을 보냅니다. 출고 확정 같은 재고 처리는 중앙 물류센터가 합니다.
4. 실제로 출차하지 않았는데 상차완료만으로 출차를 처리하지 않습니다.
5. 출차 조건을 갖추지 않았는데 차량이 실제로 나갔다면, 출차 사실은 그대로 기록하고 "무승인 출차" 예외를 등록합니다.
6. 출차 알림이 상대에게 전달되지 않았더라도 출차를 취소하지 않습니다. 전달되지 않은 부분만 다시 보냅니다.

## 제4조 (이벤트 기반 관제)
1. 실시간 위치 추적은 하지 않습니다. 입차·출차·도착·인계·복귀 같은 사건이 일어날 때 시각과 위치를 기록합니다.

| 사건 | 기록하는 사람 | 남는 값 |
|---|---|---|
| 입차 | 기사 | 시각, 위치 |
| 상차완료 | 상차 작업자 | 시각, 실제 수량 |
| 출차 | 기사 | 시각, 위치, 적재함 온도 |
| MFC 센터 도착 | 기사 | 시각, 위치, 적재함 온도 |
| 하차 시작·인계 완료 | MFC 수령 담당(스캔) | 시각, 인계 수량 |
| 정차 출발 | 기사 | 시각 |
| 중앙 물류센터 복귀 | 기사 | 시각, 회수 물량 |

2. 다음 정차의 예상 도착 시각은 마지막 사건 시각에 남은 구간 주행시간과 남은 하차 시간을 더해 다시 계산합니다. 남은 정차를 일괄로 미루지 않고 정차마다 다시 계산합니다.
3. 계획 시각, 최신 예상 시각, 실제 시각은 따로 남깁니다. 늦어진 예상 시각으로 원래 계획을 덮어쓰지 않습니다.

## 제5조 (지연과 정보 지연)
1. 예상 도착이 계획 도착보다 30분 이상 늦거나 도착 마감(간선 운송 배차 정책 제2조)을 넘길 것으로 예상되면 "지연" 표시를 하고 배차 담당과 MFC 센터에 알립니다. 지연은 운송지시서 상태가 아니라 표시입니다.
2. 마지막 사건 뒤 예상 시각보다 30분 넘게 다음 사건이 없으면 "정보 지연"으로 표시하고 기사에게 확인합니다. 이때 마지막 위치를 현재 위치처럼 보여 주지 않습니다.
3. 지연 사유와 운송사 귀책 여부를 기록합니다. 귀책은 운임 정산의 근거가 됩니다.
4. 07시에 끝나지 않은 운행은 야간 배차 담당이 주간 운영 담당에게 미결 목록으로 넘깁니다.
