# PMart 간선 운송 이관요청서 접수·출고 물량 집계 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 중앙 물류센터에서 MFC 센터로 상품을 보내는 간선 운송에서, 이관요청서를 받아 검증하는 기준과 실제 출고 물량을 집계하는 절차를 정합니다.

## 제2조 (용어)
1. "이관요청서"는 중앙 물류센터 재고관리가 발행하는 중앙 물류센터에서 MFC 센터로의 재고 이동 요청입니다. 운송 실행이 아니며, 출차 전까지 새 버전으로 바뀔 수 있습니다.
2. "운송지시서"는 차량 1대의 운행 1회(배차)입니다. 운송지시서 1건에 이관요청서 여러 건을 실을 수 있지만, 이관요청서 1건은 운송지시서 1건에만 연결됩니다.
3. "롤테이너(R/T)"는 박스를 실어 옮기는 운반 용기입니다. 적재 용량은 롤테이너 수로, 수량 검증은 박스 바코드로 합니다. 팔레트는 간선 운송에 쓰지 않습니다.

## 제3조 (참여자와 권한)
| 참여자 | 하는 일 | 할 수 없는 일 |
|---|---|---|
| 배차 담당 | 이관요청서 확인, 배차 계획, 잔량 배분, 용차 요청, 예외 승인, 일 배차 마감 | 이관 수량·목적지 변경, 재고 조정 |
| 운송사 | 차량·기사 지정과 수정, 대체 차량 등록, 운임 확인 | 물량 배분 변경, 노선 변경 |
| 기사 | 입차·상차완료·출차·도착·인계 기록, 적재함 온도 기록 | 수량 수정, MFC 센터 인수 확인 |
| 중앙 물류센터 상차 작업자 | 박스 스캔, 롤테이너 적재, 상차 수량 확정 | 배차 변경 |
| MFC 수령 담당 | 하차 박스 스캔, 인계 확인(인수 서명), 수량 차이 등록 | 운송지시서 변경 |
| 주간 운영 담당 | 야간에 끝나지 않은 운행의 관제와 예외 마무리 | — |

간선 운송은 재고 수량을 직접 바꾸지 않습니다. 중앙 물류센터의 출고 처리와 MFC 센터의 입고 확정은 각 센터가 합니다.

## 제4조 (이관요청서 발행 단위)
1. 이관요청서는 출발 센터, 목적 MFC 센터, 출고 예정일, 온도대(상온·냉장·냉동)마다 1건씩 발행합니다.
2. 이관요청서에는 상품별 요청 수량과 중앙 물류센터가 실제로 확보한 할당 수량, 할당 상태(미할당·할당·부분할당·취소)가 담깁니다.
3. 간선 운송은 이관요청서의 상품별 수량을 바꾸지 않습니다.

## 제5조 (이관요청서 자동 검증)
이관요청서를 받으면 아래 순서로 검증해 수용·보류·반려·제외를 판정합니다.

| 순서 | 검증 | 맞지 않을 때 |
|---|---|---|
| 1 | 요청서 번호, 출발지, 목적지, 온도대, 출고 예정일, 상품 상세가 모두 있음 | 반려 |
| 2 | 출발지가 칠곡 중앙 물류센터이고, 목적지가 등록되어 사용 중인 MFC 센터이며, 출발지와 목적지가 다름 | 반려 |
| 3 | 목적 MFC 센터의 주소·하차 정보가 확인됨 | 보류(기준정보 보완 대기) |
| 4 | 같은 번호·같은 버전으로 다시 들어옴 | 내용이 같으면 무시하고 기존 결과 유지, 다르면 충돌로 반려 |
| 5 | 같은 번호의 새 버전이 들어옴 | 출차 전이면 변경을 반영해 배차를 다시 계산, 출차 뒤면 반려 |
| 6 | 할당 상태 | 할당은 수용, 부분할당은 할당 수량만 수용, 미할당은 보류(할당 대기), 취소는 제외 |
| 7 | 21시 30분 이후에 들어옴 | 배차 담당이 승인할 때만 당일 배차, 아니면 다음 날로 넘김 |
| 8 | 예상 롤테이너 수가 그 온도대 차량의 최대 용량 이하 | 보류, 중앙 물류센터에 요청서를 나눠 다시 발행해 달라고 요청 |

1. 수용된 요청서만 배차 대상이 됩니다.
2. 보류·반려된 요청서는 사유, 담당, 필요한 입력과 함께 잔여 물량 화면에 계속 표시합니다. 차량 부족과 정보 누락은 구분해서 표시합니다.
3. 미할당이던 요청서가 나중에 할당되면 새 버전으로 다시 검증합니다.

## 제6조 (출고 물량 집계)
1. 상차 작업자가 단말로 박스 바코드를 스캔해 실제 출고 물량을 집계합니다.
2. 박스를 롤테이너에 실으면서 롤테이너 바코드에 박스를 묶습니다.
3. 집계는 이관요청서와 온도대마다 하며, 22시에 롤테이너 수를 확정합니다. 온도대별·품목별 실제 상차 완료 수량을 관리합니다.

## 제7조 (집계의 확정과 수정)
| 상황 | 처리 |
|---|---|
| 상차 작업자가 집계를 마침 | 이관요청서의 확정 박스·롤테이너 수로 반영 |
| 확정한 뒤 고쳐야 함 | 배차 담당이 승인한 뒤에만 수정하며, 바뀌기 전·후 값과 사유, 승인자를 이력으로 남김 |
| 다른 MFC 센터의 박스를 스캔함 | 단말이 바로 경고하고 상차를 막음 |
| 스캔 수량이 할당 수량보다 적음 | 미상차 예외로 처리(간선 운송 도착·인계·예외 정책) |
| 스캔 수량이 할당 수량보다 많음 | 상차를 막고 중앙 물류센터 재고관리에 확인 |
