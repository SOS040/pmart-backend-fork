# TMS(간선 운송) 사내 정책 문서 — RAG 원고 (초안)

배차 담당·주간 운영 담당·정산 담당 등 직원이 중앙 물류센터 → MFC 센터 간선 운송(배차·상차·출차·관제·인계·예외·마감·운임 정산)에 대해 물을 때 AI 가 근거로 쓸 **직원용 사내 정책 문서** 초안입니다. 고객·라이더에게 공개하는 문서가 아니며, MFC → 고객 배송(라이더)과는 별개입니다. 센터 간 공급의 원칙은 `scm/`, 하차 뒤 MFC 센터의 수령·검수·적치는 `mfc/03-inbound-putaway-move.md` 를 따릅니다.
