# PMart 간선 운송 완료·마감·운임 정산 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 간선 운행의 완료 판정, 배차·운임·정산 마감, 운송사 운임 계산 기준을 정합니다.

## 제2조 (운송완료)
1. 편도 운행은 마지막 MFC 센터의 인계가 끝나면, 왕복 운행은 중앙 물류센터 복귀와 회수 물량 인계까지 끝나면 운송완료가 됩니다. 마지막 인계는 끝났지만 복귀 전인 왕복 운행은 운송완료가 아닙니다.
2. 미결 예외가 있어도 운송완료는 할 수 있으며, 예외는 따로 남습니다.
3. 늦게 들어온 정차 실적은 원래 운송지시서에 연결해 정정하고, 새 운송지시서를 만들지 않습니다.
4. 차량 운송완료, 수량 예외 종결, 일 배차 마감은 서로 다른 완료입니다.

## 제3조 (마감 단계)
| 단계 | 조건 | 담당 |
|---|---|---|
| 운송완료 | 모든 정차 인계 완료(왕복은 복귀까지) | 시스템 |
| 일 배차 마감 | 그날 모든 운송지시서가 운송완료·결행·취소 중 하나이고, 미결 예외에 담당이 지정됨 | 주간 운영 담당 |
| 일 운임 마감 | 운송지시서별 운임 계산 → 운송사 확인(이의 제기) → 확정 | 배차 담당·운송사 |
| 정산 마감 | 운송사별 월간 정산서 확정 | 정산 담당·운송사 |

1. 수량 차이 같은 미결 예외는 마감을 막지 않으며, 담당과 함께 따로 계속 추적합니다.
2. 일 배차 마감 뒤 발견된 실적 오류는 원래 기록을 덮어쓰지 않고 정정 이력으로 반영합니다.

## 제4조 (운임 계산)
1. 정규차 일 운임은 노선·온도대·편도/왕복별 계약 일 단가에 다음을 더하고 뺍니다.
   - 실제 정차 수가 계약 정차 수보다 많으면 추가 정차 요금
   - 하차 대기가 30분을 넘으면 넘은 시간을 30분 단위로 올림한 대기 요금(운송사 귀책이 아닐 때만)
   - 운행하지 않은 날(결행)은 0원
2. 용차 운임은 운행별 확정 운임에 같은 추가 요금 규칙을 적용합니다.
3. 월 정산 금액은 일 운임 마감에서 확정된 일 운임의 합에 정정분을 더하거나 뺀 금액입니다.
4. 계약 일 단가에 이미 포함된 정차는 다시 청구하지 않습니다.
5. 운임이 등록되지 않은 운행은 0원이 아니라 "산정 불가"로 표시하고 마감을 보류합니다.
6. 운임 계산에는 운행 당시의 계약 버전을 적용합니다. 나중에 단가가 바뀌어도 지난 운행 금액은 바뀌지 않습니다.
7. MFC 센터가 인계 뒤 자체로 하는 적치 작업 시간은 기사 대기로 청구하지 않습니다.

## 제5조 (이의 제기와 정정)
1. 운송사가 일 운임에 이의를 제기하면 사건 기록·대기 시간·귀책 증빙과 대조한 뒤 정정 이력을 남깁니다.
2. 마감 뒤 발견된 오류는 정정 이력으로 다음 정산에 반영합니다.
3. 정산서 확정까지가 간선 운송의 범위이며, 실제 송금은 회계 업무입니다.
