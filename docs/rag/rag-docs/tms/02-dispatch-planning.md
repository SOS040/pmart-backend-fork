# PMart 간선 운송 배차 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 간선 운송의 하루 배차 일정, 정규차 배차, 물량 분배와 잔량 배분, 차량·기사 배정, 용차와 대체 차량, 운송지시서와 노선 관리 기준을 정합니다.

## 제2조 (하루 배차 일정)
출고일(D일) 기준으로 다음 일정에 따릅니다.

| 시각 | 업무 | 담당 |
|---|---|---|
| D일 주간 | 공급 물량 결정 → 이관요청서 발행·할당 → 간선 운송 접수 | 본사 공급 담당·중앙 물류센터·배차 담당 |
| 21시 30분 전 | 정규차 기본 배차 자동 생성(예상 물량 기준), 상태 "계획중" | 시스템 |
| 21시 30분 | 중앙 물류센터 이동 출고 작업 완료 | 중앙 물류센터 |
| 22시 | 출고 물량 롤테이너 수 확정, 배차 담당 근무 시작 | 상차 작업자·배차 담당 |
| 22시~22시 30분 | 실제 물량 분배, 잔량 배분, 용차 확정, 운송사 차량·기사 확정 → "계획완료" | 배차 담당·운송사 |
| 22시 30분부터 | 상차 시작(노선별 출차 시각 30분 전부터) | 상차 작업자·기사 |
| 23시부터 | 노선별 출차 시각에 맞춰 차례로 출차 | 기사 |
| D+1일 07시 | 야간 배차 담당 근무 종료, 끝나지 않은 운행을 주간 운영 담당에게 미결 목록으로 넘김 | 배차 담당 |
| D+1일 07시~10시 | MFC 센터 도착·하차·인계(MFC 센터 입고 수령 시간) | 기사·MFC 수령 담당 |

1. MFC 센터 도착은 각 센터의 입고 수령 시간(오전 7시~10시) 안이어야 하며, 수령 시간이 끝나는 10시를 도착 마감으로 봅니다. 수령 시간 안의 하차 예약, 하차면, 하차 순서, 수령 물량 상한은 MFC 입고·품질검사·적치·재고 이동 정책 제2조를 따릅니다.
2. 고객 배달 서비스 시간은 매일 08시부터 24시까지입니다(PMart 배송 권역·배송 가능 지역 정책 제6조). 간선 차량의 도착 기준은 이 서비스 시간이 아니라 제1항의 MFC 센터 입고 수령 시간입니다.
3. 장거리 노선은 23시에 먼저 출차하고, 가까운 노선은 늦게 출차합니다. 노선별 출차 시각은 첫 센터 도착 목표 시각(제1항의 수령 시간 안)에서 주행시간을 뺀 시각으로 하되 23시보다 이르게 하지 않습니다.
4. 상차를 마친 차량은 중앙 물류센터 야드에서 냉장·냉동 장치를 켠 채 기다렸다가 정해진 시각에 출차합니다.
5. 같은 MFC 센터에 같은 시간대 도착이 몰려 하차 대기가 생기면 노선별 도착 시각을 30분 단위로 엇갈리게 편성합니다.

## 제3조 (차량 기준)
1. 차량은 상온·냉장·냉동으로 나뉘며, 차량 한 대에는 한 온도대 상품만 싣습니다.
2. 차량마다 등록된 최대 적재 롤테이너 수와 최대 적재 중량을 모두 넘지 않아야 실을 수 있습니다.
3. 정규차는 정기 계약으로 고정 노선을 다니고, 용차는 부족한 물량이 생겼을 때 운행마다 불러 씁니다.

## 제4조 (정규차 기본 배차 자동 생성)
1. 출고일의 운행 요일에 해당하는 고정 노선과 온도대 조합마다, 계약된 정규차와 기본 기사로 운송지시서 초안("계획중")을 만듭니다.
2. 노선에 속한 MFC 센터의 수용된 이관요청서를 그 운송지시서에 연결합니다.
3. 물량이 없는 노선·온도대도 운송지시서를 만들고 결행 후보로 표시합니다. 결행 여부는 배차 담당이 22시 30분까지 정합니다.
4. 같은 날 다시 실행해도 운송지시서를 중복으로 만들지 않습니다.

## 제5조 (실제 물량 분배)
1. 22시에 롤테이너 수가 확정되면 예상 물량을 실제 물량으로 바꾸고 차량별로 다시 분배합니다.
2. 이관요청서 1건은 반드시 차량 1대에 싣습니다. 여러 차량에 나누어 싣지 않습니다.
3. 잔여 물량 화면에는 아직 배정되지 않은 이관요청서와 차량별 적재 가능 수를 함께 보여 줍니다.

## 제6조 (잔량 배분 순서)
정규차 용량을 넘었거나 노선이 없는 센터의 물량은 다음 순서로 배분합니다.
1. 같은 노선·같은 온도대 정규차에 남은 용량이 있으면 배정합니다.
2. 인접 노선 정규차가 같은 온도대이고, 그 센터를 더해도 방문 센터가 3곳 이하이며, 도착 시각 검증을 통과하면 배정합니다.
3. 그래도 남는 물량은 이관요청서 단위로 묶어 직송 또는 여러 센터 방문 용차를 부릅니다.
4. 22시 30분까지 배정되지 않은 물량은 미배차로 남기고 본사 공급 담당과 중앙 물류센터에 알립니다. 미배차 물량은 화면에서 숨기지 않습니다.

## 제7조 (여러 센터 방문)
1. 차량 한 대는 한 운행에 최대 3곳의 MFC 센터를 방문합니다.
2. 방문 순서는 노선에 정해진 순서를 따르며, 용차는 배차 담당이 정합니다.
3. 상차는 방문 순서의 반대로 합니다. 마지막에 들를 센터의 물량을 적재함 안쪽에 먼저 싣습니다.
4. 한 차량에 실린 물량이라도 센터별 박스·롤테이너·인계 수량은 섞지 않고 따로 관리합니다.

## 제8조 (차량·기사 배정)
1. 배차 담당이 물량 분배를 마치면 운송사가 운송지시서마다 차량과 기사를 직접 입력해 확정합니다.
2. 입력한 차량은 온도대가 맞아야 하고 적재 용량 안이어야 하며, 같은 시간대에 같은 차량이나 기사를 두 운행에 배정할 수 없습니다. 맞지 않으면 입력을 받지 않고 사유를 보여 줍니다.
3. 배차 담당이 직접 배정할 때도 같은 기준을 적용합니다.
4. 모든 운송지시서에 차량·기사가 확정되면 "계획완료"가 됩니다.
5. 운송사가 22시 30분까지 입력하지 않으면 배차 담당에게 알리고 용차로 바꿀지 검토합니다.

## 제9조 (용차와 대체 차량)
| 상황 | 처리 |
|---|---|
| 정규차 용량 부족 | 제6조 순서에 따라 용차를 부름 |
| 출차 전 정규차 고장 | 같은 운송사에 대체 차량 등록을 먼저 요청하고, 안 되면 용차 |
| 기사 결근 | 같은 운송사에서 대체 기사를 지정하고, 안 되면 용차 |
| 용차 등록 | 차량번호·기사·톤수·온도대·확정 운임을 입력 |

1. 대체 차량은 원래 차량과 온도대가 같고 적재 용량이 같거나 커야 합니다.
2. 원래 차량·기사, 대체 사유, 바꾼 시각, 승인자를 모두 기록합니다.

## 제10조 (운송지시서)
1. 운송지시서에는 출고일과 도착일, 노선, 계약 구분(정규차·용차), 운송사·차량·기사, 온도대, 운행 형태(편도·왕복), 연결된 이관요청서, 정차 목록(순서·센터·계획 도착·계획 출발·하차 박스와 롤테이너 수), 적재 합계, 실적을 담습니다.
2. 운송지시서가 바뀌면 버전을 올리며, 기사는 최신 버전으로만 운행할 수 있습니다.

## 제11조 (노선 설계)
1. 정규차는 고정 노선으로 운행하며, 매일 노선을 새로 짜지 않습니다.
2. 고정 노선의 조합과 방문 순서는 경로 계산 도구로 후보를 만들고, 중앙 물류센터 운영팀이 승인해 노선 기준정보에 등록합니다. 고정 노선 변경은 운송사 계약에 영향을 주므로 승인 뒤 적용일을 정해 반영합니다.
3. 22시~22시 30분 잔량 배분 때는 경로 계산 도구가 인접 노선 편입·용차 묶음 후보를 낼 수 있으며, 배차 담당이 골라 확정합니다.
4. 계산 결과는 후보일 뿐이며, 최신 조건으로 다시 검증하고 배차 담당이 확정하기 전에는 운송지시서에 반영하지 않습니다.
5. 안전·용량·시간 같은 필수 조건을 완화해 억지로 편성하지 않습니다. 넣지 못한 물량은 미배차로 드러냅니다.
6. 정해진 시간 안에 후보를 찾지 못하면 "계산 미완료"로 보고 다시 계산하거나 직접 편성합니다. 불가능하다고 단정하지 않습니다.
