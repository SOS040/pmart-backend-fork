# PMart 간선 운송 도착·인계·예외 처리 정책

시행일: 2026년 11월 20일

## 제1조 (목적)
이 정책은 간선 차량이 MFC 센터에 도착해 하차·인계하는 절차, 운송 중 예외 처리, 단계별로 바꿀 수 있는 범위, 회수 운송의 기준을 정합니다.

## 제2조 (하차 절차)
1. 기사가 도착을 기록하고 하차 순서를 받습니다.
2. MFC 수령 담당이 박스 바코드를 스캔합니다. 하차 단계에서는 운송지시서·이관요청서의 운송 수량과 실제 받은 수량을 대조하는 일만 합니다.
3. 박스는 롤테이너째 옮기며, 그 뒤 검수·입고는 MFC 센터 업무입니다(MFC 입고·품질검사·적치·재고 이동 정책).
4. 스캔 결과로 인계 증빙을 만들고, 기사는 정차 출발을 기록한 뒤 다음 센터로 이동합니다.
5. 하차를 바로 시작하지 못하면 대기 시간을 기록하고, 30분을 넘기면 대기 사유와 귀책을 기록합니다.
6. 단말이 연결되지 않은 상태에서 스캔했다면 단말에 저장했다가 다시 연결될 때 같은 건으로 보냅니다. 다시 인계하지 않습니다.

## 제3조 (인계 증빙)
인계 증빙에는 운송지시서·정차 순서·이관요청서, 상차 스캔 기준 출고 수량(박스·롤테이너), 하차 스캔 기준 인수 수량, 차이 수량과 유형(부족·초과·오배송·파손), 인계자(기사)와 인수자(MFC 수령 담당), 도착·인계 완료 시각, 적재함 온도, 결과(일치·불일치)를 남깁니다.

## 제4조 (인계 결과 판정)
1. 출고 수량과 인수 수량이 같으면 "인계완료(일치)"입니다.
2. 다르면 "인계완료(불일치)"로 하고 수량 차이 예외를 등록합니다. 차량 출발은 막지 않으며, 예외는 운행이 끝난 뒤에도 따로 남습니다.
3. 도착 기록만으로 인수를 확정하지 않습니다. 스캔에 따른 인계 증빙이 있어야 정차가 끝납니다.
4. 인계 증빙은 MFC 센터의 입고 확정과는 별개입니다.

## 제5조 (운송 예외 처리)
| 예외 | 처리 |
|---|---|
| 출고 지연(21시 30분에 출고 미완료) | 예상 물량으로 배차해 두고, 상차 시작 전까지 확정되지 않으면 노선 출차 시각을 다시 계산합니다. 도착 마감(간선 운송 배차 정책 제2조)을 지킬 수 없으면 미배차로 하고 본사 공급 담당과 중앙 물류센터에 알립니다. |
| 부분출고(부분할당이거나 스캔 수량이 할당보다 적음) | 실제 스캔 수량으로 운송지시서를 확정합니다. 못 보낸 수량은 같은 이관요청서로 다시 출차하지 않고 중앙 물류센터에 알립니다. 다시 요청할지는 본사 공급 담당과 중앙 물류센터가 정합니다. |
| 미상차 | 배차 담당이 같은 노선 다른 차량으로 이관요청서 단위로 옮기기, 용차, 미배차 회신 중 고릅니다. |
| 용량 초과 | 배차 정책의 잔량 배분 순서를 따릅니다. |
| 출차 전 차량 고장·기사 결근 | 배차 정책의 대체 차량·용차 기준을 따릅니다. |
| 출차 뒤 차량 고장·사고 | 안전을 먼저 확보하고 위치·화물·온도를 기록한 뒤, 배차 담당이 운송사와 직접 처리합니다. 자동 환적·재출차는 없습니다. 도착하지 못하는 센터에는 지연을 알립니다. |
| 도착 지연 | 지연 표시, MFC 센터에 예상 시각 통보, 사유와 운송사 귀책 여부 기록 |
| 수량 부족(인수 < 출고) | 차량 안에 남았는지 바로 확인하고, 없으면 상차 스캔 이력과 대조해 미상차·분실을 판정해 중앙 물류센터에 알립니다. 자동으로 손실 처리하지 않습니다. |
| 다른 센터 박스가 섞임 | 그 박스는 하차하지 않습니다. 같은 운행의 다음 정차가 그 박스의 원래 목적지이면 그곳에 하차하고, 아니면 회수 물량으로 중앙 물류센터에 복귀시켜 다음 날 다시 배차합니다. |
| 온도 이탈 | 해당 화물을 표시하고 MFC 센터 검수 담당에게 알립니다. 판매 가능 여부는 MFC 센터·품질 담당이 판단합니다. |
| 출차 뒤 이관 취소 요청 | 받지 않습니다. 이미 출차한 화물은 원래 목적지에 인계하고, 그 뒤 처리는 MFC 센터와 중앙 물류센터가 합니다. |

## 제6조 (예외 처리 절차)
1. 안전 확보 → 영향 범위(운송지시서·정차·이관요청서·박스) 기록 → 꼭 필요한 행동만 보류 → 담당 지정 → 조치 결과 연결 → 종결 순서로 처리합니다.
2. 한 운행에 예외가 여러 개면 각각 따로 종결합니다. 차량 수리가 끝났다고 수량 차이가 해결된 것이 아니며, 알림을 닫거나 기사와 통화했다고 예외가 해결된 것도 아닙니다.
3. 종결할 때 영향 수량, 조치, 담당, 결과와 귀책(운송사·중앙 물류센터·MFC 센터·기타)을 기록합니다.

## 제7조 (단계별 변경·취소 범위)
| 운송지시서 단계 | 할 수 있는 것 | 할 수 없는 것 |
|---|---|---|
| 계획중 | 물량 이동, 노선 간 이관요청서 이동, 결행, 취소 | — |
| 계획완료 | 대체 차량으로 차량·기사 교체, 물량 재분배("계획중"으로 되돌림), 취소 | 운송사 확인 없는 차량 변경 |
| 상차완료(출차 전) | 이관요청서를 내려 다른 차량으로 옮기기(하차 스캔으로 실물 확인), 출차 시각 조정 | 스캔 없이 시스템에서만 물량 이동 |
| 출차완료(운행 중) | 지연 통보, 남은 정차 예상 시각 재계산 | 목적지 변경, 정차 추가, 출차 취소 |
| 인계 뒤 | 인계 증빙 정정(승인 필요), 수량 차이 조사 | 인계 기록 삭제 |
| 배차 마감 뒤 | 정정 이력 추가(승인자·사유) | 원래 기록 덮어쓰기 |

1. 이관 취소 요청이 출차 전에 오면 해당 이관요청서를 운송지시서에서 빼고 다시 분배합니다. 출차 뒤면 거부하고 이미 출차했다고 알립니다.
2. 출차완료 뒤에는 "계획중"이나 취소로 되돌리지 않습니다.

## 제8조 (회수·왕복 운송)
1. 운송사 계약에 왕복·편도를 등록하고, 운송지시서에 운행 형태를 정합니다.
2. 빈 롤테이너는 왕복 운행의 회수 대상입니다. 회수 물량도 박스·롤테이너 바코드를 스캔해 회수 증빙을 남깁니다.
3. 편도 계약 차량에는 회수를 배정하지 않습니다. 회수가 필요한데 왕복 차량이 없으면 회수 전용 용차를 부릅니다. 회수 정차는 출차 전에만 추가합니다.
4. 고객 반품·오배송 회수품은 간선 회수 대상이 아닙니다. 이 상품은 MFC 센터가 받아 검수하며, MFC 입고·품질검사·적치·재고 이동 정책 제10조를 따릅니다.
5. 출차한 뒤 화물의 목적지를 바꾸는 일은 하지 않습니다. 다른 센터 박스가 섞인 경우의 중앙 물류센터 복귀는 제5조를 따릅니다.
