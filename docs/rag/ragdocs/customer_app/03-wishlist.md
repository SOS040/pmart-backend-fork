# 찜

## 찜은 어떻게 하나요?

- 상품의 **하트**를 누르면 찜 목록에 담겨요. 한 번 더 누르면 빠져요.
- 찜은 **로그인한 회원만** 할 수 있어요. 비회원은 로그인 후 이용해 주세요.
- 찜은 상품 단위예요. 크기·용량 같은 옵션은 장바구니에 담을 때 골라 주세요.

## 찜은 몇 개까지 할 수 있나요?

- **200개**까지 찜할 수 있어요. 더 찜하려면 찜 목록에서 몇 개를 빼 주세요.

## 찜한 상품이 품절됐어요

- 품절되거나 판매가 끝난 상품도 **찜 목록에 그대로 남아요.** 목록에 "품절" 또는 "판매 종료"로 보여요.
- 품절 여부는 지금 고른 배송지를 담당하는 센터 기준이에요. 배송지를 바꾸면 달라질 수 있어요.
- 찜한 상품이 다시 들어왔을 때 알려 드리는 **재입고 알림은 아직 제공하지 않아요.**

## 찜한 상품 가격이 달라졌어요

- 찜 목록의 가격은 **지금 가격**이에요. 찜했을 때 가격으로 살 수 있는 건 아니에요.
- 찜을 해도 재고나 가격이 따로 잡혀 있지는 않아요. 주문할 때 가격과 재고를 다시 확인해요.

## 탈퇴하면 찜은 어떻게 되나요?

- 탈퇴가 끝나면 찜 목록도 지워져요. 다시 가입해도 이어지지 않아요.
