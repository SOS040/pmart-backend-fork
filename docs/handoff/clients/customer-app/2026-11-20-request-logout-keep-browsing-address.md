# 요청 — 로그아웃 때 "지금 주소로 계속 둘러볼까요?" (customer 0.14.0)

- 보낸 영역: platform (PC 1)
- 작성: pmart-backend, 2026-11-20 — 사용자 "로그아웃 했을 때 주소 선택 바로 요구하는데 비회원 내용은 기억해두는게 어때" → "너 추천대로 해줘"(2번: 물어보고 도로명·위치만 옮기기)
- 상태: 아래 "배포 상태" 줄

## 지금 문제
- 로그아웃은 토큰만 지우고 비회원 배송지 기억(`GuestAddressStore`)은 남긴다 — 그런데 처음부터 회원으로만 쓴 기기는 비회원 배송지가 없어 로그아웃 즉시 주소 선택 화면이 뜬다.

## 서버 변경 (customer 0.14.0)
- 비회원 배송지 `POST /api/v1/guest-delivery-addresses` 는 **`detailAddress` 없이도** 201(도로명·`geo` 만 — 둘러보기용). 응답 `detailAddress` 는 없을 수 있다.
- 회원 주소록 `/me/addresses` 는 지금처럼 `detailAddress` 필수(없거나 공백이면 400 VALIDATION_FAILED).
- 비회원은 주문하지 않으므로(로그인 필요) 상세 주소·받는 분·연락처는 주문 때 회원 주소록에서 받는다.

## 앱에 부탁
1. 로그아웃 확인 화면에서 회원의 **현재 쇼핑 주소**가 있으면 "지금 주소로 계속 둘러볼까요?" — [예] [아니요].
2. [예]: `POST /guest-delivery-addresses` 에 **`roadAddress`·`postalCode`·`geo` 만** 보낸다(상세 주소·받는 분·연락처·출입 메모는 보내지 않음 — 공용 기기에 개인정보를 남기지 않기). 결과 ID 를 `GuestAddressStore.add` + `select`.
3. [아니요] 또는 쇼핑 주소가 없으면 지금처럼(다음 화면에서 주소 선택).
4. 이미 이 기기에 비회원 배송지가 있으면 묻지 않고 그 주소를 쓴다(지금 동작).

## 배포 상태
- (작성 시점) 서버 구현·시험 끝(customer check 통과), LAN 배포 전.
