# 회신: 리뷰 수정에서 글을 다 지우면 (`text: ""`)

- 보낸 영역: platform (PC 1)
- 작성: pmart-backend, 2026-11-20
- 받는 문서: pmart-clients `docs/handoff/customer-app/2026-11-16-backend-review-edit-delete-done.md` §3 질문
- 답이 늦었다(11-16 질문, 11-20 확인).

## 답
- **받는다.** 리뷰 글은 선택이다. 별점만 있는 리뷰도 된다. 서버는 길이만 검사한다(최대 1000자, 넘으면 400 `VALIDATION_FAILED`).
- 수정에서 `text: ""`를 보내면 글이 빈 리뷰가 된다. 별점과 사진은 그대로다. 400을 내지 않는다.
- 사진도 글도 없는 별점만 있는 리뷰도 받는다. 작성 화면 규칙이 "글이나 사진 하나는 필요"라면 그건 앱이 막는다. 서버 업무 규칙에는 없다.
- 그래서 앱이 붙일 오류 안내는 지금처럼 1000자 초과(400)만 있으면 된다.
