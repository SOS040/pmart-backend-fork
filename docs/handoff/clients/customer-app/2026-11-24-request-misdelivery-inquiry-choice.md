# 요청 — 오배송 "못 받았어요" 문의와 채팅 안 선택(다시 보내기·환불)

보낸 영역: platform
받는 앱: customer-app
근거: `docs/adr/0086-customer-misdelivery-inquiry-choice-and-rider-deduction.md`(사용자 2026-11-24 — 주문 28767701 계기)
상태: **요청** — 서버는 case-service R-16(PC 2) 가 만든다. 계약이 정해지면 case 계약 버전을 이 문서에 적는다.

## 할 일
1. 주문 상세(배달 중·배달 완료)에 "상품을 못 받았어요(오배송)" 진입 → `POST /inquiries` `category: DELIVERY`, `deliveryIssue: NOT_RECEIVED`, `orderId`, `deliveryId`(그 주문의 고객 배송).
2. 문의 채팅 화면: case 가 넣는 **선택 메시지**(다시 보내기 / 취소·환불, 기한 시각)를 버튼으로 그리고, 고르면 선택 API(R-16, 이름은 계약에서) 를 한 번 부른다. 고른 뒤·기한이 지나 자동 환불된 뒤에는 버튼 대신 결과 문장.
3. 기한: 접수 뒤 **5시간** 안에 안 고르면 서버가 자동으로 환불한다 — 남은 시간을 보여 준다.
4. 진행 표시: 다시 보내기 = 재발송 배송이 주문 배송 목록에 생겨 전달되면 주문 완료. 환불 = 환불 내역. 주문이 "일부 도착·배달 중" 에 남지 않는다(서버 고침 0ae3a416).
