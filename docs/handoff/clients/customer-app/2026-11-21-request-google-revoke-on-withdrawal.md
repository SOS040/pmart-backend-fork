# 요청 — 탈퇴할 때 구글 연결 끊기(다시 가입하면 동의 화면이 뜨게)

보낸 영역: platform
받는 앱: customer-app
작성: pmart-backend, 2026-11-21 — 사용자 "권한 동의는 로그인할 때마다가 아니라 처음 가입할 때만", "1, 2 둘다 해줘"

## 배경 — 세 제공자를 같은 규칙으로
- 규칙: **동의(정보 제공) 화면은 처음 가입할 때만.** 탈퇴하면 제공자와의 앱 연결을 끊어, 다시 가입할 때 동의 화면이 다시 뜨게 한다.
- 카카오: 서버가 탈퇴 반영 뒤 Admin 키로 연결을 끊는다(auth 289a989a) — **앱 할 일 없음**.
- 네이버: 탈퇴 재인증(`purpose: WITHDRAWAL` 교환) 때 서버가 끊는다(BR-74 (C), 이미 있음). LAN 시험용 "로그인마다 끊기"(`unlink-after-exchange`)는 **2026-11-21 껐다** — 이제 로그인할 때 동의 화면이 다시 뜨지 않는다(처음 가입 때만). **앱 할 일 없음**.
- 구글: 서버는 ID 토큰만 받아(ADR-0055) 구글 연결을 끊을 토큰이 없다 → **앱이 끊어야 한다.**

## 요청
- **R1.** 탈퇴가 서버에서 받아들여진 뒤(탈퇴 요청 성공 응답 — 탈퇴 대기 시작) 로그인 제공자가 GOOGLE 이면 Google Sign-In 의 **`revokeAccess()`**(Android `GoogleSignInClient.revokeAccess()`, Credential Manager 를 쓰면 그에 대응하는 연결 해제)를 한 번 부르고, 이어서 로그아웃(`signOut`)을 해 주세요.
  - `signOut` 만으로는 연결(동의)이 남아 다음 가입 때 동의 화면이 뜨지 않는다 — `revokeAccess` 가 필요.
  - 실패(오프라인 등)해도 탈퇴 흐름은 그대로 진행(사용자에게 오류를 보이지 않음). 로그에 토큰·이메일을 남기지 않기.
- **R2.** 탈퇴 요청이 실패하거나 사용자가 취소하면 끊지 않는다(계정이 살아 있는데 연결만 끊기지 않게).
- **R3.** 로그인할 때는 끊지 않는다(로그인마다 동의 화면이 뜨면 안 됨).

## 확인 방법
- 구글로 가입 → 탈퇴 → 같은 구글 계정으로 다시 가입: 구글 동의(이메일·프로필 제공) 화면이 다시 떠야 한다.
- 탈퇴하지 않고 로그아웃 → 다시 로그인: 동의 화면 없이 바로 로그인.

## 서버 상태
- 카카오 끊기: auth 289a989a(+ pmart-config 4c25f19 Admin 키) — LAN 재배포 진행 중.
- 네이버 로그인마다 끊기 끔: pmart-config 80bbe9d — auth-service 재시작 뒤 적용.
