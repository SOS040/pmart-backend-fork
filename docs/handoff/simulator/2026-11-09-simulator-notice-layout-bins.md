# [공지] 시험 센터 칸을 시뮬레이터 평면대로 다시 등록 (2026-11-09)

- 결정: 사용자 2026-11-09 — **MFC 도면 = 시뮬레이터 평면(임시 시험 MFC 한 곳)**, 백엔드 시험 센터 `MFC-SEED-01` 의 칸을 그 평면대로 다시 등록(scope L-1). 도면은 MFC 마다 다르다(ADR-0050).
- 근거 문서(백엔드): `docs/simulator/scope.md`, `docs/simulator/layout/README.md`(도면·대응표), `docs/simulator/mfc-simulator-integration.md` SIM-6 보완.
- 커밋: `e4d4e81`(mfc-location 0.6.0 좌표), `6bb0632`(등록·이전 스크립트), 이 공지와 같은 커밋(시험용 고회전 칸).

## 1. 무엇이 바뀌었나
- `MFC-SEED-01` 의 선반이 **시뮬레이터 `buildLayout()` 평면 그대로**다 — 랙 368, 칸 6,762, 보충재고 팔레트 32, 패킹대 8, 격리 3, 수령, 외부 출하대기 랙 2. 랙·단·칸 구조와 좌표가 평면과 같다.
- **칸 코드는 백엔드 문법**(ADR-0042)이다. 시뮬레이터 코드에서 이렇게 바꾼다:

| 시뮬레이터 | 백엔드 | 규칙 |
|---|---|---|
| `A01-01-101` (그룹-랙-단·칸) | `F-A1-01-1-01` | `{온도대 A 상온·C 냉장·F 냉동}-{그룹 글자 + 줄 번호}-{랙 2자리}-{단}-{칸 2자리}` — 그룹 글자는 시뮬레이터 그대로(A 냉동·B 냉장·C~H 상온) |
| 상온 `C01-03-205` | `A-C1-03-2-05` | 같은 규칙 |
| 보충재고 팔레트 `AR-1` 등 | `{A/C/F}-R1-{번호}-1-01` | 온도대별 번호(냉동 4·냉장 4·상온 24) |
| 패킹대 PS-1~8 | `PAK-A-01`~`08` | 기존 `PAK-C-01`·`PAK-F-01` 은 패킹 대기 지점 좌표 |
| 격리 AQ·BQ·CQ | `QRT-F-01`·`QRT-C-01`·`QRT-A-01` | |
| 입고·검수 | `RCV-A-01` | |
| 외부 출하대기 랙 1·2 | `DSP-A-01`·`02` | |
| 장바구니 보관 | `CRT-A-01`·`02`·`CRT-C-01`·`CRT-F-01` | |

- 위치 조회 `GET /api/v1/locations?mfcId=MFC-SEED-01&state=ACTIVE&size=200`(쪽 넘김 `cursor`, 약 6,900개 — **모든 쪽을 읽어야** 포장·카트 위치가 나온다)에 새 필드:
  - `position {xM, zM}`(mfc-location 0.6.0): 작업자가 서서 집는 지점, 미터, 평면 좌표계(x 동쪽, z 남쪽, 원점 건물 북서 모서리) — 시뮬레이터 `Location.pick` 과 같은 값.
  - `pickSequence`: 평면의 칸 순서(시뮬레이터 `locations` 배열 순서).
  - `dimensions`: 상온 칸 281×450×350 mm, 냉장·냉동 375×450×420 mm(랙 규격으로 계산), 팔레트 자리는 평면 사각형 × 높이 1.2 m(임시).
  - `highTurnover`: **선반 칸은 일반 선반(false) — 임시**(사용자 결정, 나중에 특정 그룹만 고회전). E2E 시험용 고회전 칸만 true: `A-H1-01-1-01`~`04`·`A-H1-01-2-01` = 시뮬레이터 `H01-01-101`~`104`·`H01-01-201`(상온 H01 줄 1번 랙). 백엔드 도면(`docs/simulator/layout/floorplan.svg`)에 빨간 랙으로 표시했고, 목록은 `docs/simulator/layout/high-turnover.json`(백엔드·시뮬레이터 코드, 랙, 좌표).
- 재고: 옛 시험 선반의 재고를 새 칸으로 옮겼다 — **SKU 하나 = 칸 하나**(같은 온도대, 평면 칸 순서 앞에서부터). 약 505개 칸만 재고가 있고 나머지는 비어 있다. 시뮬레이터의 가상 SKU 900개가 아니라 실서버의 실제 SKU(약 500개)다.

## 2. 시뮬레이터가 맞출 것 (SIM-6)
1. 실서버 모드에서 칸 코드를 위 규칙으로 바꿔 매긴다(또는 백엔드 위치 목록의 `position` 으로 칸을 찾는다 — 같은 좌표).
2. 선반 재고는 백엔드 재고(SKU·LOT·칸)로 그린다 — 칸마다 SKU 하나, 빈 칸 많음.
3. 고회전·보충: 시뮬레이터 화면에도 이 5칸(H01-01 랙)을 고회전으로 표시해 주세요. 실서버에서는 시험용 5칸만 자동 보충 대상이다(보충 기준이 등록된 칸만, 지금 등록된 기준 없음). 시뮬레이터의 "모든 칸을 보충재고에서 채움"은 MOCK 모드 표현으로 남긴다.
4. 도면 밖 위치: `RTN-A-01`(회수), `MIGRATION`(이관용 가상 위치)은 평면에 자리가 없다 — 표시하지 않거나 입고·검수 근처에 둔다.
