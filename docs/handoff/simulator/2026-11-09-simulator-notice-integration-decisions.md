# [공지] 실서버 연결 결정과 백엔드 현황 (2026-11-09)

설계·결정 정본: `pmart-backend/docs/architecture/mfc-simulator-integration.md`(SIM-1~11). 요약:

## 결정 (시뮬레이터가 맞출 것)
- **SIM-1 (임시)**: 실서버 모드는 1× 실제 시간. 배속은 MOCK 모드 전용. 센터 시간 설정은 하지 않는다(SIM-1a) — 시간 판단은 현재 실제 시각 기준.
- **SIM-2**: 실제 PDA 작업자는 로그인 + 권한으로 구분 — 시뮬레이터는 자기 가상 작업자 계정만 움직이고, 그 밖의 작업자는 실제 사람으로 본다. PDA 버튼(배정·시작·피킹 칸·이동 집기/내려놓기) 기준으로 실제 작업자를 따라가는 표시는 **마지막 버튼 기준**(SIM-2a) — 실제 작업자를 마지막 버튼의 칸 앞에 두고 다음 버튼까지 그 칸 사이를 걷게. 지금 API(`GET /assignments`·`GET /tasks`·작업 상세 `lines[].picks`·`GET /move-orders`)로 조합.
- **SIM-3 (R-02 회신)**: 가상 작업자 = 시뮬 센터 전용 **실제 운영자 계정**(그 센터 권한·`MFC_WORKER`), 로그인 API 로 토큰. 대행 헤더 방식은 하지 않는다.
- **SIM-4 (임시)**: 실서버 모드에서는 가짜 주문을 넣지 않는다(실제 고객 앱 주문만). 가짜 주문 실서버 투입은 나중 요구(SIM-4a).
- **SIM-6**: 백엔드 기준 — 시험 센터 `MFC-SEED-01` 의 위치 코드(`A-S9-01-1-01` 형식)·재고·작업을 읽어 그린다. 시뮬레이터 평면·칸 코드(`C01-03-205`)를 맞춰 주세요.
- **SIM-7 (R-07 회신)**: 배송 서비스가 아직 없음 → 실서버 모드는 출하 대기까지, 라이더 인계는 MOCK. 배송 구현 뒤 라이더 시험 계정.
- **SIM-8 (R-03 회신)**: 별도 출처 필드 없이 시뮬 센터·시뮬 계정으로 구분.
- **SIM-9**: 실행 끝에 API 로 정리(열린 작업 중지·복귀, 되돌리는 이동). 본보기 `pmart-backend/deploy/lan/checks/mfc_e2e.py`.
- **SIM-5**: 주기 조회(시작 3초). 재고는 작업에 나온 SKU 만·바뀌었을 때만 — SKU 전체 반복 조회 금지.
- **SIM-10**: LAN 서비스 배치는 그대로. 가상 작업자 수는 조회 부하를 보며 늘린다.
- **SIM-11**: Vite 개발 서버 프록시로만 게이트웨이에 접속(CORS 변경 없음). 가상 작업자 비밀번호는 Vite 서버 쪽 비밀 파일(Git 금지)에서 읽어 로그인, 브라우저에는 토큰만.

## 백엔드 현황 — `docs/backend-requests.md` 대비
| R | 상태 |
|---|---|
| R-01 점원 단말 작업 흐름 | 구현 — 작업 목록·상세·시작·실행·포장·인계 허가/확정, 그리고 **다음 작업 받기** `POST /mfcs/{mfcId}/workers/{workerId}/next-tasks`(응답 `detail` 에 칸·LOT·수량) |
| R-02 가상 작업자 인증 | SIM-3 으로 결정(위) |
| R-03 출처 표시 | SIM-8 로 결정(위) |
| R-04 센터 전체 작업 조회 | `GET /tasks?mfcId=&state=`(센터 권한자) · `GET /assignments` 구현 |
| R-06 작업 배정 경로 | 수동 배정 `POST /assignments`(센터 관리자) + 배정 추천 `POST /assignment-plans`(OR-Tools, 확정 `…/commits`) |
| R-07 가상 라이더 배차 | SIM-7 (배송 서비스 대기) |
| R-10 보충 이동 | mfc-inbound `/move-orders`(이동·보충, 집기·내려놓기) |
| R-05·R-08·R-09·R-11 | 각 계약(mfc-inventory·mfc-location) 확인 바람 — 이번 공지에서 다시 점검하지 않음 |
| R-12 OR-Tools·Chronos-2 | OR-Tools 는 mfc-capacity 안(Java), Chronos-2 미적용(Python 런타임 없음) |
- 용어: "감독자" → **센터 관리자**(역할 코드 `MFC_SUPERVISOR` 그대로).
