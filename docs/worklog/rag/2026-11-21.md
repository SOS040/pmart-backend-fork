# 2026-11-21 rag (PC 4)

## 운영자 RAG 채팅 세션 (요청 2번, ADR-0084)
- 요청: "하나의 채팅 세션에서 여러 번 질문", "백오피스에서 자기 채팅 개별 삭제", "보존 14일". 사용자 결정: 운영자만 / 앞 대화 반영 / 마지막 질문에서 14일 / 기존 기록은 질문마다 세션 하나.
- 한 일: V2 `chat_session` + `policy_answer.session_id`(CASCADE, 기존 답변 → 세션 하나씩). 질문 `sessionId`(없으면 새 세션, 남의 세션 404, 요청 해시에 세션). 앞 대화 최근 2턴 — 이어지는 질문이면 직전 질문을 붙여 검색(`FollowUp`), 생성에는 `<history>`(근거 아님, 규칙 9). `GET /assistant/chat-sessions`·`GET·DELETE /{sessionId}`(삭제 Idempotency-Key, 204 멱등). 보존 정리를 세션 마지막 질문 기준으로. 계약 1.3.0, 백오피스 요청 `docs/handoff/clients/backoffice/2026-11-21-request-assistant-chat-sessions.md`.
- 시험(PC 4): ai-assistant check — test 129·integrationTest 40 통과(ChatSessionIT·FollowUpTest 새로, 기존 보존 시험은 세션 기준으로 고침). V2 마이그레이션은 로컬 pgvector 임시 DB 에 V1 + 기존 답변 2건 → V2 적용 → 세션 2개·CASCADE 삭제 확인 후 DB 삭제.
- 확인 안 한 것: 앞 대화가 실제 생성 모델(qwen3:4b) 답에 주는 영향(시험은 해시 임베딩·발췌 기준선).
- 남은 것(PC 1): pmart-config `ai-assistant-service.yml` 의 `retention: 14d` 를 켜야 보존 정리가 돈다(켜면 14일 지난 기존 기록은 첫 정리 때 지워짐).
