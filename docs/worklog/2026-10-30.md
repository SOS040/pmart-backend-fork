- 결정(추천 채택): React 앱은 PC4(D603-16) Nginx 80 포트 → 허용 출처 `http://d603-16`(80 은 출처에 포트가 붙지 않음. DHCP 라 IP 대신 컴퓨터 이름)
- 한 일:
  - `deploy/lan/cors-origins.conf`(허용 출처 목록, git 추적) — `render.sh` 가 읽어 api-gateway 에 `PMART_GATEWAY_CORS_ALLOWEDORIGINS` 로 넣는다
  - Helm `gen-values.sh`: api-gateway 에 `PMART_GATEWAY_CORS_ALLOWEDORIGINS: ""`(운영 도메인 정해지면 환경별 values) — 다시 생성하면서 빠져 있던 `values/cdc-inventory-service.yaml` 도 생김
  - `deploy/lan/README.md` 파일 표, 프론트 안내 0장 2번(LAN 출처·접속 주소)
- 검증: `deploy/lan/render.sh` 실행 → `build/pc4/compose.yml` api-gateway 에 `PMART_GATEWAY_CORS_ALLOWEDORIGINS: "http://d603-16"` 확인(배포는 안 함). `gen-values.sh` 결과 확인
- 미결:
  - LAN 의 api-gateway·auth-service 이미지는 CORS·운영자 로그인 이전 것 — 새 이미지 push(Jib)와 재배포가 필요(요청 시)
  - LAN auth 첫 관리자(`PMART_AUTH_OPERATOR_BOOTSTRAP_*`)를 `.secrets`·render 에 넣는 일(비밀번호 해시 생성 포함)
  - 대안 참고: Nginx 가 `/api` 를 게이트웨이로 프록시하면 같은 출처라 CORS 가 필요 없다
