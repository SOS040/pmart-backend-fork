## 로그아웃 즉시 차단·백오피스 CSP·HTTPS
- 요청: CSRF 는 미룸("그 작업 일단 기억해두고") → "로그아웃 즉시 차단·CSP·백오피스 HTTPS 이거 세개부터 하자".
- 로그아웃 즉시 차단: 계약 SubjectBlocked 에 선택 `sessionId`·reason LOGOUT/LOGOUT_ALL/TOKEN_REUSED·userType GUEST. 게이트웨이 Redis 키 (iss, sid) 추가, 요청마다 주체·세션 중 늦은 차단 시각으로 판정. employee-auth-service·auth-service 가 로그아웃(세션/모든 기기)·refresh 재사용 때 발행. 시험: 게이트웨이 단위 7(세션 2 추가), employee-auth EmployeeLoginIT(LOGOUT·TOKEN_REUSED 사건), auth-service GuestSessionIT(GUEST LOGOUT) 통과. LAN: 같은 사람 세션 둘 중 하나 로그아웃 → 그 토큰 0.6초 만에 401 SUBJECT_BLOCKED, 다른 세션 200.
- CSP: 두 앱 공통 nginx 에 CSP(self 스크립트·스타일, 게이트웨이 API·이미지, frame-ancestors none)·nosniff·X-Frame-Options·Referrer-Policy. 빌드에 인라인 스크립트·eval·동적 style 없음 확인, 헤드리스 Chrome(HTTPS 로그인 화면) CSP 위반 0.
- HTTPS: nginx 443 ssl(PC 4 인증서) — 백오피스 443, 인사팀 8444(HTTP 80·8081 유지). 허용 목록(게이트웨이 CORS, employee-auth 복귀, Keycloak 로그아웃 — LAN 관리 API 로도) https 추가. 확인: 4개 주소 200·같은 빌드·헤더, CA 로 인증서 검증(IP·d603-16), HTTPS 로 두 앱 로그인·SSO·로그아웃.
- 남은 것: 클라이언트 lan 빌드 API 주소가 http 8080 이라 HTTPS 화면에서는 혼합 콘텐츠로 API 가 막힘 → 클라이언트가 https 8443 으로 빌드해야 함(알림 `2026-11-13-clients-notice-backoffice-https-csp-logout.md`). 그 뒤 HTTP 닫기(T3)는 사용자 결정. PC 4 앱 6개 재시작은 여전히 대기.
- 배포 전 라이브 빌드와 백엔드 사본 같음 확인 후 PC 4 배포(덮어쓰기 재발 없음).
