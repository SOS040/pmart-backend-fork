# PMart 고객센터 안내 문서 (고객용 RAG 원고 — 초안)

- 문서 버전: 0.1 (초안 — 사용자 승인 전. 저장소에는 있으나 **어느 RAG 에도 색인하지 않음** — 승인 뒤 고객용 RAG(customer-assistant-service) 색인 대상으로)
- 작성일: 2026-11-09
- 승인: Claude 초안 → 사용자 승인(2026-11-09 결정 C1)
- 기준: PMart 업무 문서의 확정 정책·채택 설계, ADR-0049·0052. 고객에게 알려도 되는 내용만 담았습니다(내부 처리 절차·라이더 지급·귀책 판단 기준·내부 승인 단계는 넣지 않음).

## 작성 규칙

- 고객에게 말하는 말투(~해요/~드려요). 상담원 대본·내부 용어는 쓰지 않습니다.
- 절 제목 끝 지위 태그: `[확정 정책]`·`[채택 설계]`(업무 문서 근거), `[설계안]`(이 문서에서 정한 안내 방식), `[결정 필요]`.
- 주문마다 다른 내용(내 주문 상태·금액)은 문서가 아니라 **최근 주문 목록 조회**로 답합니다(2026-11-09 결정 C6 — 구현 전).

## 근거가 없을 때 (결정 C4 — 문구는 Claude 가 정함)

AI 가 문서에서 답을 찾지 못하면 아래 문구와 함께 **고객센터 문의 남기기**로 연결합니다.

> 이 문의는 지금 바로 답변드리기 어려워요. 고객센터에 문의를 남겨 주시면 담당자가 확인한 뒤 앱 알림으로 답변드릴게요.
> [고객센터에 문의 남기기]

- 주문에 대한 문의면 주문을 고른 상태로 문의가 접수되게 합니다.
- 결제·개인정보처럼 확인이 필요한 질문도 같은 연결을 씁니다.
