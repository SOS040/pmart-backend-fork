- 고치면: 사용자 승인 → manifest 확인 → `deploy/lan/lan.sh render` → `lan.sh rag-ingest-customer pc2`

## 작성 규칙

- 고객에게 말하는 말투(~해요/~드려요). 상담원 대본·내부 용어는 쓰지 않습니다.
- 절 제목 끝 지위 태그: `[확정 정책]`·`[채택 설계]`(업무 문서 근거), `[설계안]`(이 문서에서 정한 안내 방식), `[결정 필요]`.
- 주문마다 다른 내용(내 주문 상태)은 문서가 아니라 **최근 주문 목록·주문 상세 조회**로 답합니다(2026-11-09 결정 C6 — customer-assistant-service 가 정해진 문장으로 답함, 모델에 주문 정보를 넘기지 않음).

## 근거가 없을 때 (결정 C4 — 문구는 Claude 가 정함)

AI 가 문서에서 답을 찾지 못하면 아래 문구와 함께 **고객센터 문의 남기기**로 연결합니다.

> 이 문의는 지금 바로 답변드리기 어려워요. 고객센터에 문의를 남겨 주시면 담당자가 확인한 뒤 답변드릴게요.
> (버튼 위) 고객센터에 문의를 남겨 주시면 담당자가 확인한 뒤 답변드릴게요. 답변은 고객센터의 내 문의에서 확인할 수 있어요.
> [고객센터에 문의 남기기]

- 2026-11-09 고침: "앱 알림으로" → "내 문의에서 확인" — 답변 알림(notification-service)이 아직 없다. 알림이 생기면 되돌린다.

- 주문에 대한 문의면 주문을 고른 상태로 문의가 접수되게 합니다.
- 결제·개인정보처럼 확인이 필요한 질문도 같은 연결을 씁니다.
