# 반품·교환

## 언제까지 신청할 수 있나요? [확정 정책]

| 경우 | 기한 |
|---|---|
| 일반 반품·교환 | 상품을 **받은 뒤 7일 이내** |
| 냉장·냉동 등 신선식품 | **받은 뒤 24시간 이내** |
| 상품 하자·잘못 온 상품·광고와 다른 상품의 **교환** | 받은 뒤 **3개월 이내** 또는 그 사실을 안 날부터 **30일 이내** |

- 기한은 실제로 **받은 시각**부터 세요(한국 시간).
- 나눠 받은 주문은 신청하는 상품을 받은 시각 기준이에요.

## 비용이 드나요? [확정 정책]

- **단순 변심 교환**: 왕복 배달비 **9,000원**(가는 길·오는 길 합쳐서)
- **상품 하자·잘못 온 상품** 등 상품·배송 문제: **무료**
- 단순 변심 반품의 회수비는 아직 정해지지 않았어요.

## 어떻게 신청하나요? [채택 설계]

- 주문 상세에서 반품·교환을 신청하고 **사유·수량·사진**을 남겨 주세요.
- 회수와 교환품 배송은 **주문할 때 주소**로만 가요.
- 같은 주문을 두 번 교환할 수는 없어요.

## 신청 후에는 어떻게 되나요? [채택 설계]

- 반품: 신청 → 확인 → 회수 → 검수 → 환불
- 교환: 신청 → 확인 → 회수 + 새 상품 배송
- 신청이 접수됐다고 바로 승인된 건 아니에요. 확인 결과는 앱 알림으로 알려 드려요.
- 여러 상품 중 일부만 승인되면 승인된 상품만 진행하고, 나머지는 이유를 알려 드려요.
- 교환할 상품이 품절이면 환불로 바꿀지 여쭤봐요.

## 냉장·냉동 상품도 반품되나요? [확정 정책]

- 받은 뒤 24시간 안에 신청해 주세요. 회수한 신선식품은 다시 판매하지 않아요.
