# 결품: 상품이 모자라 일부 취소된 경우

MFC 에서 피킹할 때 상품이 모자라거나 파손돼 주문 수량을 채우지 못한 경우입니다. 받은 뒤에 빠진 것을 알게 된 경우는 [07](07-missing-wrong-item.md) 입니다.

- 문서 버전: 0.1
- 작성일: 2026-11-09
- 관련 문서: 환불 기준은 [03](03-refund-partial-cancel.md)

## 1. 결품 처리 기준 [확정 정책]

- 결품은 고객이 주문 때 고른 품절 처리 선택과 **관계없이** 그 품목만 **부분 취소·환불**합니다. 남은 상품이 하나도 없을 때만 전체 취소합니다(ADR-0049, 사용자 결정 2026-11-08).
- 고객의 사전 선택(품절 상품만 취소 / 전체 취소)은 기록만 하고 처리에 쓰지 않습니다.
- 남은 주문 금액이 최소 주문금액(15,000원)보다 적어져도 주문은 유지합니다. 다시 결제하라고 하거나 배달팁을 더 받지 않습니다(`OMS-business-logic.md` §8.5).
- **대체 상품은 없습니다.** 고객이 고르지 않은 다른 상품·규격으로 바꿔 보내지 않습니다.
- 환불 금액은 그 상품의 주문 당시 가격과 할인 몫 기준입니다(배달팁·봉투값 제외).
- 결제 전에 품절이 확인되면 주문서에서 고객이 선택을 바꿉니다(결제 뒤 결품과 다름).

## 2. 고객이 알게 되는 방식 [설계안]

- 결품이 생기면 부분 취소 결과가 앱 알림으로 갑니다.
- 고객 문의는 주로 "왜 일부만 왔나요?", "환불은 언제 되나요?", "다른 상품으로 바꿔 줄 수 없나요?" 입니다.

## 3. 고객 대본 [설계안]

1. 사과: "주문하신 상품을 모두 준비해 드리지 못해 죄송합니다."
2. 확인: "확인을 위해 잠시만 기다려 주시겠습니까?" — 주문 상세에서 결품 품목·수량, 부분 취소·환불 상태를 확인합니다.
3. 안내: "주문하신 000 상품이 센터 재고 부족으로 0개 준비되지 못해, 해당 상품 금액 000원은 결제 취소로 환불 진행됩니다. 나머지 상품은 그대로 배송됩니다."
4. (대체 요청) "죄송하지만 다른 상품으로 대신 보내 드리는 것은 어렵습니다. 필요하시면 해당 상품을 새로 주문해 주셔야 합니다."
5. (남은 금액이 적다고 할 때) "남은 금액이 최소 주문금액보다 적어져도 추가 결제 없이 그대로 배송됩니다."
6. (환불 시점) [03](03-refund-partial-cancel.md) §3·§4
7. 마무리([01](01-common-greeting-identity.md) §7)

## 4. 전체가 결품인 경우 [확정 정책]

- 남은 상품이 하나도 없으면 주문 전체를 취소하고 결제 전액(봉투값 포함)을 취소합니다(ADR-0049).
- 대본: "주문하신 상품이 모두 센터 재고 부족으로 준비되지 못해 주문이 전체 취소되었습니다. 결제하신 금액은 전액 취소로 환불됩니다. 불편 드려 죄송합니다."

## 5. 상담원이 하지 않는 것 [설계안]

- 결품 부분 취소는 주문 처리 흐름이 자동으로 진행합니다. 상담원이 같은 품목을 다시 취소·환불 접수하지 않습니다(중복 환불 방지).
- 결과가 "확인 중"이면 기다리도록 안내합니다([03](03-refund-partial-cancel.md) §3).
