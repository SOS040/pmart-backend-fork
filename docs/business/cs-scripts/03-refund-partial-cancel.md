# 환불과 부분 취소

환불이 되는 경우, 금액 기준, 진행 상태, 소요 기간 안내입니다.

- 문서 버전: 0.1
- 작성일: 2026-11-09
- 관련 문서: 전체 취소는 [02](02-order-cancel.md), 결품은 [04](04-shortage.md), 반품은 [09](09-return-exchange.md)

## 1. 부분 취소가 되는 경우 [확정 정책]

- **결품(부분 품절)과 반품**은 원결제에서 해당 상품·수량 금액만 결제를 취소합니다(PG 부분 취소). 나머지 주문은 그대로 유지합니다(`OMS-business-logic.md` §10).
- 전체 취소 후 남은 상품을 다시 결제하게 하는 방식은 쓰지 않습니다.
- **고객이 마음대로 일부 상품만 취소하는 것은 지원하지 않습니다.** 결품·반품 외 사유로 부분 취소를 넓히지 않습니다.
  - 대본: "결제 후 일부 상품만 따로 취소하는 기능은 제공되지 않습니다. 받으신 뒤 반품 기준에 맞으면 반품으로 도와드릴 수 있습니다." → [09](09-return-exchange.md)

## 2. 환불 금액 기준 [확정 정책]

- 환불은 **주문 당시 가격**과 상품별로 나눈 할인 금액 기준입니다. 현재 가격으로 다시 계산하지 않습니다(`OMS-business-logic.md` §10).
- 추가로 환불할 수 있는 금액 = 최초 결제액 − 이미 환불된 금액 − 처리 중인 환불 금액. 같은 상품·수량에 취소·반품·미배송 환불을 겹쳐 주지 않습니다.
- 봉투값은 전체 취소 때만 환불합니다([02](02-order-cancel.md) §4).
- 예: 상품 A 20,000원·B 10,000원, 쿠폰 3,000원, 봉투 100원 → 결제 27,100원. B 를 환불하면 할인 몫을 뺀 9,000원, 남은 결제 18,100원(`OMS-business-logic.md` §10.2).

## 3. 환불 진행 상태 [확정 정책]

- 접수 → 심사·승인 → 실행 대기 → 결제사(PG) 결과 확인 → 완료 / 실패 / 확인 중(`OMS-business-logic.md` §10).
- **승인만으로 완료라고 안내하지 않습니다.** 결제사 취소 성공이 확인돼야 "환불 완료"입니다.
- 결제사 응답이 늦거나 불분명하면 "확인 중"으로 안내하고, 같은 환불을 새로 다시 요청하지 않습니다.
- 대본(확인 중): "환불이 결제사에서 처리 확인 중입니다. 같은 건으로 중복 환불되지 않도록 결과 확인 후 앱 알림으로 안내드리겠습니다."

## 4. 환불 소요 기간 안내 [결정 필요]

- 결제 취소가 성공한 뒤 고객 카드·계좌에 실제로 반영되기까지 걸리는 기간은 결제수단·카드사마다 다릅니다. PMart 안내 문구가 정해지지 않았습니다.
- 결제사 취소 성공 시각과 고객 계좌 입금 시각은 같지 않습니다(`BackOffice-business-logic.md` 환불 대사).
- 정하기 전 임시 문구: "결제 취소는 완료되었으며, 카드사·결제수단에 따라 실제 반영까지 며칠 걸릴 수 있습니다."

## 5. 쿠폰 사용 주문의 환불 [설계안]

- 쿠폰·프로모션은 1차 구현에서 제외되어 있습니다. 쿠폰이 도입되면 아래를 따릅니다(`OMS-business-logic.md` §10.1).
  - 부분 취소: 상품 쿠폰은 기존 소멸 기준, 장바구니 쿠폰은 원래 나눈 금액으로 정산
  - 전체 취소: 결제 취소 성공 뒤 쿠폰 유효기간이 남았으면 복원 한 번(새 쿠폰 발급·기간 연장 아님)
  - 부분 품절·반품으로 쿠폰 최소금액이 깨진 경우의 환수·재발급은 미결정 — 담당자에게 연결

## 6. 고객 안내 대본 [설계안]

- (결품 부분 취소) [04](04-shortage.md) §3
- (반품 환불) "반품 상품이 회수·검수된 뒤 결제 취소로 환불됩니다. 진행 상황은 앱 주문 상세에서 확인하실 수 있습니다."
- (전체 취소 환불) "주문 취소가 완료되면 결제 금액 전체와 봉투값이 함께 취소됩니다."
- 처리 뒤 앱 알림이 발송된다는 점을 안내합니다([10](10-records-notifications.md) §3).
