# 받은 상품 중 누락·다른 상품(오피킹)

내 주문 포장을 받았는데 상품 일부가 빠졌거나, 주문과 다른 상품·규격이 담긴 경우입니다. 피킹 때 모자라 미리 부분 취소된 경우(결품)는 [04](04-shortage.md) 입니다.

- 문서 버전: 0.1
- 작성일: 2026-11-09
- 관련 문서: 반품·교환 기준은 [09](09-return-exchange.md), 환불은 [03](03-refund-partial-cancel.md)

## 1. 먼저 구분할 것 [설계안]

| 구분 | 확인 | 이 문서? |
|---|---|---|
| 결품으로 이미 부분 취소된 상품 | 주문 상세에 결품·부분 취소 표시 | 아니요 — [04](04-shortage.md) |
| 포장에 빠진 상품 | 결품 표시 없음, 포장에 없음 | 예 — §3 |
| 다른 상품·다른 규격이 담김 | 라벨은 내 주문, 내용물이 다름 | 예 — §4 |
| 포장 자체가 다른 주문 | 라벨이 다른 주문번호 | 아니요 — [06](06-wrong-delivery.md) §4 |

## 2. 처리 원칙 [확정 정책]

- 고객 신고·사진과 **피킹·포장·인계·배송 이력**을 확인해 MFC(포장 쪽)와 배송 쪽 중 어디 문제인지 판단합니다. 재고·고객 동의를 확인한 뒤 환불·교환·재배송, 필요하면 회수 배차(`Delivery-business-logic.md` §9.3).
- 오배송·하자의 **교환**은 수령 후 3개월 이내 또는 그 사실을 안 날부터 30일 이내면 심사합니다. 이 경우 일반 7일·신선 24시간 기한으로 거절하지 않습니다. 구매자 교환 배달비 0원(`OMS-business-logic.md` §11.1).
- 환불은 해당 상품·수량만 결제를 부분 취소합니다([03](03-refund-partial-cancel.md) §1).
- 같은 피해 수량을 겹쳐 환불하지 않습니다. 이미 같은 건으로 접수돼 있으면 그 접수를 안내합니다.
- 고객 의사를 반드시 확인합니다(교환으로 다시 받기 / 환불).

## 3. 누락 [설계안]

1. (사과) "주문하신 상품이 빠져 있어 불편 드려 죄송합니다."
2. (확인) "빠진 상품과 수량 말씀해 주시겠습니까?" — 주문 상세에서 결품 여부를 먼저 봅니다.
3. (의사 확인) "빠진 상품은 환불 또는 다시 보내 드리는 것(교환 재배송) 중 원하시는 방법으로 도와드리겠습니다. 어떤 방법이 편하실까요?"
4. 접수: 누락 상품·수량·고객 선택을 사건(클레임)으로 접수 → MFC 포장 이력 확인 → 승인되면 환불(부분 취소) 또는 재배송
5. (안내) "접수되었습니다. 포장 이력 확인 뒤 처리되며 결과는 앱 알림으로 안내드립니다."

- 회수할 실물이 없으므로 회수 배차는 하지 않습니다.

## 4. 다른 상품·규격이 담김(오피킹) [설계안]

1. (사과) "주문과 다른 상품이 담겨 불편 드려 죄송합니다."
2. (확인) "주문하신 상품과 받으신 상품을 말씀해 주시겠습니까? 받으신 상품 사진을 앱 문의에 올려 주시면 확인이 빠릅니다."
3. (의사 확인) "주문하신 상품으로 다시 보내 드리는 교환과 환불 중 어떤 방법이 편하실까요?"
4. 처리
   - 교환: 받으신 상품 회수 + 주문 상품 새로 피킹·포장해 재배송(왕복 배달비 0원). 교환품이 품절이면 환불로 바꿀지 고객과 협의 — 다른 상품으로 임의 대체하지 않음
   - 환불: 받으신 상품 회수 → 해당 상품 부분 취소
5. (안내) "잘못 담긴 상품은 사용하지 마시고 보관 부탁드립니다. 회수 일정은 따로 안내드리겠습니다."

## 5. 회수 없이 처리 [결정 필요]

- 기본은 회수입니다. 회수 없이 처리하려면 승인 사유와 증빙을 남겨야 합니다(`OMS-business-logic.md` §11.2).
- 소액 상품이나 신선식품(어차피 다시 팔지 않음)을 회수 없이 처리할지, 그 승인 기준은 정해지지 않았습니다.

## 6. MFC 에 알릴 것 [설계안]

- 누락·오피킹이 확인되면 사건에 MFC 를 연결해 센터 관리자가 피킹·포장 과정을 확인하도록 합니다([10](10-records-notifications.md) §2).
- 상담원은 MFC 재고를 직접 바꾸지 않습니다. 재고 조정은 MFC 실사·승인 절차를 따릅니다.
