# 반품·교환

받은 상품을 반품하거나 교환할 때의 기한·비용·진행 안내입니다.

- 문서 버전: 0.1
- 작성일: 2026-11-09
- 관련 문서: 환불 기준은 [03](03-refund-partial-cancel.md), 파손·품질은 [08](08-damage-quality.md), 누락·오피킹은 [07](07-missing-wrong-item.md)

## 1. 접수 기한 [확정 정책]

| 경우 | 기한 |
|---|---|
| 일반 교환·반품 | 해당 상품 **실제 수령 후 7일 이내** |
| 신선식품(냉장·냉동) | **수령 후 24시간 이내** |
| 하자·오배송·광고와 다른 상품의 **교환** | 수령 후 **3개월 이내** 또는 그 사실을 안 날(알 수 있었던 날)부터 **30일 이내** 중 하나 — 일반 7일·신선 24시간으로 거절하지 않음 |

- 기한은 한국 시간 기준 **실제 수령 시각**부터, 경계 시각까지 접수 가능. 3개월은 달력 기준(90일로 바꾸지 않음), 그날이 없는 달은 말일(`OMS-business-logic.md` §11.1).
- 나눠 배송된 주문은 신청할 상품의 실제 수령 시각 기준.
- 접수 자격과 최종 승인·환불 완료는 다릅니다. 접수됐다고 승인된 것이 아닙니다.

## 2. 비용 [확정 정책]

- **단순 변심 교환 왕복 배달비 합계 9,000원**(가는 길·오는 길 각각 9,000원이 아님).
- 상품 하자·오배송 등 **상품·배달 문제는 구매자 부담 0원**.
- 일반 반품 회수비의 부과·환급 조건은 따로 정해져 있지 않습니다 — 교환 9,000원을 반품비로 쓰지 않습니다([결정 필요]).
- 회수·재배달 주소는 **원주문 주소로 고정**. 같은 주문의 중복 교환은 막습니다.

## 3. 진행 단계 [채택 설계]

- 반품: 접수 → 심사 → 회수 → 검수 → 결제 부분 취소 → 완료 또는 거절
- 교환: 접수 → 심사 → 회수 + 교환품 새로 피킹·포장·배송(원배송 이력은 남김)
- 일부만 승인되면 승인된 상품만 진행하고 거절된 상품은 사유를 안내합니다(`OMS-business-logic.md` §11.3).
- 교환품이 품절이면 고객과 환불 전환 또는 대기를 협의하고, 다른 상품으로 임의 대체하지 않습니다.
- 반품 환불이 시작되는 시점(회수 확인 / 센터 수령 / 검수 완료)은 정해지지 않았습니다 — 정하기 전에는 심사 대기 후 담당자가 판단하며 자동 환불하지 않습니다([결정 필요]).

## 4. 재고 [채택 설계]

- 반품·환불 요청만으로 재고를 되돌리지 않습니다. 상온 미개봉 적격품만 센터 검수 후 재고로 복구합니다.
- 신선·냉장·냉동 회수품은 다시 팔지 않습니다.

## 5. 고객 대본 [설계안]

1. (확인) "반품(또는 교환) 원하시는 상품과 수량, 사유 말씀해 주시겠습니까? 받으신 날짜도 여쭤봐도 될까요?"
2. (기한 안내 — 신선식품) "냉장·냉동 상품은 받으신 뒤 24시간 이내 접수 기준이라 확인해 보겠습니다."
3. (비용 안내 — 단순 변심 교환) "단순 변심 교환은 왕복 배달비 9,000원이 발생합니다."
4. (비용 안내 — 상품 문제) "상품 문제로 인한 교환·반품은 배달비가 들지 않습니다."
5. (접수) "접수되었습니다. 심사 후 회수 일정과 결과를 앱 알림으로 안내드립니다. 회수는 주문하신 주소로 방문합니다."
6. (기한 지남) "죄송하지만 해당 상품은 접수 기한이 지나 반품이 어렵습니다. 다만 상품 하자나 오배송이라면 교환 특례 기준으로 확인해 드릴 수 있습니다."

## 6. 철회·예외 [결정 필요]

- 철회할 수 있는 단계, 실제 회수 뒤 철회 비용, 거절된 상품의 재전달은 사업 승인 대상으로 아직 정해지지 않았습니다(`OMS-business-logic.md` §11.3).
- 철회 요청이 오면 이미 진행된 회수·결제 취소를 확인한 뒤 담당자에게 연결합니다. 접수를 지워서 남은 처리를 없애지 않습니다.
