# 파손·포장 불량·품질 문제

상품이 깨지거나 새거나, 포장이 불량이거나, 신선도 등 품질에 문제가 있는 경우입니다.

- 문서 버전: 0.1
- 작성일: 2026-11-09
- 관련 문서: 반품·교환 기한은 [09](09-return-exchange.md), 환불은 [03](03-refund-partial-cancel.md)

## 1. 발견 시점별 처리 [채택 설계]

| 발견 시점 | 처리 | 근거 |
|---|---|---|
| 라이더가 가져가기 전 | MFC 직원에게 알리고 인계 보류 → 다시 포장·환불 결정 | `Delivery-business-logic.md` §9.3 |
| 라이더가 가져간 뒤(배송 중) | 라이더 도움 요청 → 사진·시각·상품 위치 등록 → 회수·폐기·재배송 승인 | 같음 |
| 고객이 받은 뒤 | 고객 신고·사진 + 피킹·포장·인계·배송 이력 확인 → 포장 쪽과 배송 쪽 귀책 판단 → 환불·교환·재배송, 필요하면 회수 배차 | 같음 |

- 일부 상품만 문제면 **그 상품·수량만** 고객과 협의합니다(회수 또는 폐기 / 재배송 또는 환불).
- 귀책이 포장 불량이면 라이더 배달료는 정상 지급, 라이더 귀책이면 미지급(상담원은 기록만).
- 추가 보상은 따로 승인합니다. 고객 환불과 라이더 공제를 같은 것으로 처리하지 않습니다.

## 2. 기한과 비용 [확정 정책]

- 신선식품(냉장·냉동)은 **받은 뒤 24시간 이내** 접수, 그 밖은 7일 이내. 단 상품 하자의 교환은 3개월 또는 안 날부터 30일 특례(`OMS-business-logic.md` §11.1).
- 상품 문제의 교환·반품은 구매자 배달비 0원.
- 신선·냉장·냉동 회수품은 다시 팔지 않습니다.

## 3. 고객 대본 [설계안]

1. (사과) "받으신 상품에 문제가 있어 불편 드려 죄송합니다."
2. (확인) "어떤 상품이 어떤 상태인지 말씀해 주시겠습니까? 받으신 시간도 여쭤봐도 될까요?" — 신선식품이면 24시간 기한을 확인합니다.
3. (증빙) "확인을 위해 상품 사진을 올려 주실 수 있을까요?" → §4
4. (의사 확인) "같은 상품으로 다시 받는 교환과 환불 중 어떤 방법이 편하실까요?"
5. (회수) "문제 상품은 회수 후 폐기하며, 회수 일정은 따로 안내드리겠습니다." / (회수 없이 처리로 승인된 경우) "상품은 따로 회수하지 않으니 처분 부탁드립니다."
6. (안내) "접수되었습니다. 확인 후 처리 결과는 앱 알림으로 안내드립니다."

## 4. 사진·증빙 [결정 필요]

- 고객앱 문의에서 사진을 올릴 수 있게 되어 있습니다(`Commerce-business-logic.md` §13). 상담 뒤 사진을 받는 별도 방법(문자 링크 등)을 둘지는 정해지지 않았습니다.
- 사진을 낼 수 없는 경우의 대체 확인 방법과, 증빙 기준이 정해지지 않았다는 이유로 자동 거절하지 않는다는 원칙은 확정입니다(`Commerce-business-logic.md` §13.2).

## 5. MFC·배송에 알릴 것 [설계안]

- 포장 불량이 의심되면 사건에 MFC 를 연결해 포장 과정을 확인합니다.
- 배송 중 파손이 의심되면 라이더 도움 요청 기록·사진을 확인하고, 귀책 조사는 고객 대응과 따로 진행합니다(조사 중에도 고객 대응은 진행).
