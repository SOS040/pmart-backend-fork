# 잘못된 전달: 배송 완료인데 못 받음, 다른 주문 상품 수령, 주문하지 않은 사람이 받음

상품이 다른 곳으로 가거나, 다른 주문 상품이 오거나, 주문하지 않은 사람이 받은 경우의 대응입니다.

- 문서 버전: 0.1
- 작성일: 2026-11-09
- 관련 문서: 받은 상품 중 일부가 빠지거나 다른 상품이 담긴 경우(포장 문제)는 [07](07-missing-wrong-item.md), 반품·교환은 [09](09-return-exchange.md)

## 1. 상황 구분 [설계안]

| 상황 | 고객이 겪는 일 | 절 |
|---|---|---|
| 배송 완료인데 못 받음 | 앱에는 배송 완료인데 상품이 없음 | §3 |
| 다른 주문 상품 수령 | 포장은 받았는데 내 주문이 아님(다른 주문 포장) | §4 |
| 주문하지 않은 사람이 받음 | 주문하지 않은 사람이 포장을 받고 연락함 | §5 |

포장 안 상품 일부가 내 주문과 다르면(라벨은 내 주문) 포장 문제라 [07](07-missing-wrong-item.md) 로 갑니다.

## 2. 공통 원칙 [확정 정책]

- 오배송은 **원주소·전달 사진·고객 진술을 확인**한 뒤 고객센터가 대응합니다. **라이더 연락만으로 환불을 승인하지 않습니다**(`Commerce-business-logic.md` §13.2, `Delivery-business-logic.md` §9.3).
- "배송 완료인데 받지 못함"은 받은 상품의 반품으로 분류하지 않습니다.
- 포장 라벨 오류·주소 오입력·라이더 실수를 구분합니다. 라이더 귀책이면 배달료를 지급하지 않습니다(라이더 지급은 상담원이 정하지 않음 — 기록만).
- 회수 가능성·상품 상태를 확인한 뒤 환불·재배송을 정합니다. **재배송은 교환 승인 건에 한해** 합니다(`OMS-business-logic.md` §9).
- 회수·재배달 주소는 원주문 주소로 고정합니다.
- 같은 피해 수량을 다른 사유로 겹쳐 환불하지 않습니다.

## 3. 배송 완료인데 못 받음 [설계안]

### 3-1. 고객 확인

- "받으실 주소를 전체로 말씀해 주시겠습니까?" — 주문 당시 주소와 맞춰 봅니다.
- "앱 주문 상세에서 배송 완료 때 찍힌 사진 확인되실까요? 사진 속 위치가 맞는지 봐 주시겠습니까?"
- "불편 드려 죄송합니다. 라이더와 확인해 보겠습니다. 잠시만 기다려 주시겠습니까?"

### 3-2. 라이더 확인

- "안녕하세요, PMart 고객센터입니다. 주문번호 뒷자리 0000 건이 배송 완료로 되어 있는데 고객님께서 받지 못하셨다고 하십니다. 주소는 정상 기재로 확인됩니다. 전달하신 위치 확인 가능하실까요?"
- 라이더 확인 결과(귀책 인정 여부, 다시 가져다 드릴 수 있는지, 걸리는 시간)를 **기록**합니다. 이 결과만으로 환불을 정하지 않습니다.

### 3-3. 처리

| 확인 결과 | 처리 |
|---|---|
| 상품을 찾아 원주소로 다시 전달 가능 | 라이더가 회수해 원주소로 전달. 예상 시간 안내 |
| 다시 전달 불가 / 위치 확인 안 됨 | 사건으로 접수해 담당자(관제·OMS 판단)에게 연결 — 미배송 환불 또는 교환(재배송) 결정 |
| 잘못 간 곳에 상품이 남아 있음 | 회수 배차 요청([10](10-records-notifications.md) §2) |

- 대본(담당자 연결): "확인 결과 바로 다시 전달하기 어려운 상황입니다. 미수령 건으로 접수했으며, 담당 부서에서 환불 또는 재배송을 확인해 안내드리겠습니다. 결과는 앱 알림으로 받아보실 수 있습니다."
- 사진을 낼 수 없는 미수령은 다른 방법으로 확인할 수 있어야 하며, 증빙이 없다고 바로 거절하지 않습니다(`Commerce-business-logic.md` §13.2).

## 4. 다른 주문 상품 수령 [설계안]

- "받으신 포장의 라벨에 적힌 주문번호 뒷자리 확인 가능하실까요?"
- 라이더 확인: "주문번호 0000 고객님께서 다른 주문 포장(0000)을 받으셨다고 하십니다. 확인 부탁드립니다."
- 처리
  - 라이더가 잘못 간 포장을 회수하고 맞는 포장을 전달할 수 있으면: 고객에게 "받으신 포장은 문 앞에 보관 부탁드립니다. 라이더가 맞는 상품을 가지고 방문해 함께 회수하겠습니다." + 예상 시간
  - 바로 바꿀 수 없으면: 사건 접수 → 담당자가 미배송 환불 또는 교환(재배송) 결정. 잘못 받은 포장은 회수 배차.
- 잘못 받은 포장은 열거나 쓰지 않도록 부탁합니다. 신선식품은 회수 뒤 다시 팔지 않습니다(`OMS-business-logic.md` §11.2).

## 5. 주문하지 않은 사람이 받음 [설계안]

### 5-1. 받은 사람 응대

- "불편 드려 죄송합니다. 번거로우시겠지만 포장 라벨의 주문번호 뒷자리와 받으신 주소 확인 가능하실까요?"
- 회수를 위해 주소를 라이더에게 알려야 하면 **동의**를 받습니다([§6](#6-결정-필요-항목-결정-필요)).
- "받으신 상품은 문 앞에 보관해 주시면 빠르게 회수하겠습니다. 회수 예정 시간은 안내드리겠습니다."

### 5-2. 원래 주문자 처리

- 원래 주문자의 문의가 이미 있으면 그 사건에 연결하고 잘못 간 주소를 기록합니다.
- 문의가 없으면 원래 주문자에게 연락해 상황을 알리고, §3-3 처럼 재전달 또는 담당자 판단으로 처리합니다.

## 6. 결정 필요 항목 [결정 필요]

- **시간 기준**: 잘못 전달된 뒤 얼마 안에 다시 전달하면 재전달을 먼저 안내하고, 넘으면 미배송 환불·재배송을 먼저 안내할지(예: 전달 완료 후 10분·15분).
- **회수 예정 시간**: 라이더에게 요청할 회수 한도와 고객에게 안내할 시간.
- **주소 제3자 전달 동의 문구**: 잘못 받은 사람의 주소를 회수 라이더에게 알리는 동의 문구와 기록 방식.
- **보상**: 쿠폰 1차 제외 — 사과 외 보상 여부.
