# 상품이 추가되면 — 검색·진열에 퍼지는 구조와 재색인이 필요한 때

- 작성: PC 1 작업 세션, 2026-11-20 (사용자 "상품 추가되었을 때 구조 답변 전부, 재색인에 대한 부분 md 파일로 정리")
- 함께 볼 것: `docs/architecture/product-search.md`(검색 구현 정리), `deploy/lan/elastic/REINDEX.md`(재색인 절차), ADR-0031(색인은 Logstash)·ADR-0072(순위 신호)·ADR-0073(동의어·오타)

## 1. 흐름 — 승인 → 사건 → 각 서비스가 자기 사본 갱신
서비스끼리 직접 부르지 않고 **사건(Kafka)** 으로 퍼진다.

```
① 상품 등록(백오피스) → product-service 초안 → 승인(PRODUCT)
      └ 승인되면  ProductVersionPublished  (상품 ID·SKU·카테고리·판매 상태·필터·내용량)
② 콘텐츠 등록(이름·사진·설명) → product-content 초안 → 승인(DISPLAY)
      └ 승인되면  ProductContentPublished
③ 가격 등록 → pricing 승인(PRICE) → PriceVersionEffective
④ 센터 취급 켜기(MFC) → mfc-inventory → SkuHandlingChanged
```

| 받는 곳 | 하는 일 |
|---|---|
| 검색 색인(Logstash → ES `products`) | ①②③④를 받아 상품 문서 하나로 합친다. 이름·사진은 ② 때 product-content 공개 카드 API 로 보강 |
| 홈 진열(storefront) | ①②③④로 진열 사본(BR-49·BR-63) |
| 상품 상세(product-content) | ① 사본으로 상세 화면 데이터 |
| 순위 신호(storefront → 검색, ADR-0072) | 처음엔 리뷰·판매가 없어 신호 없음 → 첫 리뷰·첫 주문이 생기면 `ProductRankingSignalsChanged` 가 나가 검색 정렬(인기순·별점순·리뷰 많은 순)에 반영 |

## 2. 언제 고객에게 보이나
- **검색**: 이름(②)과 상품 버전(①)이 둘 다 있고 판매중지가 아니면. 센터를 주고 찾으면(`mfcId`) ④ 취급이 켜진 센터에서만.
- **홈 진열**: 같은 조건, 최신 게시 순으로 섞여 보인다.
- **가격**: ③이 없으면 "가격 확인 중"(0원이 아님).
- 사건이 순서대로 오지 않아도 된다 — 버전을 비교해 늦게 온 옛 사건은 무시하고, 먼저 온 조각은 기다렸다 합친다.

## 3. 동의어·오타 교정(ADR-0073)을 넣은 뒤 새 상품
- **동의어**는 검색할 때 적용 → 새 상품에도 자동으로 걸린다(예: "달걀"로 찾아도 새로 들어온 "계란" 상품이 바로 나온다).
- **오타 사전**은 상품명 낱말 사전을 주기적으로(예: 10분) 다시 만든다 → 새 상품 이름의 낱말도 몇 분 안에 교정 대상.
- 운영자가 따로 할 일은 없다. 새 상품에 맞는 동의어가 필요하면 동의어 화면에서 추가(승인 — MD 요청·관리자 승인).

## 4. 재색인이 필요한가
**상품이 추가될 때는 필요 없다.** 사건이 오는 대로 Logstash 가 그 상품 문서만 넣고 고친다(보통 몇 초 안에 검색에 보임). 수정·가격·판매중지·리뷰·판매 신호도 그 문서만 바뀐다.

재색인은 **색인 구조가 바뀔 때만** 필요하다.

| 경우 | 재색인 |
|---|---|
| 상품 추가·수정·가격·판매 상태·리뷰·판매 | 필요 없음 |
| 동의어 추가·수정·삭제(ADR-0073 이후) | 필요 없음 — 검색할 때 적용(ES 동의어 집합) |
| 오타 사전 | 필요 없음 — 상품명에서 주기적으로 다시 만든다 |
| 색인에 새 칸·분석기 바꾸기 | **필요** — 예: 2026-11-20 v6(순위 신호 칸), ADR-0073 준비로 v7 한 번 |
| 버그로 잘못 색인된 값 바로잡기 | 필요할 수 있음 |

- ADR-0073 은 동의어 분석기를 붙이는 **v7 재색인이 딱 한 번** 필요하다(오늘 v6 처럼 무중단 — 별칭 교체). 그 뒤로는 동의어를 바꾸든 상품이 늘든 재색인 없이 돌아간다.
- 절차: `deploy/lan/elastic/REINDEX.md`(check → start → wait → switch → search-service 배포 → finish → 순위 신호 다시 내기).
