# ADR-0083 운영자·고객 RAG 의 상품 질문은 상품 검색 결과를 정해진 문장으로 답한다

- 상태: **승인** (2026-11-20)
- 사용자 결정 2026-11-20: "기존 상품검색 Elasticsearch 를 운영자용 RAG 와 고객용 RAG 에 각각 연결한다" → 답변 방식 "상품 질문만 정해진 문장", 고객 "센터 취급 여부는 답하지 않음(전체 기준)", 운영자 "상품 정보만 답함(실시간 재고 수량·주문 상태는 그대로 거절)".
- 일부 대체: ADR-0036 결정 1(범위 — 특정 대상의 현재 상태는 답하지 않음)을 **상품의 가격·판매 상태·센터 취급 여부**에 한해 넓힌다. 재고 수량·주문·결제의 현재 상태는 여전히 REALTIME_DATA_REQUIRED. ADR-0051(고객 RAG 범위)에 상품 안내를 더한다.
- 관련: ADR-0021·0031·0038(상품 검색 색인), 계약 `ai-assistant-service.yaml` 1.2.0 · `customer-assistant-service.yaml` 0.3.0, `search-service.yaml` `GET /search/products`(공개 작업).

## 결정
1. **검색 서비스 API 만 쓴다.** RAG 서비스는 search-service `GET /api/v1/search/products` 를 부른다. 상품 검색 Elasticsearch(`es-search`)에 직접 붙지 않는다(다른 서비스 저장소에 직접 접근 금지).
2. **상품 질문만, 규칙으로 가린다(모델 없음).** "두부 있어요?", "생수 얼마예요?", "콜라 팔아요?" 처럼 상품 이름 + 가격·판매 여부를 묻는 꼴이면 상품 질문. 업무 규칙·요금·처리 말(봉투값·배달팁·회수비·취소·환불·반품·주문·배송·재고·몇 개 …)이 있으면 상품 질문이 아니다 — 문서 검색이 답한다(`domain/ProductQuestion`, 두 서비스 같은 규칙).
3. **정해진 문장.** 상위 3개(설정 `pmart.assistant.product-search.max-items`)를 상품명·기본가·판매 상태로 적는다. 모델이 가격·상태를 만들지 않는다. 가격이 없으면 0원이 아니라 "가격 미등록/준비 중". 상태 `PRODUCT_INFO`, 답 방식 `PRODUCT_TEMPLATE`, 근거 문서 없음.
   - 운영자: 질문 화면의 센터(context.centerId)가 있으면 그 센터 취급 여부(`mfcId` + `includeNotCarried=true`)를 붙이고, "실시간 재고 수량·주문 상태는 업무 화면에서" 를 덧붙인다.
   - 고객: 센터를 주지 않는다(질문 요청에 주소·센터가 없음). "주소에 따라 받아 볼 수 없는 상품도 있어요" 를 덧붙인다.
4. **없으면 문서로.** 검색 결과가 0건이거나 검색이 실패하면(연결 실패·5xx) 상품 답을 하지 않고 지금처럼 문서 검색으로 답한다. 실패는 로그에 예외 종류만(질문·검색어 없음).
5. **익명 검색.** 토큰을 붙이지 않는다 — 공용 RestClient 가 전파하는 사용자 토큰을 뗀다. 익명 검색은 고객 최근 검색어·인기 키워드 기록에 남지 않는다.
6. **설정이 없으면 꺼짐.** `pmart.assistant.product-search.base-url` 이 없으면 상품 질문도 문서로 답한다(기본값으로 대신하지 않음). LAN 은 `http://search-service:8105`(Eureka 이름).
7. **답에 상품 목록을 따로 싣지 않는다.** 응답은 문장(answer)만 — 화면이 상품 카드를 그리려면 계약에 목록 필드를 더하는 별도 결정이 필요하다. 저장 답변을 다시 읽어도 같은 문장이다(그 때의 검색 결과).

## 결과
- 운영자·고객 모두 상품의 가격·판매 여부를 물으면 검색 색인 기준으로 바로 답한다. 색인 반영이 늦으면 답도 늦은 값이다(문장에 밝힘).
- 클라이언트는 새 상태·답 방식 값(PRODUCT_INFO·PRODUCT_TEMPLATE)을 받아도 깨지지 않아야 한다 — 회신 `docs/handoff/clients/all/2026-11-20-notice-rag-product-info.md`.
- 문장 꼴 규칙이라 놓치는 질문(예: "두부 들어왔나요?")은 문서로 답한다. 놓침·오탐은 질문 사례가 쌓이면 규칙을 고친다.
