# ADR-0089 PDA 앱 무활동 한도 = 근무 길이(12시간) — ADR-0056 결정 14 ③ 대체

- 상태: **승인** (2026-11-25, 사용자)
- 대체: ADR-0056 결정 14 ③("무활동 30분이면 다시 로그인"). 결정 14 의 나머지(로그아웃 때 Keycloak 세션도 끝냄, 근무(교대) 종료 시각 뒤 자동 로그아웃)는 그대로.
- 근거(사용자 2026-11-25): "PDA앱 리프레시 토큰 30분 맞아? 8시간 막 일하다가 밥먹고나선 로그인을 매번할순없어" → 선택지(늘리기·근무 길이·앱 화면 잠금) 중 "무활동한도를 근무 길이로 맞춰줘".

## 결정
1. employee-auth `pmart.employee-auth.apps.mfc.session-idle` = **PT12H**(세션 최대 `session-max-age` 12시간과 같음). 세션 = min(갱신 + 12시간, 시작 + 12시간) → 사실상 로그인 한 번에 근무 한 번.
2. 공용 PDA 보호는 사람이 한다 — 자리를 비우거나 근무가 끝나면 로그아웃. 앱 화면 잠금(PIN·사번 확인)은 이번에 넣지 않는다(필요하면 따로).
3. access token 15분·refresh 1회 사용·로그인한 기기에서만·정지·퇴사 즉시 차단(SubjectBlocked)은 그대로.

## 결과
- 점심 등 30분 넘게 쉬어도 다시 로그인하지 않는다.
- 공용 PDA 를 로그아웃 없이 두면 12시간까지 그 계정으로 쓸 수 있다 — 현장 안내 필요.
