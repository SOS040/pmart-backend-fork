# ADR-0081 찜(위시리스트) — 회원·상품 단위·200개·customer-service

- 상태: **승인** (2026-11-20)
- 사용자 결정 2026-11-20: "찜 기능 넣고 싶어" → 대상 "회원만", 단위 "상품(productId)", "200개, 남기고 표시", 담당 "customer-service"
- 근거: `docs/business/Commerce-business-logic.md` — 찜은 승인 대상(79·94·332·2400·2709행), 승인 전 비회원 식별·개인정보 수집을 시작하지 않음. 이번 사용자 결정이 찜의 도입 승인이다(재입고 알림은 승인 범위 밖).

## 결정
1. **회원만.** 고객 토큰(CUSTOMER)만. 비회원은 앱이 로그인 안내(서버는 비회원 찜을 두지 않는다).
2. **상품(productId) 단위.** 옵션(SKU)은 담을 때 고른다. 같은 상품을 다시 찜하면 그대로(멱등).
3. **최대 200개**(정책값 `pmart.customer.wishlist.max-items`, 없으면 추가 CONFIG_REQUIRED). 넘으면 422 `WISHLIST_LIMIT_EXCEEDED`.
4. **품절·판매 종료는 찜에 남긴다.** 목록에서 지금 상태(판매 중·품절·판매 종료·정보 없음)로 표시. 자동 삭제 없음. **재입고 알림은 만들지 않는다**(문서상 별도 승인).
5. **customer-service 소유**(service-map 갱신). 목록의 상품명·가격·대표 사진·판매 상태는 저장하지 않고 조회 때 product-content 의 묶음 카드 API 에서 읽는다(실패하면 그 칸만 null — 찜 목록 자체는 준다).
6. 탈퇴 완료(ADR-0077) 때 찜도 지운다. 찜 개수를 상품에 공개하지 않는다(1차). 사건(이벤트)은 내지 않는다(추천·알림이 생길 때 추가).

## 결과
- 앱: 상품 상세·목록 카드 하트(전체 찜 ID 를 한 번 받아 표시), 마이 → 찜 목록 화면.
