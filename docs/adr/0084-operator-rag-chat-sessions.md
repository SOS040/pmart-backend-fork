# ADR-0084 운영자 RAG 채팅 세션 — 한 세션에 여러 질문, 앞 대화 반영, 본인 삭제, 마지막 질문 뒤 14일 보존

- 상태: **승인** (2026-11-21)
- 사용자 결정 2026-11-20(요청 2번 "채팅 기능 수정"): "하나의 채팅 세션에서 여러 번 질문하고 답변받을 수 있도록", "백오피스 화면에서 운영자가 자신이 생성한 채팅을 개별적으로 삭제", "채팅 기록의 보존 기간은 14일" → 적용 범위 "운영자(백오피스)만", 이어 묻기 "앞 대화를 반영", 14일 기준 "마지막 질문에서", 기존 기록 "질문마다 세션 하나로".
- 관련: ADR-0036(운영자 RAG — 결정 3 질문 원문, 보존 기간 [결정 필요]을 이 ADR 이 14일로 정함), 계약 `ai-assistant-service.yaml` 1.3.0, 마이그레이션 `V2__chat_session.sql`.

## 결정
1. **세션 = 질문 묶음.** 표 `chat_session`(만든 운영자·출처·만든 시각·마지막 질문 시각). 답변(`policy_answer`)은 세션 하나에 속한다(`session_id`, 세션을 지우면 답변도 함께 — ON DELETE CASCADE).
2. **질문할 때 세션을 고른다.** `POST /assistant/policy-questions` 의 `sessionId` 를 주면 그 세션에 이어 묻고(본인·같은 출처 세션만, 아니면 404), 주지 않으면 새 세션. 응답에 `sessionId`. 요청 해시는 세션을 줄 때만 세션 ID 를 더한다(같은 키를 다른 세션에 쓰면 409, 세션 없이는 예전 해시 그대로).
3. **앞 대화 반영(규칙, 모델 없음).** 같은 세션에서 근거가 있는 완료 답변 중 질문 원문이 저장된 최근 2턴을 쓴다.
   - 검색: 이어지는 질문("그럼·그건·만약…"으로 시작하거나 12자 미만)이면 직전 질문을 앞에 붙여 검색한다(`domain/FollowUp`). 주제가 바뀐 완결 질문은 그대로 검색한다.
   - 생성: 앞 대화를 `<history>` 로 넘기되 **근거가 아니다** — 답의 내용·숫자·인용은 문서(`<doc>`)에서만(생성기 규칙 9, 인용 검사 그대로). 질문 300자·답 500자로 잘라 문맥 창을 문서에 남긴다.
   - 발췌 기준선(모델 없음)은 앞 대화를 쓰지 않는다(검색만 위 규칙).
   - 질문 원문 저장이 꺼져 있으면(`store-question: false`) 앞 대화가 없다 — 세션 묶음만.
4. **본인 삭제.** `DELETE /assistant/chat-sessions/{sessionId}` — 본인 세션을 질문·답변째 지운다(되돌릴 수 없음). 없거나 남의 세션이면 지우지 않고 204(멱등, 존재를 드러내지 않는다). 다른 운영자·관리자가 대신 지우는 경로는 없다.
5. **보존 14일 — 마지막 질문 기준.** 정리 작업(1시간마다)이 마지막 질문 시각이 `pmart.assistant.answers.retention`(14d) 보다 오래된 세션을 답변째 지운다. 처리 중 답변이 있는 세션은 건너뛴다. 설정이 없으면 지우지 않는다(기본값으로 대신하지 않음).
6. **기존 기록은 답변마다 세션 하나**(`SES-` + 답변 ID 뒷부분). 마지막 질문 시각 = 그 답변 시각이라, 보존 설정을 켜면 14일이 지난 기존 기록은 첫 정리 때 지워진다.
7. **조회.** `GET /assistant/chat-sessions`(내 채팅, 마지막 질문 최근 순, 제목 = 첫 질문 또는 첫 답변 앞 60자), `GET /assistant/chat-sessions/{sessionId}`(질문 순 질문·답변 — 지금 권한으로 볼 수 없는 답변과 실패한 시도는 빼고). 기존 `GET /assistant/question-history` 는 그대로 둔다.
8. **고객 RAG 는 바꾸지 않는다**(사용자 "운영자만").

## 결과
- 백오피스 AI 질문 화면이 세션 목록·대화 화면·삭제 버튼으로 바뀌어야 한다 — 요청 `docs/handoff/clients/backoffice/2026-11-21-request-assistant-chat-sessions.md`.
- 보존 설정(14d)은 pmart-config 에 넣어야 켜진다(PC 1).
- 이어 묻기 규칙은 문장 꼴만 본다 — 놓치는 이어 묻기(예: 대명사 없이 생략한 질문)는 앞 질문 없이 검색한다. 앞 대화가 생성 답변에 주는 영향은 실제 모델(qwen3:4b)로 평가하지 않았다(다음 답변 평가 때).
