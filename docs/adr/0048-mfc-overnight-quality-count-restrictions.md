# ADR-0048 MFC 품질·실사·운영 제한·재포장 등 — 결정 없이 구현한 기본값 (사용자 확인 대기)

- 상태: 제안 (2026-11-08 밤, 사용자: "결정 필요 없는 부분을 쭉 구현하고 나중에 결정한 거 리스트업")
- 관련: ADR-0040(재고 모델), ADR-0044·0045(결품), ADR-0046(집품 뒤 취소), ADR-0047(인계), MFC Q-11·Q-13, BO-08

## 배경
업무 문서에 규칙은 있으나 승인자·배분 순서 같은 값이 미결(Q-11·Q-13)인 MFC 기능을, 문서가 허용하는 "보류 동작" 안에서 구현했다.

## 결정(기본값)
1. 품질(IV-09·IV-10): 격리는 즉시, 해제는 요청 → 다른 MFC_SUPERVISOR 승인, 폐기는 요청 → 승인(approvalRef, 부분 승인) → 승인 잔량 안 실행. 격리로 LOT 의 R 이 E 를 넘으면 넘는 양만 나중 예약부터 BLOCKED, 자동 재배분 없음.
2. 실사(IV-11): 실사 잠금 위치의 NORMAL·STORED 만, 장부 숨김, 차이면 다른 작업자 재계수(최종 = 재계수), 시작·계수자 아닌 감독자 승인(approvalRef), 장부가 바뀌었으면 BOOK_CHANGED, 승인 때 그 위치 조사 보류 해소.
3. 운영 제한(BO-08): 슬롯 창이 [from, to) 와 겹치면 적용, 해제 요청으로만 끝(시간 자동 해제 없음). 접수 중지 = 신규 Hold 거절, 수용 축소 = min(설정, 축소), 기존 약속 유지.
4. 재포장(WK-07): 새 포장 ID·QR, 이전 INVALIDATED, 내용 변경 없음.
5. 권한: 실행 = MFC_WORKER·MFC_SUPERVISOR, 승인 = MFC_SUPERVISOR(본인 아님). approvalRef 는 존재 확인 없이 기록(approval-service 미구현).
6. 위치 폐지 = CLOSED·재고 0. 공급 요청 = MFC_SUPERVISOR, 같은 SKU 미해결 요청 중복 거절.

## 열어 둔 것
- `ReservationBlocked`(격리·실사 손실 보류)를 고객 결품 처리(ADR-0045 결품 사가)에 연결할지 — 자동 부분 취소·환불이 되므로 결정 대기.
- Q-11 실제 승인자·금액 임계, Q-13 재배분 순서, 내용 변경 재포장, 회수품 반입·검수(claim·배송 회수 흐름 필요).
