## 정해 주실 것(5·6·7 시작 전)
### 5 별점·리뷰
- (가) **정렬 선택지만** 추가 — "별점 높은 순"·"리뷰 많은 순"(계약 `sort` 값 추가). 기본 관련도 순위는 그대로.
- (나) (가) + **기본 순위에 별점을 섞기** — 섞는 정도(예: 관련도가 비슷하면 별점·리뷰 많은 쪽 위, 리뷰 적은 상품의 높은 별점은 덜 믿기 — 베이지안 평균).
- 리뷰가 없는 상품은 정렬에서 뒤(0점이 아니라 "없음").
### 6 인기순
- 집계 기간: 최근 7일 / 30일 / 전체.
- 무엇을 셀지: 주문 확정 수량(추천) / 주문 건수. 취소·반품은 빼는지.
- 정렬 선택지 "인기순"만인지, 기본 순위에도 섞는지(5 와 같은 질문).
### 7 동의어·오타
- 동의어 사전: 누가 관리(설정 파일 — 배포 때 반영 / 백오피스 화면 — 새 기능), 처음 목록(예: 계란↔달걀, 콜라↔코카콜라).
- 오타 교정: "결과가 0건이거나 적을 때만" 고친 검색어로 다시 찾고 화면에 "○○ 검색 결과예요 — △△로 찾기" 보이기(계약에 `correctedQuery` 추가, 고객 앱 일) / 자동완성 쪽만 / 하지 않음.
