# 2026-11-19 오류·문제와 해결 기록 (PC 1 작업 세션)

- 범위: 이날 PC 1 작업 세션의 배포·시험·운영 중 생긴 오류, 사용자가 겪은 문제, 내가 잘못 판단해 바로잡은 것.
- 상세 진행은 `docs/worklog/platform/2026-11-19.md`, 배포 절차는 `deploy/lan/README.md`. PR 세션 기록은 일지의 `(PR 세션)` 줄.

## 요약

| # | 분류 | 증상 | 원인 | 해결 | 상태 |
|---|---|---|---|---|---|
| 1 | 사용자 체감 | 고객 앱 요청이 **타임아웃** | customer·order 배포 재시작(12:51·12:53) 동안 각 1분 남짓 응답 없음 | 기동 뒤 정상. 배포 전에 "잠깐 끊긴다"고 알리지 않았음 | 해결 — 다음부터 배포 전에 알림 |
| 2 | 사용자 체감 | 고객 앱 **"배송 출발" 휴대폰 알림이 안 옴**(지도는 보임) | 푸시가 옛 설치의 단말 토큰(`a848…`)으로만 감 → FCM "무효" → 서버가 토큰 삭제. 지금 설치의 토큰(`f6e6…`)은 30초 뒤에 등록 | 서버 수정 없음. 그 뒤 알림 정상(사용자 확인) | 해결 |
| 3 | 개인정보 | 좌표→주소 요청 URL 의 **고객 현재 좌표가 게이트웨이 추적(Zipkin)에 남음** | 게이트웨이 추적 `http.uri` 에 쿼리 전체가 들어감 | `TraceUriWithoutQuery` — 경로만(9e977d49, PC 4 배포). 다시 시험: 좌표 남은 추적 0건 | 해결. **고치기 전 추적은 보관 기간이 지나야 사라짐** |
| 4 | 배포 | BR-49 배포가 **권한 확인에 막힘** | 자동 권한 검사가 설정 올리기 + 배포 묶음 명령을 거절 | 사용자 "응" 뒤 이미지 올리기와 배포를 나눠 실행. 처음 시도에서는 아무것도 나가지 않음 확인 | 해결 |

| 6 | 배포 | 설정 저장소(pmart-config)에 **커밋 안 된 변경이 남음**(BR-49 배포 막힘 사이) | 설정 바인딩은 storefront 새 코드와 같이 나가야 해서 먼저 올리지 않음 | BR-49 배포 때 함께 올림(32754db) | 해결 |
| 7 | 시험 | storefront 새 시험 `centerHidesNotCarriedProducts` 실패 2번 | ① 시험 상품의 콘텐츠 카드 스텁 없음 ② 같은 DB 를 쓰는 다른 시험의 진열 순서에 섞임 | 스텁 추가, 옛 게시 날짜, 끝에 판매중지로 치움 | 해결 |
| 8 | 시험 | product-content 새 시험 단언 실패 | 응답이 없는 값을 JSON null 로 주는데 "칸 없음"만 기대 | null·없음 둘 다 받게 | 해결 |
