## 원칙(꼭 지킬 것)
- 원산지는 **라벨·이미지에 명시된 값만**. 추측 금지(법적 문제). 같은 브랜드 다른 상품 값으로 채우지 않는다. 못 읽으면 비운다.
- 포장 리뉴얼로 라벨이 두 장이면 둘 다 적거나(어느 것이 새 것인지 모를 때) 새 라벨 값을 쓴다.

## 남은 결정·확인(사용자에게 물을 것)
- 원산지를 비운 신선식품 3개: 참프레 동물복지 냉장 닭볶음탕용 800g, 냉장 가슴살 300g, 냉장 통닭 8호 700g — 실물 포장 확인 필요.
- 미트엔조이 대패삼겹살: 표시사항 2장(스페인산·폴란드산) + 리뉴얼 안내 → "스페인산 또는 폴란드산(리뉴얼 전후 순차 배송)"으로 넣음.
- 친환경 양배추 1/2컷: 원산지 변경 안내, 새 라벨 생산지 판독 불가 → 비움(옛 라벨 제주).
- 라벨끼리 다른 것: 상하 유기농주스(튀르키예/이탈리아, 우유 유무), 비비고 소고기 미역국(정보고시 호주산 ↔ 라벨 국내산), 꽃보다오징어(구 외국산 → 신 국내산).
- 원본 데이터 오류: 칠성사이다 제로 원재료(라벨 기준 알룰로오스로 바꿈), 롯데 알뜰소시지(이름 350g ↔ 라벨 500g), 햇반 작은공기 6입(라벨 3개)·3입(흑미밥 라벨).
- 이미지를 열지 않고 같은 상품 다른 구성 라벨을 빌린 것: 고려당 복분자주 낱병, 햇반 발아현미 4개 묶음, 미미네 떡볶이 2개 묶음, 돼지수육국밥 2개 묶음 / OCR 만 쓴 것: 버터롤, 모짜렐라 슈레드, 여주쌀, 하림 치킨너겟 — 이미지로 다시 확인 권장.
