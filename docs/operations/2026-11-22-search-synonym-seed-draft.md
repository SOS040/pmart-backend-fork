## 고른 기준
1. **같은 뜻 묶음만** 허용된다(승인 형식 검사 — 한 방향 `=>` 는 막힘). 묶음은 양쪽으로 넓혀 찾으므로, 서로 바꿔 찾아도 이상하지 않은 말만 넣었다.
2. 상품명에 이미 있는 말 + 고객이 흔히 쓰는 다른 표기·외래어 표기·옛말. 상품명에 없는 쪽(예: 달걀)은 사실상 "그 말로도 찾기"가 된다.
3. 오타(우우·치브·치즈ㅡ)는 넣지 않는다 — 결과 0건이면 자모 교정이 사전의 실제 낱말로 바꿔 다시 찾는다.
4. **뺀 것**: 브랜드끼리(코카콜라 ↔ 펩시 — 펩시를 찾았는데 코카콜라가 나옴), 상위어 ↔ 상품(과일·맥주·와인·파스타 → 사과·칭따오… — 한 방향이어야 맞음), `코크`(상품명 "초코크림"에 걸림), `콜라`(이미 "코카콜라"가 코카+콜라로 나뉘어 찾힘).

- "와인"은 지금 와인 상품이 없다(결과 0건이 맞음).
