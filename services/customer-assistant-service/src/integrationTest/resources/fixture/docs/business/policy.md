# 테스트 업무 정책

문서 버전: 1.0 · 기준일: 2026-10-01 · 상태: 설계안

## 1. 봉투

[확정 정책] 봉투값은 주문당 100원 1회다. 전체 취소 시 봉투값을 전액 환불한다.

## 2. 분할 배송

[설계안] 무게 10,000g 초과 주문은 분할 배송한다. 정확히 10kg 은 분할하지 않는다.

## 3. 고객 카테고리

[확정 정책] 고객 분류는 1·2단계로 구성하고 상위 30개 분류를 노출한다.

## 4. 구현 상태 (2026-10-31, 슬라이스 4)

[확정 정책] 결제 확정 뒤 주문 확정 이벤트를 발행한다.

## 부록 C. 쿠폰 — 1차 제외

쿠폰 중복 사용은 장바구니 쿠폰 하나만 허용한다.
