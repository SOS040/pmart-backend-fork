## 2. 왜 299인가요?

- 바코드(EAN-13)의 앞자리는 나라나 용도를 나타낸다. 한국 제조사 상품은 **880** 으로 시작한다(예 `8801234567893`).
- **200~299** 는 국제 표준(GS1)이 "매장이 내부용으로 쓰는 번호"로 비워 둔 대역이다. 이 번호는 실제 판매 상품과 겹치지 않는다.
- 그래서 LAN 시험 상품 503개에 실제 제조사 번호 대신 299 로 시작하는 번호를 만들어 붙였다(2026-11-16, 목록 `../barcodes-2026-11-16.csv`).
- 시스템에는 503개 모두 정식 등록돼 있다(상품 승인 버전 → MFC 재고 SKU 사본). PDA 로 찍으면 어떤 상품인지 안다.
- 실제 상품 포장에는 이 번호가 인쇄돼 있지 않다. 찍으려면 스티커로 뽑아야 한다(1번 표 4번). 실제 포장의 880 바코드로 찍으려면 그 번호를 상품에 추가로 등록한다(상품 하나에 바코드 여러 개 가능).

## 3. 번호 구성 (13자리)

```
2990 00000238 9
│    │        └ 검사 숫자 (앞 12자리로 계산)
│    └ 상품 일련번호 8자리 (E-00000238 → 00000238)
└ 299 + 구분 (0 = 낱개 E-, 1 = 묶음 B-)
```

- 예: `2990000002389` → 낱개 상품 `E-00000238`
- 예: `2991000000191` → 묶음 상품 `B-00000019`
- 검사 숫자: 홀수 자리 ×1, 짝수 자리 ×3 을 더해 10 의 배수가 되도록 하는 수. 2026-11-16 에 검사 숫자가 틀린 옛 시드 바코드 7개(B-6·7, E-1~5)를 고쳤다(승인 AP-f51a0836).
- E-00000008~17 은 `29900000100xx` 처럼 일련번호 대역이 다르지만 검사 숫자는 맞다.
